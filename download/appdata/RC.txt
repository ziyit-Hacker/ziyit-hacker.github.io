## Release Control 26.9-snapshot-26W41A 更新说明

### 一、新增功能

- 新增「更新与安全」窗口：集中展示当前版本与最新版本、更新渠道、响应签名状态、签名密钥 ID、更新包校验方式与防降级状态，并可在此完成「检查更新 / 立即更新 / 回滚到上一版本」。
- 支持更新回滚：可一键回滚到上一版本，命令行同步提供 `--rollback-rcu`。
- 新增「授权密钥」激活方式：可在网页生成一次性、15 分钟有效的 `RCS-` 开头授权串，兑换长期凭据；激活窗口改为「产品密钥 / 授权密钥」双标签页。
- 加密对话系统新增密钥来源：「云加密 / 联网密钥 / 我的文件密钥」，可调用服务端签发文件密钥（含每月额度提示）或直接进行云加密，并可跳转网页查看文件密钥。
- 更新列表支持多包展示：按「增量 / 全量」分别列出待安装包并显示体积，长期支持（LTS）版本显示专属徽章。
- MOD 市场新增下载进度窗口：显示下载进度、速度与大小，下载完成后自动安装。
- 进程列表显示名优先采用可执行文件的文件描述信息，命名更贴近 Windows 任务管理器。
- 命令行新增更新相关命令：`--update-rcu`、`--apply-rcu`、`--rollback-rcu`。

### 二、功能改进

- 菜单「检查更新」与对应快捷键改为打开「更新与安全」窗口。
- 主窗口不再接收拖放；拖放安装统一改在「管理 MOD / 管理 DLC」窗口内完成（以保证主窗口维持管理员权限）。
- DLC 归属校验改用 RC 凭据（以 `Bearer` 令牌请求，无令牌时回退「用户名 + 密钥哈希」）。
- 启动许可检查流程重排：解析 API 地址 → 已保存产品密钥 → RC 长期凭据 → 常规校验，并区分 401 / 403 提示。
- 打包工具在加密 DLC 时跳过 `rely` 依赖目录。
- 命令行更新命令统一携带鉴权信息并做 SHA-256 校验；`--update-list` 额外显示增量 / 全量与体积。
- 新增崩溃日志：全局异常与线程异常会写入 `logs/crash.log`。
- 移除旧的本地「个人授权（Personal.license）」体系，激活统一由产品密钥 / 授权密钥承担。

### 三、安全增强

- 服务器响应签名校验：校验响应头中的签名与密钥 ID，含时间偏差窗口，验签失败即拒绝该响应。
- 请求防重放：每次请求携带时间戳与一次性随机数，避免合法请求被截获后重放。
- 更新包清单（manifest）签名校验：规范化后验签，并比对版本号与基线版本。
- 撤销版本处理：自动拉取撤销列表并跳过已撤销版本，必要时提示最低安全版本。
- 防降级保护：默认阻止向低版本回退，回滚须经受控入口。
- 更新与云加密请求统一鉴权通道；鉴权失效（401 / 403）时提示并清理本地凭据。
- 长期凭据在本地加密存储。
- 对密钥、种子等敏感字符串做混淆处理，降低被静态提取的风险。

### 四、漏洞修复

- 修复以管理员权限运行时，MOD / DLC 管理界面的拖放（DnD）安装完全失效的问题（RCVE-26.9-26.9-001，自 26.5-snapshot-26W20E 起存在）。
- 修复专业版密钥激活后，菜单栏中受权限控制的功能入口仍为禁用、不随权限等级刷新的问题（RCVE-26.9-26.9-002，自 26.7 起存在）。
- 命令行方式启动不再误触发 UAC 提权。

- 架构：64位（x64）
