企业级 Windows 进程管理 · 安全审计 · 深度系统优化

Release Control 是 ZIYIT STUDIO 专为 IT 专业人员、安全运维及高级用户打造的下一代系统进程管理套件。提供毫秒级进程监控、递归树状终止、自启项深度扫描、Hosts 分区编辑、智能进程守护等 50+ 高级特性。软件采用双服务器冗余验证机制，支持离线/在线许可证模式。

核心功能矩阵

  • 实时进程树状视图 (PID / 会话ID / 内存工作集 / 线程数 / 句柄数 / CPU 时间 / IO 读写)
  • 批量终止与递归终止进程树 (强制结束顽固进程及其所有子进程，支持白名单保护)
  • 可配置后台守护监控：自动检测并终止特定进程名，支持声音与桌面提醒，支持正则匹配
  • 开机自启动项全面管理：注册表 Run / RunOnce / 启动目录 / 计划任务 / 服务项 / Winlogon
  • Hosts 文件可视化分区编辑器 (支持锁定关键分区，防止恶意篡改及权限重置，一键还原)
  • 全局本地化语言架构 (内置 110+ 语言显示名称，动态切换无需重启，支持自定义翻译)
  • 开发者调试面板：实时日志流 (Debug/Info/Warning/Error/Fatal)，强制保存日志，模拟各级日志输出
  • 许可证双重校验 (在线+离线)，剩余有效期精确到秒，支持服务器冗余切换，防篡改加密存储
  • 多源更新引擎 (主服务器+备用服务器+GitHub镜像)，自动检测新版本并显示详细更新日志(Markdown渲染)
  • 系统托盘集成 (最小化至托盘、开机自启后隐藏主窗口、一键唤醒、自定义快捷键)
  • 进程详细信息弹窗：包含模块列表、环境变量、父进程关系、性能趋势图、网络连接状态
  • 软件/硬件环境检测：自动识别虚拟机环境、沙箱检测、反调试技术 (增强反分析能力)
  • 进程性能实时图表：CPU 占用率历史曲线、内存占用曲线、IO 速率监控
  • 进程依赖分析：查看进程加载的 DLL 模块、数字签名验证、文件属性详情
  • 系统服务管理器：查看/启动/停止 Windows 服务，支持服务依赖关系展示
  • 网络连接监控：查看进程对应的 TCP/UDP 连接、端口占用、远程地址

产品详细介绍

Release Control 是一款面向专业用户、系统管理员、安全运维人员以及企业IT部门的下一代 Windows 系统进程管理与深度优化工具。与 Windows 操作系统自带的任务管理器不同，Release Control 提供了更深层次的系统访问能力、更丰富的进程信息维度以及更灵活的自动化管理策略。软件从底层采用 psutil 和 pywin32 双引擎驱动，能够绕过部分系统限制，获取被常规工具隐藏或限制访问的进程信息。

1. 进程监控与详细信息展示

在进程监控方面，Release Control 实现了毫秒级的刷新频率，用户可自定义监控间隔（最低 0.1 秒，最高 60 秒）。进程列表支持多种数据维度的实时展示：进程 ID (PID)、进程名称、CPU 占用率（百分比）、内存占用（MB）、进程状态（运行中/挂起/停止/僵尸）、启动时间、运行时长等。

进程列表支持强大的过滤和搜索功能：用户可按进程名搜索、按翻译后的中文名搜索、按 PID 精确搜索。排序方面，支持按 PID（升序/降序）、按进程名（字母顺序）、按 CPU 利用率（高低）、按内存利用率（高低）、按启动时间（先后）等多种排序方式，点击列标题即可切换排序方向，上方会显示 ↑ 或 ↓ 箭头指示当前排序状态。

2. 进程终止与进程树管理

进程终止功能是 Release Control 的核心优势之一。除了常规的单进程终止外，软件支持递归终止进程树——即当用户终止一个父进程时，系统会自动递归扫描并终止该进程的所有子进程、孙进程及更深层级的后代进程。这一功能对于清理恶意软件簇、彻底结束游戏反作弊系统残留进程、终止臃肿软件套件的所有相关进程等场景极为有用。

同时，软件内置了进程保护白名单机制。用户可以将关键系统进程（如 csrss.exe、winlogon.exe、lsass.exe、services.exe、svchost.exe 等）加入保护列表，当尝试终止这些进程时，软件会弹出二次确认警告，防止误操作导致系统蓝屏或崩溃。白名单支持通配符（如 *.exe）和正则表达式匹配。

3. 后台守护监控模式

后台守护监控模式是 Release Control 区别于同类产品的重要杀手级特性。用户可配置一个或多个进程名称（支持通配符 * 和正则表达式匹配），软件将在后台持续扫描系统进程列表（扫描间隔可自定义，最低 0.5 秒，最高 3600 秒）。一旦检测到目标进程出现，立即执行用户预设的动作序列，包括但不限于：

  • 终止该进程
  • 递归终止该进程的完整进程树
  • 记录日志到日志文件
  • 发送 Windows 桌面通知
  • 播放系统提示音效
  • 执行外部脚本或程序

这一功能可广泛应用于：网吧环境下的游戏进程管理（自动查杀破解工具）、企业内禁止运行某些娱乐软件（如游戏、视频客户端）、家长控制未成年人运行特定程序、服务器进程保活（自动重启挂掉的进程）等场景。监控统计信息会实时显示每个进程被查杀的次数，方便用户评估监控效果。

4. 开机自启动项全面管理

开机自启动项管理模块提供了对 Windows 系统所有自启动位置的全面覆盖，包括但不限于以下位置：

  • 当前用户注册表 Run 项（HKCU\Software\Microsoft\Windows\CurrentVersion\Run）
  • 本地机器注册表 Run 项（HKLM\Software\Microsoft\Windows\CurrentVersion\Run）
  • RunOnce 项（一次性启动，下次开机自动删除）
  • 用户启动目录（%USERPROFILE%\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup）
  • 公共启动目录（%PROGRAMDATA%\Microsoft\Windows\Start Menu\Programs\StartUp）
  • 计划任务（所有与登录/启动相关的计划任务）
  • Windows 服务（设置为自动启动的服务项）
  • Winlogon Shell 项
  • AppInit_DLLs（全局 DLL 注入点）
  • 启动文件夹快捷方式

每个自启动项均可独立启用/禁用/删除，软件还会对可疑的自启动项进行风险提示（如：无数字签名、文件路径指向临时目录、文件本体已不存在等），帮助用户识别潜在的恶意软件或流氓软件。

5. Hosts 文件分区编辑器

Hosts 文件编辑器采用了创新的分区管理模式。用户可以将 Hosts 文件中的域名解析记录划分为多个逻辑分区，例如：

  • 系统默认分区（Windows 系统自带规则）
  • 广告屏蔽分区（自定义的广告域名屏蔽列表）
  • 开发测试分区（本地开发环境域名映射）
  • 内网解析分区（公司内网域名解析）
  • 家长控制分区（屏蔽不良网站）

每个分区可以单独锁定，防止被其他程序或用户意外修改。这种设计使得多用户协作或多人管理同一台设备时，可以各自维护自己的分区而不会互相干扰。软件还提供了 Hosts 文件的实时备份与一键还原功能，即使发生误操作也可快速恢复到之前的状态。对于需要批量添加大量域名解析的场景，支持从文本文件导入记录，也支持导出当前配置到文件进行跨设备迁移。

6. 许可证与授权管理系统

许可证与授权管理系统是 Release Control 的安全基石，采用RSA + AES 双重加密技术保护用户授权信息。软件启动后会首先检查本地是否存在 license 文件，若不存在则弹出激活窗口要求用户输入用户名和产品密钥。

产品密钥通过 MD5 哈希 + Base64 编码进行加密传输，服务器端存储的是哈希值而非明文，即使服务器配置文件泄露也无法逆向获得用户原始密钥。软件支持两种授权模式：

  • 在线验证模式：每次启动时连接 RCL 验证服务器，实时校验密钥有效性和剩余天数
  • 离线模式：当服务器不可达时（网络故障、服务器维护等），自动切换到离线模式，使用本地缓存的许可证信息继续运行

授权信息中包含用户名、加密密钥、授权天数、注册时间戳，通过计算已使用天数来判定是否过期。当授权剩余天数小于 3 天时，软件会在启动时提醒用户及时续期；当授权过期时，软件将拒绝启动并引导用户进入重新激活流程。整个授权验证过程全程加密传输，有效防止中间人攻击和本地文件篡改。

7. 更新检测机制

更新检测机制采用了多服务器冗余架构，确保即使主服务器出现故障也能正常检测更新。主服务器地址为 https://ziyit-hacker.github.io，备用服务器地址为 https://github.com/ziyit-Hacker/Update。

软件启动后会在后台线程中静默检测最新版本，通过读取服务器上的 Update.inf 文件获取最新版本号，并与当前版本进行比较。检测逻辑支持正式版与快照版的版本号智能比较（按数字大小和周次排序）。若发现新版本，弹出更新对话框并以 Markdown 格式渲染显示详细的更新日志（包含新功能列表、Bug 修复说明、已知问题等）。用户可选择立即下载（打开浏览器跳转到下载页面）或稍后提醒。更新检测支持手动触发（通过菜单栏“检查更新”按钮）和自动检测（可配置开关）两种方式。

8. 日志系统

日志系统是软件可维护性的重要保障。Release Control 支持五级日志输出：

  • DEBUG：详细的调试信息，用于开发者和高级用户排查问题
  • INFO：常规运行信息，记录程序正常操作流程
  • WARNING：警告级别，表示潜在问题但不影响核心功能
  • ERROR：错误级别，表示功能执行失败但程序可继续运行
  • FUCK：致命错误级别，触发后程序会立即闪退并保存崩溃现场日志

用户可以在设置中灵活配置需要记录的日志级别。日志文件默认存储在软件目录下的 logs 文件夹中，文件命名格式为 RC-logs-Part{序号}.log，每个日志文件的大小上限可配置（默认 1 GiB），超出上限后自动轮转创建新的日志文件。日志写入模式支持两种：缓冲模式（内存中缓存日志，达到 150 条或达到时间间隔后再批量写入磁盘，IO 性能更优）和实时模式（每条日志立即写入磁盘，便于实时监控）。开发者模式下，用户可以通过调试面板实时查看日志流、强制保存当前日志缓冲区、清除日志缓冲区、以及模拟生成各级别测试日志。

9. 多语言支持

多语言支持是 Release Control 面向全球用户的重要特性。软件内置了全球主要语言的支持，包括但不限于：中文简体、中文繁体（台湾/香港）、英语（美国/英国/澳大利亚/加拿大/印度等变体）、日语、韩语、德语、法语、西班牙语（西班牙/墨西哥/阿根廷等）、葡萄牙语（葡萄牙/巴西）、俄语、阿拉伯语（多个国家变体）、印地语、意大利语、荷兰语、波兰语、土耳其语、越南语、泰语等。

用户可以通过设置菜单中的语言选择对话框实时切换界面语言，无需重启软件即可生效。软件还支持自定义翻译，高级用户可以修改语言 JSON 文件来适配自己的偏好或补充缺失的翻译条目。

10. 开发者调试模式

开发者调试模式为软件测试和问题排查提供了强大工具。开启开发者模式需要输入 ZIYIT 官网管理员凭证进行身份验证，防止普通用户误入。

进入开发者模式后，用户可以通过独立的调试面板实时查看系统运行状态：

  • 当前系统总进程数
  • 系统内存使用率（已用/总计，百分比）
  • CPU 使用率（百分比）
  • 日志缓冲区当前大小（条数）

调试面板中还提供了多个测试功能按钮：强制保存日志（立即将缓冲区中的日志写入磁盘）、清除日志缓冲区、生成 DEBUG 级别测试日志、生成 INFO 级别测试日志、生成 WARNING 级别测试日志、生成 ERROR 级别测试日志、模拟 FUCK 级别致命错误退出。这些功能极大地方便了开发者在不同场景下验证软件的行为和日志系统的正确性。

11. 系统托盘集成

系统托盘集成大幅提升了软件的使用体验和便捷性。用户可以在设置中配置以下行为：

  • 关闭按钮行为：点击窗口关闭按钮时是直接退出程序，还是最小化到系统托盘
  • 开机自启行为：开机自启动时是正常显示主窗口，还是自动隐藏到系统托盘

托盘图标支持右键菜单，包含：显示主窗口、退出程序、重启软件、检查更新、卸载产品密钥等常用选项。软件最小化到托盘后，后台守护监控模式仍然继续生效，不会因为窗口隐藏而停止工作。

12. 性能优化

性能优化方面，Release Control 采用了多线程异步处理架构。进程列表刷新、图标加载、日志写入、网络请求等耗时操作均在后台线程中执行，确保主界面 UI 始终保持流畅响应，不会出现卡顿或假死现象。

进程图标缓存机制避免了重复提取相同进程的图标造成的性能损耗。树形控件的虚拟滚动技术使得即使系统中有上千个进程时也能保持平滑滚动。软件启动速度经过深度优化，通过将日志写入改为异步队列 + 批量写入模式，启动时间从最初的 8 秒大幅降低至 2 秒以内（在良好网络环境下）。

13. 安全性防护

安全性方面，软件采取了多项防护措施：

  • 反调试技术：通过检测开发者工具（F12）、右键菜单屏蔽、控制台劫持等方式防止恶意用户通过浏览器调试器破解软件或绕过授权验证
  • 产品密钥加密保护：密钥通过 MD5 哈希后 Base64 编码传输，服务器端存储的是哈希值而非明文，即使服务器配置文件泄露也无法逆向获得用户原始密钥
  • 日志自动脱敏：在记录日志时会自动过滤可能包含敏感信息的字段（如完整路径中的用户名、IP 地址等）
  • 防内存提取：软件在运行时会对关键数据结构（如许可证信息、解密后的密钥等）进行加密存储，防止通过内存 dump 方式提取敏感数据
  • 通信加密：所有网络请求均强制使用 TLS 1.2+ 加密传输

14. 版本发布策略

软件发布采用双通道策略：

  • 正式版（Stable）：经过完整的测试周期和兼容性验证，稳定性高，经过充分的内测和公测，适合生产环境部署和企业使用
  • 快照版（Snapshot）：基于最新代码自动构建，包含最新的功能特性和 Bug 修复，但可能包含未充分测试的代码，适合开发者和测试人员抢先体验新功能

每个发布版本都提供 SHA256 哈希值供用户校验文件完整性，防止下载过程中文件被恶意篡改或损坏。用户可使用 Windows 自带的 certutil 命令或第三方工具进行校验。

常见问题解答 (FAQ)

1. Release Control 是什么？主要功能有哪些？

Release Control 是一款专业的 Windows 系统进程管理工具，主要功能包括：进程实时监控与终止、递归终止进程树、后台守护监控（自动查杀指定进程）、开机自启动项全面管理、Hosts 文件分区编辑器、进程搜索（支持PID/进程名/翻译名）、进程列表排序（PID/CPU/内存/启动时间）、多语言支持、许可证验证、系统托盘集成、开发者调试模式等。

2. 软件是否需要管理员权限运行？

推荐以管理员身份运行 Release Control，以获得完整的进程信息和系统访问权限。在管理员模式下，您可以终止任何进程、修改 Hosts 文件、编辑开机自启动项等。如果以普通用户模式运行，则只能查看进程信息，无法执行终止操作或修改系统配置。软件会在启动时自动检测权限并给出提示。

3. 如何获取产品密钥？

您可以通过官方渠道联系 ZIYIT STUDIO 获取产品密钥。软件激活时，在激活窗口中输入用户名和产品密钥即可完成激活。每个产品密钥仅限单用户使用，禁止共享。B站会不定期发布福利密钥，请关注官方账号获取最新消息。

4. 试用期是多久？过期后怎么办？

软件支持多种授权模式：30天试用授权、1年商业授权等。当授权剩余天数小于3天时，软件会在启动时提醒用户续期；当授权过期后，软件将拒绝启动并引导用户进入重新激活流程，输入新的产品密钥即可继续使用。

5. 软件是否支持离线使用？

支持。Release Control 采用双重验证机制：在线验证和离线模式。当软件无法连接到验证服务器时（如网络故障或服务器维护），会自动切换到离线模式，使用本地缓存的许可证信息继续运行。离线模式下，软件的核心功能（进程管理、监控、自启动项管理等）均可正常使用。

6. 后台守护监控模式是什么？如何使用？

守护监控模式是软件的特色功能，用户可配置一个或多个进程名称（支持通配符和正则表达式），软件将在后台持续扫描系统进程列表，一旦检测到目标进程出现，立即执行用户预设的动作（终止进程、终止进程树、记录日志、发送桌面通知、播放声音提示等）。监控间隔可自定义（最低0.5秒），广泛应用于网吧游戏管理、企业软件管控、家长控制等场景。

7. 如何搜索进程？支持哪些搜索方式？

软件支持三种搜索方式：按进程名搜索、按翻译后的中文名搜索、按PID精确搜索。搜索结果会实时显示在进程列表中。搜索历史会自动保存，方便下次快速调用。快捷键 Ctrl+F 可快速定位到搜索框。

8. 进程列表支持哪些排序方式？

进程列表支持多种排序方式：按PID（升序/降序）、按进程名（字母顺序）、按CPU利用率（高低）、按内存利用率（高低）、按启动时间（先后）。点击列标题即可切换排序方向，列标题上方会显示 ↑ 或 ↓ 箭头指示当前排序状态。默认按PID升序排列。

9. 什么是递归终止进程树？

递归终止进程树是指当用户终止一个父进程时，系统会自动递归扫描并终止该进程的所有子进程、孙进程及更深层级的后代进程。这一功能对于清理恶意软件簇、彻底结束游戏反作弊系统残留进程、终止臃肿软件套件的所有相关进程等场景极为有用。

10. 白名单功能有什么用？

白名单功能可以保护关键系统进程不被误终止。用户可以将重要进程（如 csrss.exe、winlogon.exe、lsass.exe、svchost.exe 等）加入白名单，当尝试终止这些进程时，软件会弹出二次确认警告，防止误操作导致系统蓝屏或崩溃。白名单支持通配符和正则表达式匹配。

11. 软件支持哪些语言？

Release Control 内置了全球主要语言的支持，包括中文简体、中文繁体、英语、日语、韩语、德语、法语、西班牙语、葡萄牙语、俄语、阿拉伯语、印地语、意大利语、荷兰语、波兰语、土耳其语、越南语、泰语等110多种语言变体。用户可以通过设置菜单中的语言选择对话框实时切换界面语言，无需重启软件。

12. 如何查看进程的详细信息？

双击进程列表中的任意一行（除选择列和进程名列外），即可弹出进程详细信息窗口，显示包括：进程ID、进程名称、中文名称、进程状态、CPU使用率、内存占用、启动时间等。双击进程名列可以快速复制进程的原始文件名到剪贴板。

13. 如何校验下载文件的完整性？

每个发布版本都提供了 SHA256 哈希值，您可以使用以下方法校验：1) 使用 Windows 自带的 certutil 命令：certutil -hashfile 文件名 SHA256；2) 使用 PowerShell 命令：Get-FileHash 文件名 -Algorithm SHA256；3) 使用第三方工具如 HashTab、7-Zip 等。下载后请务必比对官方提供的 SHA256 值，确保文件未被篡改。

14. 正式版和快照版有什么区别？

正式版经过完整的测试周期和兼容性验证，稳定性高，适合生产环境和企业部署。快照版基于最新代码自动构建，包含最新的功能特性和 Bug 修复，但可能包含未充分测试的代码，适合开发者和测试人员抢先体验新功能。建议普通用户选择正式版，开发者和测试人员可以选择快照版。

15. 软件被杀毒软件误报怎么办？

Release Control 采用了反调试技术和进程深度访问机制，部分杀毒软件可能会误报为潜在风险，这是正常现象，软件本身不含任何恶意代码。建议您：1) 将 Release Control 添加到杀毒软件的信任列表/排除列表；2) 从官方网站下载以确保文件来源可信；3) 比对 SHA256 哈希值验证文件完整性。如有误报请及时向我们反馈。

16. 如何配置开机自启动？

您可以通过以下两种方式配置开机自启动：1) 在软件设置中勾选“开机自启动”选项，软件会自动在启动目录创建快捷方式；2) 使用内置的自启动项管理器，可以更精细地管理所有开机启动项（包括注册表、启动目录、计划任务、Windows服务等）。配置后，您还可以选择开机自启后是否自动隐藏到系统托盘。

17. Hosts文件分区编辑器有什么作用？

Hosts文件编辑器采用分区管理模式，用户可以将域名解析记录划分为多个逻辑分区（如广告屏蔽分区、开发测试分区、内网解析分区等），每个分区可以单独锁定，防止被其他程序或用户意外修改。软件还提供实时备份与一键还原功能，支持从文本文件导入记录和导出配置。

18. 系统托盘有什么功能？

用户可以选择将软件最小化到系统托盘而不是关闭，软件会在后台继续运行（守护监控模式仍然生效）。托盘图标支持右键菜单，包含：显示主窗口、退出程序、重启软件、检查更新、卸载产品密钥等选项。用户可以在设置中配置关闭按钮的行为（退出或最小化到托盘）以及开机自启后是否自动隐藏到托盘。
