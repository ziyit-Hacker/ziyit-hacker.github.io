翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;

--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;

}
[[/module]]

一张洞穴入口的照片，拍摄于2014年底。

Level 474是一个相对安全和无害的层级，目前没有已知的出口。它就像是一片被森林所围绕的空地，其中包含着一个巨大的洞穴。

描述

Level 474是一片被浓密的，看似无限的森林所围绕的空地。在空地之中，可以找到一个洞穴的入口。该层级的积雪永不融化，日夜交换的规律与前厅类似，白天持续9个小时，黑夜持续15个小时。

Level 474有三个主要的特征。空地、森林和洞穴。

空地

这是一片面积较小，且较为平坦的林中空地。它的长度大约只有0.2千米。生长着小型的灌木和苔藓。不存在任何的实体。

在差不多是空地中心的地方有着一个大公告板（如图所示）。有一张海报被图钉定在了公告板上。海报上用白色的巨大的英文字母写着“欢迎来到474号国家公园”。除此之外，公告板上还贴着一张包含着空地和周围森林的地图。这张地图后来被发现与该层级的真实尺寸不符。

在公告牌上，还有一张写着WiFi的名字和密码的白纸。网络的名称是“NP474”，而密码是“CaveDivingRules!!2”。这个WIFI的网速很慢，且只能在空地上使用，但通过它可以与层级之外的人进行交流。

森林

据推测，空地周围的森林是无限的。树木的种类和总体布局与前厅中美国俄勒冈州的部分树木的情况一致。它也包含有灌木、岩石和苔藓。森林里的大多数灌木所生长的浆果类似于在前厅中的蓝莓和木莓。该地区的苔藓似乎是这个层级的原生物种，因为在其他的地方没有发现这种苔藓。该地区的地形一般平坦而光滑，地面被积雪覆盖。由于它的面积巨大，目前它尚未被勘探完全1。截至撰写文章的时候，在森林里尚未发现任何的实体。

洞穴

洞穴是位于空地之下的大片空间。洞口位于空地的中心附近（如图所示）。它由一块类似大理石的材料制成，在距离洞口几英里的地方还有一丝光线，再往里的地方是一片漆黑的。

在一块石头的后面有着一盏破碎的煤气灯。不知道是谁或什么生物把它留在了那里，也不知道他们发生了什么。

由于某些原因，我们尚不知道洞穴里有些什么，后文将会对此进行解释。

基地、前哨和社区

曙光Alpha基地

  • 基地人口：2（Jack Lowell和Eleanor Hutchinson）
  • 该基地并不隶属于M.E.G，然而，该基地的人员会与M.E.G进行合作，以确保他们能够生存下来，并继续探索这个相对未知的层级。
  • 该基地是一个小型的临时木屋，由死去的树木、碎木头以及泥土制成。在基地的后面有一片种植着浆果和土豆的小型农场，围绕着由树皮制成的临时篱笆。
  • 位于空地的最北边。

发现

2014年初，一个六人小队从Level 11切入到了这个层级。小队切出的地点位于M.E.G的Beta基地北边的4公里处。目前还不知道他们是如何触发切出的，想要重现切出的尝试都失败了，但小队成员Jack Lowell说：“就像是掉进了地下”。小队的成员有Sean Burgess、Nathan Cobb、Rachel Everette、Mark Snyder、Eleanor Hutchinson以及Jack Lowell。他们一起切出到了空地的北边。他们立即开始了对空地的探索、收集信息、建立与M.E.G的联系以及建立曙光Alpha基地。然而，在六个月后，他们仍然没有找到Level 474的出口。

2014年底，Sean Burgess、Nathan Cobb、Rachel Everette以及Mark Snyder决定对洞穴进行一次探险活动。此次活动被称为曙光探险1A，其目的是了解更多关于此层级的信息，以及在洞穴中寻找离开层级的方法。而这两个目的会分别通过三次旅行来达成。任务一由团队分头行动来探索洞穴，任务二由整个团队来一起在洞穴中找到一个出口。探险1A将会持续六个小时，Eleanor Hutchinson和Jack Lowell会在地面上的一个临时的控制中心来与队员进行通信。每十分钟，他们会在通讯中报告一次，以确认进展是否顺利。在第一个小时里，1A探险队继续在洞穴系统中越来越深入。Nathan Cobb进行了观察并向地面上的中心发送道：“这就像是个普通的洞穴，兄弟们”。

当第九次试图与1A探险队沟通时，他们没有得到任何答复。

在探险进行了一个半小时后，Eleanor和Jack与探险队失去了联系。他们在接下来的三个小时中尝试向探险队发送信号，但始终没有得到回应。他们决定回到曙光Alpha基地，并继续监控那里发出的信号。他们在那之后再也没有收到来自洞穴里的信号了。

入口与出口

入口

只有一个关于入口的报告，是在2014年初在Level 11出现的。

出口

截至撰写本文时，Level 474的出口仍是未知的。
