使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。

--sd-symbol:var(--sd-border)!important;/*大多数标志*/

层级描述：

Level 307是一条长达6公里（约4英里）的爬行动物与两栖动物展示长廊。该层级常年笼罩在极端潮湿的环境中，地面上遍布着泛绿的脏污水洼。当流浪者进入时，身后的入口总会诡异地变成上锁的门扉——无论原始入口的形态或位置如何。更凸显其选择性非欧几里得特性的是：当抵达终点展厅时，出口会再度异变为悬挂塑料防撞链的加宽门洞。根据事故报告推断，该层级因空间局促且危机四伏，不存在任何据点或前哨站。

实体

根据现存影像资料与事故报告，已观测到生态缸内存在诸多物种，包括但不限于：

在围栏里可见的蜥蜴。

  • 各种树蛙
  • 各种玻璃蛙
  • 各种箭毒蛙
  • 火腹蟾蜍
  • 美洲蟾蜍
  • 穴居蟾蜍
  • 红尾蚺
  • 各种蝰蛇
  • 束带蛇
  • 普通麝香龟
  • 箱龟
  • 日本石龟

该层级中的所谓“动物”实为两类实体，分别为爬行动物与两栖动物。根据现存报告及机密影像分析，这些实体均表现为非敌对状态。影像资料同时表明，层级内的展示玻璃疑似特殊塑料或具异常强度1。

终点展厅较之长廊更为开阔，陈列展品数量显著增加。此处设有特殊独立展区，饲养着鹦鹉、鹳鸟、巨嘴鸟等热带鸟类——然而其个体多呈伤残或死亡状态2。最关键的是，展厅内置有标刻未知文字的暗门，其内部封存着M.E.G.命名为“蛇怪”的实体。

蛇怪是一种类蜥蜴实体，与前厅科莫多龙最为相似，但具有若干显著差异特征。据影像资料推断，其体长约14英尺（约4.3米），通体呈现腐败肮脏状。该实体体表（尤其是额部）覆盖着块状板结油污毛发，始终有蝇群环绕飞行——这些特征暗示其虽存活却已开始腐烂。报告描述其气味如“世纪腐肉”3。观测到该实体发出河马般的咕噜声或鳄鱼般的嘶嘶声，实为捕食者特性的完美融合4。

受限于该层级数据匮乏，蛇怪的行为规律尚未明确。据现有案例记载，当任何流浪者进入其领域时，该实体总处于狩猎状态。有限数据同时表明，其移动速度会适应进入者——始终快出微小幅度。凡从此层级生还者均遭受精神崩溃与心理创伤，该实体似乎具备摧毁遭遇者心智的能力。所有幸存者迄今未能从精神损伤中恢复，其引发的创伤兼具双重特性：既呈现血腥场景/暴力画面等冲击性意象，亦会植入受害者原未罹患的抑郁、焦虑等病症。此类损伤目前呈现不可逆转性，需接受潜在终生治疗。5

入口与出口：

如前所述，离开该层级的唯一方法是沿进入路径原路返回，回到初始进入的层级。

入口：

  • 通过Level 70或Level 2中垂挂塑料防撞链的门洞可进入Level 307。
  • 进入Level 81建筑大厅的洗手间将通往Level 307。
  • 进入Level 162的黑色门有概率抵达Level 307。

Level 307勘探事故日志

于03/01/████，一名M.E.G.特工返回Level 1的Alpha基地时，其右臂严重损伤。该特工呈现定向障碍、偏执甚至病理性症状。当问及事件细节时，其声称发现了新层级。[无关细节已省略]据陈述，该层级地面始终存在湿润触感及泛绿液体（疑似污水），但行进中从未打滑——疑似层级异常效应。

该生还特工声称与另一名经核实的M.E.G.特工共同进入层级，而后者据其引述“遭怪物撕碎”。生还者陈述当其目睹同僚遇袭场景时，立即产生强烈生理性不适直至呕吐。据称当“怪物”逼近时，其手臂被撕裂，疼痛感被粗鄙描述为“如同火蚁军团钻啃血肉，并向血管注入硫酸”。

该特工表现出严重心理恐惧与创伤症状，问询期间全程可见颤抖。尽管蛇怪生理特征近似科莫多龙，其体内未检出任何毒素细菌或感染迹象。截至本档案撰写时，该特工仍在接受治疗，且未见明显好转。

报告结束。

于03/06/████（日/月/年），三名受雇探索新发现潜在层级Level 307的流浪者中仅一人返回。该生还者体表存在多处割伤及其他外伤，并呈现颤抖、偏执、定向障碍、平衡失调及其他异常症状。

Level 307勘探事故日志

我们三名流浪者受雇探索潜在的Level 307，最终只有我一个人活着回来。能四肢健全地逃出来已经算走运了——据一位M.E.G.特工说，之前有探员在那层被扯断了手臂。刚进去时就发现那里比入口处潮湿得多，地面全是积水。同伴检查后确认那些只是混着藻类的脏水。走到尽头是个特别大的展厅，里面没有蛇蛙龟那些常见动物，全是鸟类。但有些鸟已经死了，活着的也伤得很重。我们正在查看时，那东西突然从一扇小门里冲出来，直接扑倒██████把她按在地上。我和█████转头就往走廊跑，根本不敢看后面的惨状，光是余光瞥到就恶心得想吐。没过多久那东西就追上来扑倒了█████。这次我死都不敢回头看，结果它还是抓住了我。我拼了命挣扎才脱身，可能它吃掉我两个同伴后已经饱了，总之我抓住机会头也不回地逃了出来。

那股腐烂蜥蜴的恶臭至今还残存在我的鼻腔里。

报告结束。
