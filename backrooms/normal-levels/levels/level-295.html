使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。

描述

Level 295为一片荒无人烟的沃土，直径约为300km。Level 295由于其中不毛的植被而被认定处于一种永冬的状态。层级内烟雾重重，遮天蔽日，而其最为明显的特征则是其所带的亮蓝色。层级地表矗立有数座造型奇特的山丘。山丘上覆盖着颜色阴沉的灌木丛、大量树木和其他淡入了Level 295环境的密集植被。在层级内亦可时而遇见河流，河流的长度因其延伸至场景外极远之处而无法测量，更有甚者则直接极为突兀地融入了山丘之中。

Level 295内环境冰冷，温度在3°C附近波动1， 因此获取到一些能让自身在寒冷气候中存活下来的物品至关重要。然而其温度偶尔也会低至零度以下，令其不稳定的气候对穿行其中的流浪者表现出了危害性。

瘟疫

Level 295因其所具有的一项异常性质而获“瘟疫”之称。它不仅仅是一个层级，还是一种能以毫无察觉的探索者们为寄主的，使其层级外观四处流行的瘟疫。此层级将受害层级污染的具体机理未知，因为这一现象总是在有人未经警告而穿行于Level 295的过程中发生。

Level 295通过“感染”人体得以层级之间传播2。一旦受害者被感染，他们便会开始执着于同一目标：离开此层级，并污染其他未经感染的层级和地区3。在流浪者离开此层级的一刻，他们便会将其触碰到的地貌和表面污染。一旦因寄主触碰了某个表面而开始了传播过程，Level 295便会开始进行扩张并将其周边材质逐渐取代4， 而要完成转化则需花上大量时间。具备感染能力的表面外观上通常表现为土壤，触感冰冷，这一土壤将导致植被的过度生长，因而使大片沃土之上生长出极度密集的植被。被污染的区域则将会出现蓝色浓霾，与其父层级相似。

想要遏制Level 295的传播十分艰难，因为找到被感染区域的难度很大，而具备大量放热能力的物品则尚可被用于轻松根除被污染的地面，同时也能缓慢修复被Level 295污染的区域。5在已知其在受热方面的明显弱点的情况下，任何对污染区的目击都将被迅速上报到附近的M.E.G.前哨站以阻止Level 295的进一步蔓延，因其不宜居性质的存在，在受污染空间内长期居住是不安全的。最常用的复原表面法是利用火盐来根除污染区，从远处投掷火盐以阻止其进一步传播。亦可使用滋水枪将可燃性液体喷射在感染区上并随后燃料点燃。

时至今日，Level 295与其污染区在比邻M.E.G.前哨的支持下与严禁进入Level 295的禁令颁布后已停止蔓延。而这一事实也说明了Level 295的传染已经接近停止，这也让在避免刺激Level 295复生的情况下建立社区一事成为可能。

基地、前哨和社区

Level 295内原先存在许多前哨，但在发现此层级的危害性质后前哨的数量已大量减少。严禁任何人在此层级内建立社区，以防他们在无意间成为寄主群。
