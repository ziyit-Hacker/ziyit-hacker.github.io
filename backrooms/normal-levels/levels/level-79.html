翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

--sd-border:90,29,27;
--sd-image:90,29,27;

}

描述：

Level 79的主廊道。

Level 79由7个疑似为智能设计1的房间组成。测定大小约为370平方米2，该层级能令人忆及20世纪中叶的医药研究所，且内含各种与其相关的器械。其空间展现出了大量前人使用过的迹象，理论上该层级自身就是人类规划及（或是）建造的直接成果。

各个房间的相关信息可在下方找到：

  • 1号房间（R）
  • 2号房间（L）
  • 3号房间（R）
  • 4号房间（L）
  • 5号房间（R）
  • 6号房间（L）
  • 7号房间（C）

办公室。

首个位于主廊道右侧的房间3表观上曾被用作一处办公空间。此外还有一处倚墙置物架，该区域内含一张桌子与一些文件柜。这些物品被随意地摆放在一个储物橱中，且遭受过严重的火灾损伤。此房间中的墙壁之一上挂有一面大型黑板。如下表述被用黄色粉笔写在了板面之上：

“实验仅是取得了些许成果；切勿长此停留。不管怎样我们将移步至第二阶段，我随后便来见你。——Dr. Zohn”

器械储藏室。

第二个房间，位于主廊道的左侧4，则被用作一个各色医疗及科研物件的储藏室。以下是在该房间内找到的值得注意的器械的清单：

• 心肺监测仪5

• 肾透析仪6

• 超声仪7

• 心电图（ElectroCardioGram，ECG）仪8

• 呼吸机9

• 固定角离心机10

除了标准的医疗器械外，还发现了4台用途未知的机器。这些设备虽尚未被完全理解，却显得比在此房间内找到的其他器械先进许多。

检查室。

此区域被设计为一个标准的医疗检查室。在全房间随处可见的许多橱柜与抽屉内则发现了通常与本房间性质之适用场合相关的医疗器械。在右侧有一台功能未知的大型机器嵌入墙中。这一怪异的机器有着盘曲的软管、静脉注射管以及放在低处隔仓的电线。各种药品以及平常或是异常的物质则被贮藏在房间左侧一个上锁的橱柜内。已知成分包括但不限于：

• 杏仁水

• 杜冷丁11

• 硫唑嘌呤12

• 麦角酸酰二乙胺13

• 阿霉素14

• 知茶

• 东莨菪碱15

• 边沿含褪黑素的彩色棒棒糖

4号房间内发现的X光机。

4号房间内有一台世纪中叶的X光机，以及与放射科相关的器材和修饰物。后方前面上一台大型底检片器，通常以X光映光器之名示人，其中存留着一张X光片。在该X光片上的是一支严重损毁的人类手臂的放射影像16。根据对手部位置骨骼的分析进行估计，该个体的年龄大致在6至10岁之间。

生活区。

一个内有排列在金属床架上的6张单人床垫的小型房间。房间内的两个梳妆台内在最初发现时含有如下物件：

• 6套淡灰色衬衫与长裤，童装小码。

• 一只红色橡胶手球。

• 3支黑色蜡笔。

• 14张空白横格纸。

手术室。

第六个房间为一内有一硕大无朋的内脏与其他不明流体堆积的空手术室。在这些浆体中观察到了金属碎屑、螺钉与各种其他小型无机物件。分析揭示其中存在6名独立个体的DNA。

机器。

廊道末端的最后一个房间内有一构成与作用不明的机械。尽管其用途不明，但该机器的前端面共有16面钟，每一面都显示着各异的时间17。该层级的两份第一手报告都称该机器发出了一种与抽泣声相似的扭曲电噪声。每隔约30分钟该机器将发出一次响亮的敲击声，伴有一阵全层级可感的颤动。观察者将经受一种类似切行的感觉。 一种与在6号房间内发现的物质相同的东西则被观察到在从该机器的左侧缓缓泄出。

入口与出口

Level 79仅有一个已知的入口与出口，即位于其主廊道的开端，该地点理论上会在长度未知的一段时间内出现在任何层级的任意门中18。
