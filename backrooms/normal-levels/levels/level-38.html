翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

Level 38中某个同时具备Level 4、Level 5、Level 6和Level 9特征的地点。

绝大多数在Level 38内拍摄的照片被带出本层后所呈现的图像。

Level 38是后室的第三十九层。它是从Level 0到Level 37之间全部层级的集合体。

描述：

Level 38是Level 38之上所有常规层级的集合，它被认为是从Level 0到Level 37的所有层级相互叠加的交点。存在这种重叠是因为后室的各个层级不具有规则的确定结构，这意味着当各个层级相互折叠以创建出入口时，这些层级的某些部分最终会重合并存在于一个联接区域内。

除了具备之前三十八个层级的所有物理属性外，Level 38还拥有一些与之前三十八个层级相同的特殊效应，其中包括Level 6中所发现的完全黑暗，Level 28中的风暴石1，以及深入Level 33时可发现的腐化现象。

Level 38由两个区域组成。这两个区域之间的界限并不固定，实际上在Level 38中也存在着区域之间的混合过渡部分。在这里进行说明的区域分别被称作里界和表界。

里界：

里界是一个统称，指的是任何不处于天空盒内的区域内的地点2。这些区域是Level 38中最常见的区域，同时也很可能是流浪者在这里探索时抵达的第一个区域。由于Level 12的信息屏蔽效应会延续到Level 38，所以尝试拍摄这些区域并留下影像资料是近乎不可能的。到目前为止，只有两张在Level 38内拍摄的图片没有被损坏或扭曲。

尽管层级之间的交错看似随机，但我们还是发现了层级间的合并规律以及层级的某些部分融入最终的几何结构的方式，如下所示：

表界：

表界是指Level 38中处于室外的任何区域。这些区域不太常见，因为Level 0和Level 37之间的室外层级较少。尽管如此，各层级之间拼接和碰撞的关联方式已经被确认和记录。

  • 表界的地面通常会被小麦所覆盖，就像Level 10的麦田一样。

  • 在Level 35中看到的车辆同样可以在Level 38中看到。

基地，前哨和社区：

B.N.T.G. “行商”前哨站

当Level 38最初被发现时，B.N.T.G.试图建立并维持一个前哨站。它的建立目的是提供杏仁水和其他补给（如孪生指3等）给意外到达此层的流浪者。然而，“行商”最终被废弃了。这是由于Level 38的不稳定性，以及实体的持续进攻。

入口与出口：

入口：

通过在Level 0到Level 37之间的任意层级游荡即可进入Level 38。前进时，流浪者可能会注意到景观的变化，周围的事物更加混乱，通常充满了与总体环境不协调的矛盾事物与奇怪穿插。不过，在这样做时，也有可能会抵达Level 263。

出口：

离开Level 38与进入这一层的方式实际上是相同的。在穿越本层的过程中，流浪者可能会注意到周围环境开始发生变化并逐渐呈现出稳定的形式。根据所在Level 38的区域不同，最终离开时到达的层级也会有所不同。如果在表界，流浪者将退出到天空盒下存在的某个层级。如果在里界，流浪者将进入由任意数量的房间所组成的任意层级。

或者，如果流浪者能够攀爬位于表界的过山车轨道或直接乘坐过山车，有一定概率可切入天空盒以前往蓝色通道。
