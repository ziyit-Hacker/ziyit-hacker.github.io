翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

Level 16的景色

Level 16是后室的第17层。该层级看起来是一个雾气蒙蒙的雨林生态环境。此层级于近期被首次发现，因此关于此层级的信息很有限...？

描述

Level 16是一个与后室之外的雨林别无二致的茂密雨林系统。唯一的显著差别就是此层级内部的重力相比于基准现实来说非常微弱。当前尚未知晓此种现象背后的成因。

此层级似乎不存在昼夜循环，且一直处于黎明状态。此层级的温度持续保持在21摄氏度（70华氏度），尽管其内存在大量无法被阳光照射的遮荫区域。其内部的微弱重力只会对Level 16以外出现的生物和物品造成影响，而对此层级的本地生物不会造成影响。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

恢复到的Level 16的图像数据

Level 16是后室的第17层。此层级拥有着不断改变的地形，每隔一段未知时间就会改变自身。因为它的属性随着每次环境变化而改变，因此很难对此层级加以研究。

描述

Level 16的当前状态正处于一段冰河期，与基准现实的冰河期一致。但一个显著的区别是此地区存在的冰块拥有着具有较高反射率的反光表面。

此层级也拥有昼夜循环，大约每13小时循环一次。其昼夜温度分布在6摄氏度（43华氏度）到10摄氏度（50华氏度）的区间内。

此层级内的实体很稀少，但仍可被观察到。可以在此观察到大量的微光向导。这是一个不同寻常的现象，因为这些实体非常罕见，且从未观察到集体行动。 由于此层级会很快改变其地形，因此不太可能对此现象进行深入调查分析。

...当这个层级发生转变时，层级密钥也随之转变。我们已经来过这里好几次了，但它看起来完全不同，所以我们从来没有注意到。

基地、前哨和社区

因为此层级不稳定的自然环境，因此此层级不适合人类生存。出于此种原因，此层级内也没有建立任何常驻基地。

当环境开始改变时不要待在这里。冰川会从地面拔地而起，高耸入云。河流会突然开始从巨石中喷涌而出。四周会开始结冰，空气随之变得寒冷。小型的球状物会开始围绕在我们身边，就像是警告一样。如果你不小心，你就可能陷入到不断变化的地形中去。
我成功地逃了出来，仅仅受了点冻伤和擦伤。其他人就没那么幸运了。

入口和出口

入口

在level-75中找到一个橙色的镓补丁，接触它就会把你带到这里。还有其他几个所谓的入口，但这是截至编写本报告时唯一得到确认的入口。

出口

在每次地形改变后，出口的位置都不同，但目的地是不变的。在此层级目前的状态下，找到一个覆盖有沙子的冰层，站到上面就会把你带到Level 46。

注意：

一旦Level 16的当前状态发生变化，以前的文件应予以归档，以防止对当前状态地形的混淆。归档条目中的信息可能不再包含准确的描述，不应该在实际生存环境中参考。

真希望我们在进入之前就知道这一点。我们走进了雨林，走出来时却变成了一片冻土。
