翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

Level 93的第一张图片。

Level 93是后室的第94个正数层级，由一支最初来自Level 3的M.E.G.搜寻队于████年██月██日发现。

描述：

Level 93表现为一座似无底部的大山，外观与喜马拉雅山中的珠穆朗玛峰相近。倘若Level 93确有底部，则其尚未被看见或记录。

实体

所有在后室中已发现的实体都意外丧生在了Level 93。实体在Level 93中唯一的痕迹便是其埋入雪中的冻尸。没有物理形态的实体（笑魇、灌篮崽之类）也不会在Level 93中生成。

『如果一个层级连想把你弄死的实体都杀掉了，你就得知道自己要有好果子吃了。』
——匿名Reddit用户

异常性质：

构成成分：

Level 93的构成成分十分单一，仅含有：冰、雪、钠、碳、低含量的铁、汞、砷和铋，以及偶尔出现的石英。因此，攀登或是探索Level 93相当的危险，因为滑坡和雪崩的可能性极大。建议探索Level 93时备好防护装备。

冰川：

冰川是Level 93中最常被观测到的特征。

Level 93的冰川由冰、雪、干冰、钨、铷、低含量的铁、石英、丙酮、水和汞组成，偶尔还有碳。

Level 93的冰川似乎并不遵循已确认的物理法则。在Level 93所能发现的冰川已被观察到：刮蹭Level 93，不断增大与缩小，吞没Level 93的地区，以及完全固化。

其他特征：

Level 93还具有许多其他异常特征。（有些尚未被证实）

树木 - 已确认

Level 93的树只能在Level 93一开始的天气阶段，于超过1█ m2，低于10度的平坦地带发现。Level 93能遇到的树种包括：银桦，红栎，亚马逊玫瑰木，白云杉及其他。这些树木本无法在类似Level 93的气候中生存，但却以一种未知的方式于Level 93内繁荣生长着。

地震活动 - 已确认

Level 93的山顶有1/30000的几率自动爆发，然而，这个几率会随停留在Level 93的时间增加以指数形式增长。在爆发过程中，观察到了这些事件：

  • 少于1秒：爆发发生。顶峰被摧毁。浓烟自与爆发有关的顶峰中喷薄而出。
  • ~50秒：碎片开始落至地面。
  • 1-3分钟：岩浆开始自山上涌下，速度越来越快。
  • 3+分钟：浓烟停止喷出。

Level 93中的岩浆流动速率似乎是常规现实与其他层级的1.9倍。

湖泊 - 已证伪

由u/Yttrium于2022年宣称。湖泊应该是Level 93中最难发现的地形。湖泊大致能在大于14█ m2的平坦地面上找到。

帐篷 - 已确认

Level 93的帐篷通常会显现在任何平坦区域，无论其面积多大，距顶峰多远。帐篷表现为可携带的红/黄色帐篷。Level 93中的所有帐篷通常都是猎犬与悲尸的生成点。实体有30%的概率在帐篷内生成。

由于此现象，务必不要进入Level 93的任何帐篷。

发现：

Level 93由一支探索Level 8深度时的M.E.G.搜寻小队所发现。以下是Gamma基地与09搜寻队间的归档联络：

归档文件：L93发现记录

09搜寻队-3：能听到吗？能听到吗？

Gamma基地-34：是的，我们能接听到。

09搜寻队-3：Level 8在实体方面没什么尤为特殊的。

Gamma基地-34：好的，那么……行吧，请你们自行返回基地。

09搜寻队以未知的方式离开了Level 8，预计最终抵达Level 9，然而最后却到了Level 93。

09搜寻队-3：这里并不是Level 9……

Gamma基地-34： 你那是什么意思？

09搜寻队-3：我们离开了Level 8，然后我们出现在了一座山上。不知道这是怎样发生的，但事实确实如此。

Gamma基地-34：你能描述下环境吗？

09搜寻队-3：这里嘛……这里看起来像是一座山，像珠穆朗玛峰或是什么别的。我没看见有地平线。所以这里一定有数百英尺高，然后我也不觉得这里就是山顶。

Gamma基地-34：你可以再补充点其他信息吗？

09搜寻队-3：这个层级不知为何具有天气系统。

Gamma基地-34：可以记录下你所看见的天气吗？

09搜寻队-3：好吧，在我们开始这场谈话之前，天就在下小雪了，但现在它变得越来越大了。

Base Gamma-34：好的，请尽快尝试离开。

[归档文件结束]

据推断09搜寻队在45分钟后最终离开了层级，然而，由于Level 93中缺乏氧气，09搜寻队的全体成员都陷入了缺氧（氧气不足）并在几分钟之后丧生了。因此，还未有任何出口被记录下来。

基地，前哨与社区：

因其无情的气候与特性，本层级中没有存在的基地和/或前哨。

入口与出口：

入口

Level 93可自Level 8、47、115、135以及山村进入。

  • Level 8
    • 朝Level 8的一个角落切出。
    • 离开Level 8时有1/1000的概率随机进入。
  • Level 47、Level 135
    • 将你自己埋入雪中。
  • Level 115
    • 卡入Level 115的一面墙中。
  • 山村
    • 在森林中游荡4小时。

出口

没有离开Level 93的已知方式。经推测09搜寻队偶然遇到了出口，然而出口尚未被记录下来。据称一位流浪者走下了Level 93并着陆到了Level 135，但此方法并未再次奏效。
