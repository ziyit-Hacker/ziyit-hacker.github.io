工业化
当今人类的明日世界

描述

大多数流浪者切入Level 705时，他们会出现在本层级最安全的地区——大桥上。 连接了两个岛屿的大桥约有10公里长。桥的西侧为“未开发区”，而东侧为“开发区”。

桥上持续不断的雾气营造了一种如同风暴之后一般，沮丧低落的气氛。桥下有一条河流，但由于其深度过深，一直无法进行直接的勘探。目前能确定的是其温度很高，且浮力小于常规水体。 因此进入这条河流是绝对禁止的。 Level 705的每个区域都有与该水体相连的部分，故流浪者最好避开存在水体（如湖泊与河流）的区域。在桥上流浪者可以听到波浪声与风声。由于桥位于海上方，其温度较低，平均仅有7℃。

由于不推荐进入“未开发区”，如果流浪者在雾中迷失了方向的话，建议向着明亮的一侧前进，前往“开发区”是更好的选择。

Level 705是由桥梁连接的两个岛屿组成的层级。“开发区”是Level 705的一个更为高级且先进的区域，后室机器人科技正在不断改善这个区域。Level 705最初是一座废墟城市，但由于一些建筑和机器的遗留状况良好，我们得以利用技术进行进一步的重建。


描述：

开发区是一个正在重建中的城市。该区域的昼夜循环与前厅完全相同, 温度也与前厅的东亚相似（平均温度为 12.9℃）。街道周围有多座建筑和一些设施，环境类似于Level 11。自从发现这个层级以来，开发区的人口和技术水平稳步提升，但尚未正式成为人类的领土。由于开发区相对于Level 705的其他区域较小，我们得以较快完成勘探。开发区的面积约为75平方公里。

Level 705有明显的季节更替循环，每三个月左右更换一次。每个季节的温度和环境与前厅东亚地区相同。生态系统的变化也与前厅相似（例如，樱花在春天开放，而大多数植物在夏天，诸如此类1）。

在对这个层级进行重建期间，我们将其划分为4个区域，以便于监测进展和变化。

第1区

第1区看起来类似于前厅中的典型城市，与Level 705的其他区域相比，第1区的重建进展最快。第1区的重建已经基本完成，区域内建有许多医院、公寓楼、道路和工厂。建筑物功能完备，配备了功能齐全的厨房、浴室和电器。第1区是Level 705中除了大桥之外最安全的区域，也是定居的最佳地点。尽管重建已经进行约5年，但第1区的面积仅约有5平方公里。2第1区的基地距离桥梁3公里，由约60人组成。

第1区街景。

第2区

废弃工厂的一个实例。

Level 705的第2区与第1区类似，大多数建筑对公众开放，并且具有一些基础设施。区别之一是第2区的工厂等设施目前未投入使用，因为许多设施缺少核心设备或仍在建设中。尽管这些建筑目前未被使用，但大多数已完全建成且结构稳定，因此非常安全。另一个区别是第2区包含一个大型的杏仁水湖泊, 并且已建造了管道、井和过滤器，以便在各区域的所有建筑物中提供自来水。第2区也非常适合居住，但大多数建筑物未配备电器和家具。

第2区由我们位于湖泊附近的，由30人组成的第二基地管理。因此，在流浪者进入第2区及其他区域之前，他们可以取得一些资源，例如水。由于实体绝迹，第2基地还负责监控周围的设施，有时会从流浪者那里收集有关第3区和第4区的信息。

第2区覆盖约10平方公里的面积，并完全环绕第1区。

第3区

典型的第3区建筑。

由于后室机器人科技主要着手维护第1区和改善第2区，第3区尚未开始重建。该区域的街道常被碎片和垃圾覆盖，大多数建筑物正在不断损坏（除了下文的基地外）但尚未完全倒塌，鉴于其不稳定性，建议避免靠近。第3区最具威胁的实体是猎犬。虽然不常见，但流浪者应时刻作好面对它们的准备。该区域唯一其他有报告的实体是笑魇，它们只在夜间活动。Level 705的笑魇身上出现了一种现象，即它们倾向于避开光线，与常规的笑魇正相反。所以夜间在此区域行动时，最好使用手电筒或其他光源以避免遭遇它们。第3区的基地仅由约20人组成，建在废弃建筑之间，但因为会持续发出强光以驱赶笑魇，所以并不难找到。

第3区的占地面积约为25平方公里，是开发区上第二大的区域。

第4区

第4区。

如果流浪者越过了某条界限（由于第3区的尽头未知，所以第3区和第4区的界限也不清晰），就可以注意到周围环境的一些变化。这意味着进入第4区。 街道上覆盖着瓦砾和尘土，存在大量无面灵在此游荡。所有建筑物均已荒废。

第4区是开发区中面积最大，同时也是最危险的区域。在白昼时间段，该地区的唯二威胁为猎犬以及窃皮者。所有建筑物都在坍塌，以至于没有什么可以称之为真正意义上的建筑物了。尽管有报告称存在状态相对较好的建筑物 (如图所示的即将倒塌的建筑)，那也只是相对好一些而已。它依然是不安全的。

如上文所述，开发区是一个岛屿，这意味着流浪者在无论何时位于开发区的边缘都可以看到大海。由于岛屿的边界皆为陡崖，而海洋十分危险（上文已提到），流浪者在此应当小心行事。如果流浪者以切入的方式进入了开发区，由于第4区的面积最大（约40平方公里），其在第4区醒来的概率最大。

实体：

如上文所述，第1、2区实体绝迹，而其余区域存在数量不等的实体。目前有报告的实体包括：

  • Entity 10：窃皮者。仅被目击出现于第4区，多数活动于建筑物内。
  • Entity 9：无面灵。仅被目击出现于第4区。没有记录在案的敌意。
  • Entity 8：猎犬。 仅在第3、4区出现，且较为罕见。
  • Entity 3：笑魇。仅活动于第3、4区的夜晚。
  • Entity 22：警告风筝。 流浪者报告了位于第4区边界的目击，所以其也可以作为流浪者位置的指示。
  • Entity 121：骨盗。仅有1名流浪者在远处发现了该实体。暂无直接冲突的记录。

基地、前哨和社区：

尽管在所有区域中都没有任何值得注意的的长期前哨站，但有几个松散的社区可以帮助层级中的流浪者，并提供有关该层级环境及现象的有价值档案。

入口和出口：

入口：

  • 流浪者可以在Level 387和Level 571中发现一个放置有各种建筑工具的房间。有报告称在这些房间中停留一定久的时间有概率切入此层级，并声称流浪者将会在大桥上醒来。
  • 流浪者可以切入Level 400的金字塔来进入Level 705。
  • 流浪者可以在Level 714发现一片被“开发”主题涂鸦覆盖的区域。1名流浪者报告称，在本区域停留10分钟后，他发现自己已经身处Level 705的第2区中。

出口：

  • 有时第3或第4区内会出现一条隧道。它通向Level 605。
  • 切入大桥会抵达Level 901。
  • 为了保护当地的动植物，后室机器人科技在第1区建立了一个自然公园。其中不时出现的藤蔓隧道通往Level 369或Level 414。
  • 流浪者也可以通过大桥前往未开发区。但我们非常不建议这样做。

尽管我们做了很多努力，但还是有很多流浪者切入了未开发区。由于环境和实体的威胁，目前只进行了三次勘探。由于所有的勘探都不算成功，无人机也无法改善环境3，这份文件包含了一些真实性存疑的推测。

将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

描述：

Level 705大桥的西侧的岛屿，通常被称作“未开发区“.

如果流浪者通过大桥进入了未开发区，他们会注意到一些异常变化。

迄今为止报告的异常：

  • 天色变得黑暗。
  • 异常响亮的波浪声。
  • 感觉大桥越来越窄。
  • 自言自语而不自知。

Level 705的未开发区环境与开发区完全相反。由于所有无人机勘探的画面都是一片黑暗，我们有理由认为该区域处于永夜状态。直接的人力勘探只进行了3次，所以该区域的精确温度仍未知。已知的是，勘探记录表明该区域极度寒冷。

街道被数量可观的瓦砾碎片覆盖，并且没有建筑物是可用的。由于其缺少自然光，在没有人造光源的情况下，辨识周围环境和躲避瓦砾碎片是非常困难的。并且，由于未开发区整体反光性似乎更弱，所以无论使用多强的光，能照亮的区域总是有限。

在人力勘探中，记录了成谜的声音，如脚步声，未知语言的嘀咕声，以及未知野生动物的叫声。由于此区域的黑暗，流浪者很容易遭遇笑魇。

目前我们已经勘探了约50公里远的距离，然而无论流浪者前进多远，都不可能找到一处安全的安身之所。所以，如果流浪者意外进入了未开发区，极度建议立即寻找大桥。虽然未开发区的环境极其恶劣，但是离开此区域的方法非常简单——抵达开发区。本区域的强风可以作为流浪者寻路的工具，大桥的方向总是与其相反。

除去实体和严寒的威胁，其他危险相对温和。由于随处可见的碎片瓦砾，空气质量较差，但报告称不会影响呼吸。此外，被瓦砾碎片割伤可能会干扰勘探；然而，伤口可以用常规的急救工具治疗，并且暴露在灰尘中不会造成严重的问题。为了协助流浪者逃离此处，我们在大桥附近修建了三根柱子。第一个离大桥约5公里，第二个距离其约3公里，最后一个距离其约1.5公里。如果流浪者不能辨认风的方向，就应该去寻找这三根柱子。

未开发区的面积未知。

实体：

未开发区中存在无面灵，窃皮者，笑魇4以及猎犬。这些实体（笑魇除外）同样会受到黑暗的影响。因此，适当的止步、屏住呼吸同时保持安静可以避免遭遇实体。一名特工报告了遭遇一只消极的无面灵，但是缺少更多报告来佐证其存在。

正如开发区的同类，此区域的笑魇也趋于避开光。因此，建议点亮光源以驱赶笑魇。但是，持续点亮光源有可能会引来其它实体。

入口和出口：

大桥可以作为一个出入口。

入口：

  • 1名流浪者声称其在Level 22切出后来到了此区域。
  • 流浪者可以在Level 990的”洪水“事件中切出从而进入此区域。
  • 流浪者可以在Level 395中发现一个放置有各种建筑工具的房间。有报告称在这些房间中停留一定久的时间有概率切入此区域。

出口：

  • 在一座形状相对正常的建筑周围切出可以进入Level 854。
  • 流浪者有极小概率于瓦砾碎片下发现一个下水道入口，它通往Level 688。

目前还没有发现具体精确的出口点，所以请务必注意任何异常位置，因为它们可能是有价值的出口。

如果发现其他入口或出口，请告知我们，我们将不胜感激。
