从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;

}
[[/module]]

他X的世界的终点， 先前的Level 600，是一个可以从废墟之路进入的后室的隐秘层级。

描述：

他X的世界的终点是一个由于缺乏补给和敌对实体无处不在而十分危险的层级。

他X的世界的终点外观类似于被一次核战争摧毁的城市，此层级并未出现核辐射的迹象，且太阳锁定在正午高度处。街道被摧毁并被碎片覆盖，这些碎片一路破散到诸如超市和军事前哨等房屋与特殊设施。

这座城市里充斥着猎犬、尸鼠、木灵以及人形土匪。它们是这个层级中最危险的实体，因为它们能够使用和挥舞枪支。

偶尔可以在建筑物内找到尖噬怪的涂鸦。鉴于在目前对于此层级的探索中并未发现此类实体，尚不得知这些涂鸦是为何以及如何出现的。

当抵达他X的世界的终点的边界时，会出现非欧几何现象。景观将开始向上和向下扩展，经过的区域将重复和循环，如果坚持前进，到达终点所需的时间可能比预期的更长或更短。但是，试图这样做的人将目睹土地开始脱离并慢慢扎入蓝色通道。

超级市场与百货大楼

他X的世界的终点中的超级市场通常是空的，但可能存在一些诸如桌子以及床一类的家具。瓶装的杏仁水或者罐头食物可以在这些结构内部找到，以及这个层级中整体拥有的标准非欧几里得属性。

商场里空无一人，没有任何家具或用品。此处还拥有大量的土匪和非欧几何结构，非常不建议穿越这些地区。

值得注意的是，所有找到的日历都显示同一日期：1999年12月31日。

军事前哨

军事前哨是层级中罕见的建筑，到目前为止仅发现了一个。前哨基地由废弃的军用车辆、营房、沙袋、军用口粮和偶尔出现的军用背包组成。

城市中心一处。

场景（Scene）-01.1是开发室（Devroom）的A号场景，它是在1987年8月31日被发现的。

场景-01.1是一个巨大的城市，与穿越山区广阔景观的道路相连。

布局与效应：

场景-01.1 由两个主要区域组成，分别是与场景-01.2相似的繁华大城市以及分隔城市的大片山地森林。这些城市内部没有实体出没，唯一的例外是那些自发驾驶的智能汽车。它们的驾驶方式没有类似人类的特征，只是温和平缓地沿着道路行驶，并遵守所有道路安全法。

虽然建筑物的内部与真实世界中的类似建筑具有相似的结构，这些建筑都是未经装修且空无一物的。虽然各种居民从其他场景带来了家具，并一直在这里建立家园，但许多建筑物仍然是空的。偶尔会出现具有非欧几里得属性的房间。这些房间具有清楚标记其非欧几里得特征的路标，进入它们时没有任何危险。

场景-01.1的森林沿着山地景观出现，森林里长满了树木，但没有野生动物或昆虫。河流可以在森林中找到，但它们都没有起点或终点。河流从不形成急流，被认为是可以安全进行游泳和饮用的。

道路没有笔直的路径，会随机绕着山脉和景观蜿蜒而行。人们经常可以找到跨越数英里，从一座山峰到另一座山峰的混凝土支撑桥梁。汽车实体也可以在这里找到，但它们在森林中不太常见。

土匪

土匪是他X的世界的终点中主要的威胁，它们是类人生物实体，由7到12名成员成组移动，可以像正常人一样说话。它们都具有使用如霰弹枪、突击步枪和狙击步枪等枪支的能力。一些土匪使用钝器，包括消防斧、砍刀、金属棒球棒、撬棍和警棍。他们与普通人的唯一区别是他们像尸体一样的外观和腐烂的气味。

非欧几何结构

他X的世界的终点内部有四分之三的结构具有非欧几何特征。这些结构的非欧几何特征被表明，并且具有很高的危险性。在这些房间里，有许多土匪放置的陷阱，这些陷阱通常会导致死亡或者不可逆损害。当进入摩天大楼时，将会进入哪一层是随机的，因此不建议住在其中。

这些具有非欧几何特征的房间由于结构重复和缺乏出口，可能会引起空间混乱和方向感丧失。所有房间都没有家具，里面唯一值得注意的物品是陷阱与大量碎片。摩天大楼的每一层都是完全独立的，进入它们的唯一方法是退出并重新进入摩天大楼。

摩天大楼的遗迹从外面看起来很小，但是，已知这些结构的内部尺寸至少是其三倍。购物中心的大厅如不走过重复的走廊则几乎不可能退出。

应当提醒的是层级的边界也具有类似的非欧几何特征。

入口与出口：

入口

要进入他X的世界的终点，你可以在蓝色通道里找到随机的入口，进入这些入口可以坠入这个层级。另一个进入的方法是在废墟之路里一路向西并跳下公路，这可以让你进入蓝色通道，进入后继续向西就能来到此层级。

出口

要离开他X的世界的终点，需要前往层级的边缘，然后便可以进入蓝色通道。
