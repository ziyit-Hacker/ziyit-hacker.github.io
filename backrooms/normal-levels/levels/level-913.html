翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

如何使用：

[[include:backrooms-wiki-cn:component:level-class
|class=等级
]]


class 处的可用参数包括以下内容，支持简繁体及英文输入。

n/a 不适用 不適用

该组件支持简繁切换，如下方代码所示：

|lang=cn/tr
|class=等级
]]


在lang 处选择语言，cn 表示简体中文，tr 表示繁体中文，不填默认选择简体中文。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

Level 913是后室的第914层。

描述

目前尚无法证实该地点是否存在尽头，但其非线性特性对验证其真实性无疑构成了阻力。

在切入本层级后，流浪者将会发现他们躺于地面之上。当他们对地面侧耳细听时，他们将会感知到一种与老电视闪屏，在其屏幕上出现闪点时相似的断断续续的声响。

流浪者有时可听见自己的回声，其间隔自数毫秒到几十年，不尽相同。相比其原来的声音，这些回声会变得更为扭曲且有时会夹杂生物的嗡嗡声、笑声或是其他无法分辨的杂音。

Level 913的墙面纯白，有时会装有诸如空调、电箱或是窗户等的物件。

窗户之外通常被黑暗所环裹，有时会有一道不明光点闪过黑幕。大多数人报告到该光点会紧随其行动而动，且随时间推移而变得愈发明亮，直到该光源从琥珀色变为暗红色，随后骤然不见踪影。它很快便会在另一扇窗户处再现，并继续跟随着流浪者。

层级中央有着被单纯排为一条直线的数个方形水泥立柱，其间的空隙足以让约莫一人通过。若流浪者闭上双眼并在水泥立柱间穿梭，则其会在较远的另一个方位处出现。该行为有时会导致切行及以下将会提及的后果。

抬头看向天花板，流浪者将会发现日光灯管上似乎有黑色虫类在飞舞。一段时间后，它们将逐渐被日光灯渐强的亮度及光热烧为灰烬。与此同时，流浪者的视线将会充斥白光，而他们则会听见生物在其周边扇翅的嗡嗡声。

有时可在墙上找到一扇木门。在将其打开后，其场景即与数小时前别无二致：一扇白色的门，白色的天花板，白色的墙，还有继续照亮着整个房间的白灯。

流浪者时而可以找到似乎已被上锁的门，令其无法被打开。此时，他们将会听见门后传来的一声隐晦且令人发毛的笑声。天花板上的灯光会骤然熄灭，随后窗外的亮点便会渐渐逼近。

流浪者与该异常光源接触的结果不得而知，因为遇见了该现象的人随后都失去了联系。

基地、前哨和社区

本层级内没有基地、前哨或社区。

入口和出口

入口

  • 可通过自其他地方处下坠以来到本层级，这也是绝大多数流浪者来到此地的方式。
  • 一些流浪者也会进入任意位于前厅内的房间。倘若他们打开门后发现外部空间是一望无际的洁白，且无论走了多远都不会感到饥饿或是口渴，那便意味着他们切入了Level 913。

出口

  • 如上所述，通过闭上眼睛并在水泥立柱间穿梭有较小几率可离开本层级，但尚不明确流浪者在离开后会位于何处。这是因为所有成功切出该层级的个体皆有他们自空中坠下，且在数秒之内因不明原因快速失去了联系的报告。
