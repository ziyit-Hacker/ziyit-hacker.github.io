翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

一张Level 387内公寓楼的照片

描述

Level 387表观上为一含一幢混凝土公寓楼、一条较短马路与一片阴郁森林的小型晦暗层级。该层级内可通行区域仅有30000m2之多，任何逾越该界限的尝试皆导致了不幸的后果。本层级永久性地停滞于清晨时分，因此不存在昼夜循环。其中的气候相对凉爽，一直保持在6°C的水平。

该区域的界障由环绕着边界的浓重雾墙构成。进入其中的流浪者疑似会从中消失，再未归还。与雾墙接触者消失的因由尚不明确，但据流浪者传言，它会将其带至另一层级。“雾境斥候”的精英理事会1并未对类似于此的传言作出回应，令该传言很快便人气尽失。所有在Level 387内因某些原因消失者再未有人目击，但“雾境斥候”却向任何质疑者保证其中并未有谋杀行径，仅是迷雾而已。

公寓楼

公寓楼为一幢18层之高，与前厅者别无二致的建筑，其中含有Level 387的居民与“雾境斥候”的行动基地。据“雾境斥候”文档估计，该公寓楼的套房总数约为200。所有套房内都有与中央供暖系统相连的暖气片，可散发20°C的体感舒适温度。208间套房内，有132间拥有小型阳台，作为居民们共有的难得享乐场所。

每间套房内的家具大多千差万别，但所有的套房内都会存在前厅内应有的典型家具。大量家具、墙面及天花板要么已经老化，要么质量堪忧，此建筑内通常都会有着一股土腥与陈腐的气味。

食物方面，水龙头处会流出杏仁水，亦可在冰箱内找到杏仁水与钝人肉的生制切片、雌性死亡飞蛾翅干和一种血腥却营养丰富的暗红色黏稠浆泥（其成分不明）。该浆泥呈现于一口碗中，其数目似乎于近来失踪者的数目存在直接关联。对于该事件易引发恐慌的性质，“主理人”2现身发言，并对此作出回答：“后室异常世界的又一异常性质，无需为此担心。”本层级的人们开始接受这种食物，将其奉为佳肴，况且这里的冰箱每周都会重新装填。丰富的生活资料与舒适的人居环境吸引了众多定居于本层级的流浪者。实际上，一条出自“主理人”之口名言已开始散播至其他层级与流浪者们中：“Level 387是流浪者们的梦中福地。它是一处有着饮之不竭的杏仁水、温暖庇护所，实体绝迹，且有着最为重要的归属感的至福归宿。”

地下室

地下室完全由混凝土筑成，通常会被流浪者们挪作社交用。这很可能是因为被弃用的家具被挪到了这里，而其中亦有来自一垂于天花板之灯泡昏暗的光照，让许多流浪者对该地下室有着其“拥有诡异的惬意感”之描述。该地下室仅有半个部分被开放给所有流浪者，唯有“雾境斥候”的最高级成员方可被允许进入另一半地下室中。流浪者曾报告过听见了从地下室无法进入之部分传来的液体自混凝土淌下的动静，还有某种黏稠而多汁之物体的被剪碎声。很不幸的是，目前尚没有有关此事的官方文档或是证据出现。

门厅层

其中没有套房，该层会被另作他用，如进行宣告演讲及选举活动。本层与建筑的入口相连，亦是新来者的引入处。一些沙发、桌子和椅子被带下了本层，令其成为了本层级内最受欢迎的社交场所。每年都会在此进行选举，并产生通过一套民主选举体系产生新的精英理事会。但主理人却能够永不失去其权力。

马路

马路是一条位于此建筑附近的狭小沥青通道。该马路长约为300米，宽约为5米，且与雾墙的北侧及南侧呈完美正交状。马路起于何处，终于何方均不明了，因为该道路表观上穿越了雾墙并持续延伸了下去。神秘之处在于，沥青表面上有着表明曾有车辆自该道路驶过的车辙。目前尚未找到进一步的证据。

马路两旁为一排平平无奇的路灯。这些路灯皆高10米，外观各异。它们内部不含有灯泡，因此总是处在关闭状态。

森林

森林是本层级内最大的区块，占据了其总区域约90%的部分。该森林由多种树木构成，最为常见者为北美乔松、白杨、榆木和橡木。因寒冷的温度及迷雾重重的气氛之存在，大多数的树木都已丧失叶片，并呈现着阴郁的外观。

随着流浪者漫步愈远，迷雾也会渐渐变得越发浓重。这可能会导致流浪者突然走入雾墙中并消失不见。正是出于此原因，该森林的渺远边界仍探索甚少。居民们有过当深处该森林边界处时会有受人监视之不安感的报告。“雾境斥候”则将其定性为臆想症并认为不应在任何情况下对其展开更深入的调查。

实体

Level 387实体绝迹，野生动物不见踪影，唯有那片养分丰富的森林。其中的土壤内可发现极少量已然降解的蠕虫尸体，时间可上溯至数百年前。这一发现暗示了本层级内古老生命存在的可能性。

“雾境斥候”的旗帜。

基地、前哨与社区

因Level 387内较小的空间，层级内仅存在一个囊括了Level 387中所有人口的中心社区。

“雾境斥候”：

  • 它是唯一一个位于Level 387内的社区。
  • 该社区据估计应有500人。
  • 他们最常出现在公寓楼内，但他们也会在Level 387的森林处花上些时间放松自我。
  • 他们非常友善，并会在流浪者接受公民身份后向其提供庇护与大量的资源。若其不接受，那么他们将会强迫其离开。
  • “雾境斥候”作为一个社区已高度发达，并采用了旗帜标识、一套法律体系和一个可运作的政体。若有流浪者破坏了律法，他们给其的惩罚便是将其放逐至雾墙边境处。
  • “雾境斥候”有着一套影响着居民所拥有之权限的细致体系。

体系

“雾境斥候”的体系由四个阶级组成：“主理人”、“精英理事会”、“戍卫部队”与“凡众”。体系内的阶级决定了一名流浪者的权利、待遇和信息访问权限。

“主理人”的旗标。

“主理人”

  • “主理人”名为Thaddeus Kazan，也被称作“圣父”。
  • 他是“雾境斥候”的创建者，不可被票逐出精英理事会。
  • 他于2020年5月发现了Level 387，自此定居在了这里。
  • 身居体系的最高位，有着绝对权力。
  • 他时长会现身于门厅层以发表布告或是举办活动，以使“雾境斥候”社区团结一致。

“精英理事会”的旗标。

“精英理事会”

  • 该阶级由9人组成。
  • 他们是Level 387的领导者。
  • 每年“凡众”们都会选举出一个新的理事会或新的理事会成员以继续把持权力。
  • 他们同聚于门厅层内，掌管着Level 387。

“戍卫部队”的旗标。

“戍卫部队”

  • 该阶级由55人组成。
  • 他们是Level 387内之法则的执行者。
  • 由于规章少之又少，与其说该阶级是一份工作，不如说它是种受人尊崇的象征。
  • 只有能力最为卓越的“凡众”才会被授予该阶衔，如训练有素的格斗家们。
  • “戍卫部队”有着超越“凡众”的更高阶权力，令其能够对“凡众”发号施令。
  • 每隔一段时间，“戍卫部队”便会参加一场与保卫工作、律法或是威胁因素相关的“精英理事会”会晤。
  • 现如今，“戍卫部队”的唯一职责便是保卫好地下室的后半段；每日都需有两名守卫看守其入口，并有两名新的守卫进行轮替。
  • 每位“戍卫部队”的成员都武装有一条7英存长，打磨锋利的家具质地的金属片，以作他们的武器。

“凡众”的旗标。

“凡众”

  • 该阶级在“雾境斥候”中占比超85%。
  • 他们是Level 387的普通居民，身居体系的底层。
  • 只要遵守规则，“凡众”便可自由游荡于Level 387中。
  • 他们没有什么需要履行的职责，但上级可能会命令“凡众”在任何事项上为其提供帮助。

入口和出口

入口

  • Level 387最为常见的入口方式为自Level 5内的一副画作处切入。
  • 另一条通往Level 387的路径为在Level 46内找到一扇弥散雾气的门。
  • 环保Level 39内一颗孤立且暗色的树木亦会将流浪者带至Level 387。
  • 在Level 309内长期行走有概率会将流浪者传送至Level 387。
  • 在Level 150内食用腐肉有概率会将流浪者带至Level 387的地下室内。

出口

  • 自本层级切出通常会将流浪者传送至Level 388。
  • 进入Level 387内的任一套房内会有极小的几率令你切出至Level 13内的一间套房处。
  • 公寓楼地下室内一扇积满尘埃的未来风格门扇会将流浪者带至Level 15。
  • 若流浪者在Level 387的马路上入睡，其便会在level-80中醒来。
