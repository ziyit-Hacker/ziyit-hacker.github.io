翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

在lang 处选择语言，cn 表示简体中文，tr 表示繁体中文，不填默认选择简体中文。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

Level 225的起点。

Level 225是后室的第226层，是一系列具有不稳定结构的封闭式长廊，会对处于其中的任何生物造成毁灭性的影响。

描述：

流浪者在进入Level 225后，会发现自己身处一条有着瓷砖地板和白色墙面的混凝土长廊中。长廊的天花板上有一个“出口”标志，它的灯光会时不时变暗几秒钟，但大部分时候是常亮的。建议来到本层级的流浪者设定一个15分钟的倒计时，流浪者在接下来的15分钟内可在本层级中安全活动。15分钟后，本层级便会开始治好你。本层级的地形将变得完全不同，虽然墙壁、地板、上锁的门和“出口”标志不会发生移位，但本层级的景象将发生巨大的改变。这种突发的周期性的变化被称为循环。

处于第4循环的Level 225。

不论发生多少个循环，流浪者总会在长廊中找到至少一扇打开的门，这些门通向另一条长廊，因此本层级实际上无穷无尽。把每一条长廊都记录下来是徒劳无功的，因为本层级中唯一稳定的结构是你本次旅行的起点。

“净化”：

Level 225有一些不同寻常的特性。在各个循环的开始，本层级中的一切物体会被扫干净。这在刚开始是好事，但流浪者在Level 225停留的时间越长，他们表现出不干净的可能性就越小。各个循环产生的影响如下所述。

第1~3循环

流浪者感到欣喜若狂。他们的衣服变得干净了一些，闻起来也更香了，如刚洗完澡并涂上古龙香水时一般。他们的双手变得湿润，并且身上所有的小伤口都完全消失了。他们随身携带的工具变得好用了很多，如刚刚被洗干净并涂上润滑油一般，身上的可充电电子设备也悄无声息地被充满了电。如果他们吃了在循环之前吃过的食物，他们会发现食物远比循环之前要美味。更有甚者，即使是过期或发霉的食物，尝起来也变得更加新鲜可口。通往完美的道路已经开通。

第4~5循环

流浪者身上穿的衣服看起来更干净了，如刚从干洗机里拿出来的一般。机器和工具更好用了，如刚出厂一般。刀子变得削铁如泥，流浪者随身携带的机器运作起来如全新的一般。电子设备被充满电后，性能比以往任何时候都要好。

第6~8循环

到了这里，流浪者开始乐极生悲。他们突然感觉自己更完美了，衣服开始出现磨损，电子设备时好时坏，机器和工具变得松动，身上的食物也开始变硬。

第9~13循环

到了这里，流浪者开始感到不适1。他们的衣服逐渐出现撕裂，皮革开始开裂，绒毛似乎也开始融化，致密的布料开始分解成更小、更简洁、更完美的纤维。他们随身携带的机器也开始分崩离析——零件之间的摩擦力变得如此之小，以至于固定零件的螺母开始自行滑落，紧固件和楔子也从机器上脱落。电子设备不再工作，因为电池已经无法使用。食物变得硬邦邦的，难以咀嚼。流浪者开始感到浑身发痒，身上的死皮开始以吓人的速度脱落。

第14~25循环

到了这里，流浪者或许已经命不久矣，因为完美，或者说他们体内的细胞已全部死亡。由于可分解尸体的细菌已经不存在，流浪者死后尸体并未被分解，而是被完美地保留了下来，这是理所当然的事。所有的机器散架成为一堆零部件，并且不再可能被组装起来——由于摩擦力的消失，这些零件自然会变得异常滑手，根本拿不起来。流浪者身上穿的衣服到这里会完全垮掉，变成一堆破布和碎屑。其余的那些已经无关紧要的人类的机器也会被打理好。

第26~31循环

你的尸体将会消亡，化作一丁点骨肉。你所有的随身物品，你所有的财产，你的记忆，你的意识，还有你自己。你很快就会化为一堆原子，比你所希望的更接近虚空：孤寂，独立，完美。2

第32循环

到了这里，你将一无所有。你实际上根本就不存在。你所留下的仅仅是地板上的一个干净的斑点。你带到这里的一切都已消失得无影无踪，就像你一样。这就是净化的过程，这就是追求完美的过程，这也是你向你认为的最好的自己无限靠拢的过程。

目前尚不明确每个循环中分解的成因是本层级本身的特性，还是存在一个以这种方式吞食流浪者的实体。

但你们怎么会觉得我会把你们这类生物作为食物呢？

基地、前哨和社区：

本层级没有已知的基地、前哨和社区。

入口和出口：

入口：

  • 你可以通过进入Level 33的紧急出口到达本层级，但能成功到达本层级的可能性微乎其微。
  • 到达本层级的一种更简单的方法是通过Level 6.1中的一扇写着“员工通道”的门。

出口：

  • 从你来到这里的门出去是离开Level 225最可靠的途径。
  • 沿着本层级中分散的“出口”标志走，最后会看到一扇贴着绿色宽标签的门，进入这扇门将到达Level 4。
  • 第7循环期间，你可能会找到一扇明显与本层级中的其它门不同的米色门，进入这扇门将到达Level 60。

你们人类……

但你们为什么要放弃快乐呢？
你真的相信埋怨这个世界，你就会更快乐吗？当你说你对自己的现实生活感到满足的时候，你确定你没有欺骗自己吗？你不是希望自己能远离日理万机的生活吗？
你对独立的解读是什么？当你已经不复存在，你所有的焦虑也就消失了，你觉得会怎么样？你难到没有想过，别人在讲述这个过程的时候，都在骗你吗？
别人骗你说这样很痛苦，别人骗你说你会死。但当你失去一切的时候，你永远不会死，你只会成为更强大、更令人满足、更完美的一份子。
