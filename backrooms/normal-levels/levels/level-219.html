翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

入口和出口


入口


切勿尝试以任何方式到达本层级。完全偶然地意外切入本层级是存有可能的。已有他人在开启位于学校、公路或是家居层级的门后发觉自己身处本层级，亦或是在上述层级中游荡并触发意外切行后至此的报告。两个导致最多流浪者最终来到Level 219的层级分别为Level 11与Level 9。

出口


本层级尚没有已知出口。


我前脚才在Level 11内休息，在我转身的下一刻我便发现自己身在这个素不相熟的层级了。

在此之后究竟过了多久？


描述


Level 219由数个区域组成，通常会随本层级时间推移而逐渐出现。一名流浪者最开始会发现自己身处一片看起来像是现代房屋的区域内，随后的是一条公路，最后的则是一座学校。这些区域的循环将会不断重复，直至流浪者身亡。

我所有的动作似乎都在为弹簧引导，就像是一个在盲目做戏的木偶。我无法感知到自己的双腿与躯干。我别无选择……



房屋


该房屋即为流浪者在进入本层级后首次苏醒的地点。其中有一间小型的卧室、一间厨房、一个客厅及一间浴室。当处于该房屋内时，该层级将会使流浪者遵循并完成一系列的活动，如将所需材料准备进一个书包内，打开冰箱以期备好早餐（尽管本层级内并没有任何种类的食物），然后再刷牙洗漱。

该区域与一个典型的大小中等的房屋相似——亦即在城区中可见的那类，其中有一个户外花园及一个小型露台。其中共有两扇窗户，一扇位于客厅中，一扇则位于卧室内。墙壁为鹅黄色，其地板上则铺有地毯。

我听到了自己的母亲正在叫我去吃早饭，但那里却空无一人。除我以外不见人影。我已无视了她。那里一个人也没有。日复一日。

每当冰箱敞开之时，其中皆空空如也。那里一份能填满其空壑的熟食也没有。耽溺于食物一点意义也没有。

我的胃在自我吞食。我试着从别的地方获取食物，什么也没有。以至于试图咀咬我的手掌亦无法使我的饥饿魇足。我为啥会跑进这个厨房呢？为什么？我明知这里没有食物……

这是我第七次收拾书包了。书本、铅笔盒、教科书……一次又一次。在当时我已不再想去注意我放进其中的是哪个了，我的双手机械地游移着，像由程序控制一般。只要这些东西能给我带来些精力……

刷，刷，刷，此时我洗刷我的牙齿已无法延缓将至死亡的脚步了。因此我所能做的就只有伫立于镜子前，并注视着我憔悴渐宽的衣带，正趋衰败的身躯。我现在看起来已与饿殍无异了。



该房屋内有一面标记着该路线各阶段何时结束的时钟。在7:30左右时，流浪者将会被支配着走出该房屋，并走上前往学校的公路。

滴答，滴答。

那是每日不变的噪音，多么烦人。它不会停止的。但我想让它停下。每一次我都希望把它砸个粉碎。



迷雾公路


在离开房屋后，流浪者将会被支使行走于一条空寂的城区公路上，该路段总是为浓雾所包围。该公路周边的建筑皆为空置状态，整条公路上也没有任何汽车或是噪声。

它与大都会内的繁忙道路颇为相近，都有着高耸入云的大厦与散布周边的商铺。在远处时亦可看见一座大型商场。

这感觉起来就像是一切都是虚假的一般。太过安静，太过僵持了。甚至看不见一辆汽车或是公交移动其间，建筑内也空无一人。它是一座因那些身亡其中之人不得安宁的鬼城。

我憎恶这般寂静，我的双耳因为如此的寂静而鸣响起来。我走路发出的声响也无法让我沉静下来，我只想它结束，我只想停下脚步。我的鞋子早已磨坏，双足血肉模糊。我的脑袋快炸了。



该徒步行程需耗费将近40分钟，使流浪者在8:10左右抵达学校处。

我已对沥青路上的裂痕，还有这条公路上的所有建筑了如指掌。此外我无事可做。这里没有别人，只有我自己，终日如此。负重踏步而行。就像现在这样。我缘何不能停止？我缘何要心甘情愿地继续前行？即便我尝试过走上他路，我也只会重回这里。

我希望这里能有别的东西给我个痛快，让我从痛苦中解脱。



学校


这座学校建筑蔚为庞大。其中有着数目客观的教室及其他通常可在前厅的常规中学处见到的其他区域。流浪者必须得进入他们自己的教室并坐在课桌前，直到白天结束（18:00左右）。随后他们方可被允许离开自己的课桌及学校地界。他们会被再次转移至公路上并返回家中。

流浪者们曾经在被迫行进的路上看到过美术室、科学实验室，甚至还有一所剧院。每个私人教室内都装饰有世界地图、图表以及纸板手工品，此外还有一面数字白板和一面平平无奇的黑板。

教室的空寂与我过去所感受到的差得并不太多。一个看不见的孩子在写字、听讲、静坐。我则感觉起来像是具空壳，现在便已经是了。

每人注意到过，这在大家眼中再普通不过了。他们所有人都屈服于此种命运，而它则在这个地方继续了下去。每个人都有他们自己的小团体，我则怀揣着自己的想法形单影只。我们在他们眼中真就如此地微不足道吗？



与Level 0相似，本层级会阻隔任何活物间的联系。当一名流浪者踏入本层级的地界时，他们便无法按其意愿探索任何地点。他们将会被强迫去遵循一条由本层级异常性质决定的严苛路线，其身体将被操纵，如同被夺舍一般。这是一条与流浪者上学循路径相似的路线。即以在房屋区域内的床上醒来为始，随后为前去学校的路途做好准备，然后便是去上课。

这样的循环就像是在家里一样，与我的童年无异。我没有朋友这点除外。我没有动力去完成这凶恶无比的试炼。我仅仅是孤身一人，在孤军奋战罢了。



本层级内既无实体也无补给。因它将导致抵达其中的所有人的死亡，故其被划分为了死区，要么因脱水而死，要么因饥饿而亡。没人能够成功逃离本层级，大多数人仅能靠外界的准备手段与补给才得以生存较长时间。

为什么这样的地方偏偏必须存在？这个世界就只是在分析我们最烂的生活经历然后去再现它们的基础上而建立的吗？

这太痛苦，太令人无奈了，人类在他们所处的宏大世界中是如此微不足道，一直如此。



该层级是通过几份来自流浪者用手机向M.E.G.发送的电子邮件内的文档而被逐渐探索的。在几个月的时间内，所有文档已被整合为一以撰写本文档。

每一天，流浪者都必须得顺着这样的路线而行，直到身亡为止。试图打破该路径是不可能的。我们所建议做的唯一一件事便是尝试写下有关该层级的任何新信息，以期未来能够找到一种能阻止任何悲剧重演的方式。为保全人员生命，不会有任何M.E.G.探险队会被送至本层级进行探索与记录。

日日用功，年年学习，直到你周身腐烂，找份工作，退休，然后死去。一条咒语，正在将我四分五裂。我想把我该死的肉身给撕个稀烂。

我会在这死去，无人立碑。没人会知道我去了哪，我将成为一串数据。我已经放弃与它抗衡了。

多遗憾啊。


基地、前哨和社区

本层级不宜久留，在其地界中形成任何形式的基地、前哨或社区亦无可能。

我好累……我要卧于地面。我将眠而复醒，醒而复眠，轮回的苦痛便会消散……永远消散。最终我方可安息。我将朽为灰土。

不再会有崭新的明天。警报也不再会作响。不再有早餐与散步……唯有寂静，直至有其他人像我一样沦落至此。

晚安。
