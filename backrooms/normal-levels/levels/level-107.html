使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {

Level 107内的一个毁坏的房间。注意墙壁上的电力箱。

Level 107是后室的第108层。

描述：

Level 107为一遭到严重污染以及损毁的房间，据初步观察，该层级内部表现为一段时间内无人居住。该层级外观标志为棕黄色的瓷砖墙壁以及被强行撕毁的屋顶，仅留下一堆扭曲的电线以及因未知原因腐烂的木材来支撑房间的顶部。房间的门已严重受损，其上大部分的铰链已脱落。有关Level 107需注意的是，每个房间似乎都有一个电力箱连接到房间的一面墙上。可以直接观察到钢筋支撑着主要部分并延伸至地板下的某些房间。

大多数房间地面被断木与碎片覆盖，强烈建议穿着结实的鞋子以避免受伤。房间内不透明的厚窗户似乎会发出强烈而明亮的光线，但其为层级内唯一的自然光源。因此强烈建议使用高功率照明设备。Level 107持续发出一种环境噪音，其被描述为一种由录音设备产生的静电声与尖叫声。若层级持续发出该噪声，可能会使流浪者陷入疯狂。通常情况下，连续暴露在噪音下超过72小时将导致听力损伤。

实体：

层级受到多种实体的影响。可以在许多房间内发现悲尸，通常可以在附近找到杏仁水和口粮等物品。此外在Level 107中常常发现感染了疫疾的蠕灵，鸭典娜以及瓷砖陷阱。

其他许多不明实体的报告已得到证实。多数前往该层级的流浪者报告天花板传来巨大的尖叫声。目前，没有任何证据支持该观点。

基地、前哨与社区：

由于Level 107上述所提到的环境噪音效应，该层级不存在已知的基地、前哨与社区。

入口与出口

入口

最近的研究显示，通过Level 106内的特定门将带你来到Level 107。此外，已经证明进入在Level 135发现的的一口特别的井有极低的概率带你来到Level 107。

出口

根据研究人员的最新研究，在Level 107内每经过35个房间，天花板上便会存在一定数量的洞。爬上天花板的这些洞将带你来到其他层级，通常会来到Level 68。从地板切出将带你来到Level 108。

研究员：采访开始，White先生。
White先生：哦？好吧…开始吧。
研究员：当你到达Level 107时，你有没有……不舒服的感觉？
White先生：…
White先生：我通常不会这么说，但是当我到达Level 107时……
White先生：……突然感受一种震撼和回忆的感觉，就像人生如跑马灯一般闪过我的眼前。它如此可怕，又如此美丽，所以——
研究员：White先生，我还有一个问题要问你。
White先生：嗯？
研究员：Level 107内有什么实体？
White先生：（听到响亮的爆炸声）啊！
（记录结束）

采访报告：White先生的多个器官突然破裂，导致其当场死亡。然而尽管White先生已经死亡，其身体仍持续颤抖了5分钟。研究表明，White先生的死亡是不正常的，因为其在采访开始前并未显现任何异常状况。

描述：

Level 107是一个能够影响到达该层级流浪者的异常层级。

由于Level 107的异常效应，Level 107的真实外观未知。当任何生物到达该层级时，其将会遭受严重的精神衰变，并被传送至被其他流浪者所认知为Level 107的区域。有关该区域的描述见初始版本。当任何人被问及有关Level 107的外观，实体或者具体描述（例如：Level 107的目的是什么），其将导致受影响者直接死亡。研究人员认为，此为Level 107有目的性的封闭信息的措施。

实体：

从某种方面来说，Level 107内的唯一实体即Level 107本身。理论上，其为一巨型智慧实体，其使用心智扭曲操作（P.B.W.M.）将人员传送至层级的一虚假空间维度内。据研究，传送一名人员需要约2.3秒。目前正在研究如何真正的探索Level 107。

基地、前哨与社区：

由于上述的异常效应，Level 107内没有已知的基地、前哨与社区。

入口与出口：

入口

最近的研究显示，通过Level 106内的特定门将带你来到Level 107。此外，已经证明进入在Level 135发现的的一口特别的井有极低的概率带你来到Level 107。（请注意，这些入口将通往真实的Level 107，但是流浪者将被传送至虚假的Level 107）

出口

根据研究人员的最新研究，在 Level 107内每经过35个房间，天花板上便会存在一定数量的洞。爬上天花板的这些洞将带你来到其他层级，通常会来到Level 68。从地板切出将带你来到Level 108。（请注意，这将会使流浪者离开虚假的Level 107。）
