使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。

描述

Level 105与一座宽敞的教堂相似，其内部格局却极度简约且无菌，与停尸间内的环境别无二致。该层级则被居住其中或频繁造访它的人称作“祈祷所”。

当流浪者到达本层级时，他们将会看见几乎充斥了周遭的各式立柱。向前行进即至可在任何教堂内找到的各色木制条凳处。其数目将近200，被井井有条地排置在两侧。

祭坛上并未展现任何一类的宗教符号。事实上，整个层级内似乎都并未显示出任何宗教图像。教堂中的人们则通过将本层级描述为“一处可礼拜任何能在后室中找到的宗教的地方”来解释该特性，举例言之，就是那些鲜为众人知或是刚由其成员创立的宗教。

在教堂主间的末端可找到一方小祭坛，伴有一张盖有白布的桌子。右方则置有一架在教堂内人声鼎沸之时常会被人弹奏的管风琴。除了上述特例之外，本层级便再无其他的华丽装饰了。

装点着该区域的并非宗教符号，而是些数学符号和几何形状。在主间的前四十张条凳（左右各二十张）每排的两端都放有廿面体1。接下来的四十张条凳在其两侧则各饰有一个正十二面体2，随后的四十张条凳则有正八面体相伴3，再后来的四十张条凳有立方体相随，在最后的四十张条凳两端的是正四面体4——最为简洁，却也最为尖锐的正多面体。披盖在立柱上的是点缀着类似正四面体网格徽记的布条底部外侧的三角形中含有“Ⅱ”与“Ⅲ”的罗马数字字样，顶部外侧的三角形则含有数字“Ⅴ”。在最中心的三角形处，行星木星的的符号即位于一个正五边形之内。此外，窗面上的马赛克皆呈彭罗斯瓷砖的密铺状5。

一张布条上徽记的特写图。

运作着这座教堂的人们以“教众”或是“虔信之子”的名号为人所知晓。他们是些决定在本层级定居并继续崇尚其信仰，同时也为寻求一处居所的流浪者。他们对收住并照料任何外人一事持开放态度，并且是后室孤儿们的主要监护人，这些孤儿由M.E.G进行救助并交由他们照料。

本层级资源的数目难以估量，在其开始为人熟知之时便已吸引了大批流浪者，这也促使其中的许多流浪者加入了教众之中，久而久之便开始拥护新的信仰。本层级也成功让大量作为其社区一员，且才能禀异的医生与药剂师齐聚一堂，从此成为了一处治疗患病与负伤流浪者，并致力于帮助尽可能多的人的主要站点。

大多数成员都欢迎新来者加入他们的活动与宴集中，集会作为一次全新的体验可贯穿整日。这些活动从祷告到猜谜、游戏还有更多活动，不一而足。

除人类之外，本层级内亦可看见无面灵。他们也是“教众”的一员，且会更频繁地进行祷告，并尝试参与到各式活动中。“教众”教会了他们如何去写字，他们对新来的流浪者也关爱有加。

整个教堂之内，不同的区域已被“教众”们改造为了寝室，它们相当狭小，且与该层级自身有着相似的简约设计。其中亦有一处贮藏室，内部含有所有类型各异的补给。教堂内还有2条通向一间厨房和餐厅，以及被用作额外空地的空房间的走廊。

多数补给都是些有着某种宗教含义的食物，譬如无酵饼6、酒品、巴克拉瓦7、 无花果、椰枣、巴东牛肉8、苹果、蜜、月饼、白斩鸡9等等。

这里还有会被特意派遣至层级外去宣传该教堂的成员，且会邀请有需之人，并将任何种类的资源捐送给他们。他们被称作“虔信探险者”。可通过他们的朴素衣着来辨认他们，虽然他们并不会去穿戴任何形式的徽记或是特殊饰件来让他人辨认

他们声称自己希望与尽可能多的决定加入他们的人在教堂相逢，但仅限那些真正有意愿且希望有可供祷告的安全之所的人们。他们反对向他人施压或是使用极端的手段来让流浪者皈依，通常也对使用暴力一事深恶痛绝。他们也更宁愿不去被他人称道或是过高地敬仰。

加入教会所需的做的便是与“高层人士”进行交谈，即那些主管教会活动之人。其主要领导人以“启明者”之名为人所知，他是一位血统未知的高个男人，有着一头姜黄色短发，身着朴素的暗色衣物。他总是穿戴着某种样式的面纱以遮盖其面部其余的部分， 且不愿展现出自己的全貌。

以下是一次新近记录的有其出场的访谈记录。

开始记录

时间： 12:45
日期： 3月4日
地点： Level 105
采访人： Artur Bosch
受访者： 启明者

[教堂中，摄像机面向着启明者，他正坐在特工Bosch所在桌子的另一面。]

启明者： “亲爱的先生，这台摄像机已经在记录了吗？”

Artur： “是的。”

启明者： “很好，你的问题是什么呢？你大可以问我你心底的所想一切，我将回答所有一切的疑问。”

Artur： “所以，这个教堂中的社区是何时，又是怎样开始存在的呢？”

启明者： 一个至关重要的问题啊，亲爱的先生，这可说来话长了……

那是我尚为孑然之人的时候，信仰便是唯一驱策着我前行的动力。那便是我完全偶然，磕绊着进入这个地方——一座几无光亮，破败而又空荡的教堂时候。

我无处可驻，所以我便决定在此定居下来……

[他停顿了下，用手指轻敲桌面。]

最初我一无所有，这个地方正在分崩离析，我手头没有任何资源。但我在我的旅途中找到了像我一样的虔信者，那些与我志同道合之人。

我们联合起来，开始以我们所有的精力徒手修理起这个地方……时过境迁，我们让它变得美丽焕发。

[他又顿了顿，停下了敲击桌面的动作，把手放回了大腿处。微微地斜起了他脑袋。。]

我们从其他人手上集中起捐赠品，并开始向同我们一样的信徒们宣传这个地方……很快，一个社区便形成了。

这些都要归功于我们的信仰与我们身为信徒的韧性。这便是我漫长而又富有深意的阐述了。”

Artur： “所以这个社区是出于共同愿景与需求而联合在了一起。这挺有意义。但是，这座教堂的墙壁为何如此……空荡？若我没记错的话，大多教堂的墙壁上都会缀有某种形式的符号吧。这背后又有什么缘由呢？”

启明者： “亲爱的先生，原因很简单。这是一座为所有人而设的教堂，符号则是一种将所有事物置于标签之下的方式，但我们并非单一的整体。我们成众，信仰各异。我也并非那类会去约束应将何种宗教符号置于墙上的人，因为那将意味着把铸就我们力量的多元性抹消殆尽。

我仅一介凡人，一叶供信任我之人向目标前进的扁舟。我没法为我身边之人妄下决策。”

Artur： “您愿意告诉我们教众们所做的任何形式的重要事迹吗？人们都说本教会在帮助更为不幸之人这一方面有着卓越功绩，我们殷切期望能听到您有关此事的发言。”

启明者： “啊，我不想在即将公之于众的访谈中听起来像是在吹擂自己。我希望所有人都能理解我更希望保持谦逊而非因上述的事迹而非被人称道或是捧上神坛。

但，是的，你是对的。我们的教会已帮助了许多人，我们收容了那些因后室残忍本质而失去了父母的孩子。我们的一些成员，在现实世界中是医护人员，帮助治疗了那些游荡在无垠地带中罹患了疾病的人。

我们已向与M.E.G.有着相似目标的小型团体伸出了援手，只要这个地方能存在下去，我们也希望能继续帮助尽可能多的人。”

Artur： “好的，为编撰文档起见，能说说这个层级有哪些出口和入口吗？”

[这个男人在回答前沉思了一会。]

启明者： “从主门离开将会把你带至那宏大的城市中，你是从那儿来的，所以我想你也知道如何从那里进入我们的教堂。你所需做的一切便是找到一座教堂，就像是从教堂处回家，不是么？事实上……”

[这位姜黄色头发的男人在衣装中的口袋摸索了一会，随后递给了他一张纸。]

启明者： “我已为M.E.G.的人准备了这些。应该能省下些时间。”

Artur： “感谢您所做的贡献，我还有最后一个想问您的问题。您能告诉我们些有关您正践行的宗教的事情吗？它有名字吗？还有些其他细节吗？”

[这位男人微微咯笑了下。]

启明者： “我没法解释它，因为它是一种如此难以分享的经历。其无可名，乃至我的神亦无可名。但我知晓祂的存在，我们共受用一条精神纽带，而且我也能听见祂。

祂光彩照人，丽质焕发，令我驻足。一个知道通向真相的大道的存在。

唉，如果这并非一个令人满意的答案的话，我很抱歉。”

Artur： “别担心，先生，我尊重您信仰的神圣性。

我现在就停止记录，再次感谢您对本次采访的贡献。”

结束记录



一张启明者的画像。


基地、前哨和社区：

教众社区

本层级的居民。他们是些信仰着诸多未知宗教并随时间推移逐渐加入了教会的流浪者。

他们遵循着金字塔状的阶层体系。金字塔底端的是些寻常的“教众”，及随着的阶层为“虔信探险者”（那些在本层级外宣传该教堂之人）以及位居顶层的“启明者”（该团体的领导者）。

  • 倘没有更多人员的话，他们的成员约有350人。
  • 他们对交易持友善态度，且总是对协助流浪者一事持开放态度。
  • 他们会对新成员敞怀欢迎。


入口和出口：

入口
  • 在Level 11内找到一座大教堂并进入其前门将会来到Level 105。
  • 切入任意层级内的任意陈旧木制家具有较小几率会来到Level 105。
  • 找到并携带一本在其封面上无符号的宗教书籍将会使流浪者切入Level 105。
  • 切入小型喷泉中有可能会来到Level 105。
出口
  • 穿过主门即可回到Level 11。
  • 将手部浸入小型喷泉内过深将会让流浪者直接切入Level 7。
  • 切入木制家具可能会来到含有此类家具的层级。
  • 切入墙中可能会来到一些较为安宁的层级处。
