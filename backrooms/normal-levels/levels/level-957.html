在我的无尽之梦中，我……


我被带到了那儿。又回到了乌有之境。不过这已经是我又一次回去了。他们让我这次写点关于此地的东西。

每次重回此地，我都感到相当恶心、巨他妈的反胃。我不清楚是来到了这儿还是我的又一次焦虑发作让我感到恶心反胃。我不在乎，在这里我就是觉得如此的反胃。头晕目眩，胃如打结。我恨这里。每一次，我都恨透了这里。

这整个小镇都无法让我感觉到任何的关怀或爱心。就只有千篇一律的四车道街道、千篇一律的工业园区、千篇一律的操蛋破住房，整一坨这些都堆在这没屁用的小镇里。

无价值的小镇……

毫不顶用的小镇……

无果镇……

我必须得把这俩词连在一起。抱歉，我只是忍不住想要发泄我对这小镇的沮丧心情。我的治疗师给了我一份狗屎清单来帮我镇静下来，而这对我来说一点屁用没有。

环顾四周，你看到了什么？

我看到了垃圾。废物。屎。这破地方烂完了。这停车场和马路就是一坨屎，这些建筑物让人觉得它们就不是为了让人看着舒服而建的。走在这傻逼人行横道上总让人觉得有点什么危险，因为无论是哪个天才造的信号灯，他都没想着要把这些脑残玩意放低点。看在你妈个逼的份上，基本上没什么东西把人行道和马路分开，就只有一小片草皮和一条路缘。

不过他们也不是偏得管这些。住在这里的人总是开着车到处跑。他们的垃圾房被宽点的路或者其它开车在上面出入的东西分隔开。关于他们貌似并不在乎人们走不走路这事，我还是挺困惑的。如果你怎么着都得开车，那还为什么要住在路边呢？

都是一样的屎。

最好别让我开始喷这一坨空停车场和这些跟见了鬼一样单调死板的办公楼和仓库。我甚至不知道这里一半的半挂车都是要去哪儿，从哪里来，它们就像被一老哥从这稀薄的空气中生成，来让我的散步体验变得更烂。我觉得这里一半的建筑物压根都没投入使用过。我很少见到它们外面有很多车，而且它们也不可能自然地保持如此的干净。就连住房和小型公寓点我都觉得有一半时间是没人住里面的。如果你一天里面得有大半天都不待在里面，买房还图个啥啊？

这里有什么东西能让你感到愉快？

没东西。这地方只让我感到非常非常非常恶心。我觉得在这我能做的事顶了天也不过是到处乱转，试着在这些区域后场和雾蒙蒙的空气中寻找宁静。火车轨道直接干进一小片树林里面，但一过了这几棵树，我看到的大部分就都是这些单调乏味的停车场和工业厂房了。至少那里还挺安静的，能缓解我感到恶心时伴随而来的那些头痛感。在这边的时候，我头痛基本上就没停过。

当感到情绪低落时，你能跟谁倾诉？

这是个好问题。每次我沿着铁路走的时候总能看到一小群人。他们不是朋友，更算不上旧相识或者我刚认识的人。我觉得他们无家可归…差不多吧。他们全都面色苍白、营养不良，但我觉得我对此无能为力。他们总是拽的一比，所以很难和他们恰当地交谈。他们看起来和我一样难受，就算他们似乎找到了一些较为悲伤的应对方式。

我不喜欢待在他们旁边，但他们差不多得算我遇到的全部人。开车到处窜的人肯定不在乎，我也不打算胡乱走进那些随随便便的公司大楼或者住房里，我可不是个怪人。

除此之外，我就得等到我以某种方式离开这。就算到了那会，我在离开之后还是感觉有点恶心。

在家中，当事情变得棘手时你会选择去哪？

我就只是逃避。我尽自己最大可能地从这狗屎地方、狗屎散步中逃跑。附近也没人真的在乎就是了。他们全都开着他们愚蠢的汽车驶过这些令人作呕的单调建筑，也没人愿意打扫,哪怕是让这些地方看起来稍微干净或自然点…更不用说令人愉快了。我觉得没人在乎，所以我就尽我所能地逃跑。跑了一小会之后我就…到了另一个地方。


我难以表达心里有多么觉得这地方缺少任何的正常生活气息。这让我绝望。大概这就是为什么我在这总感到恶心。大概这就是为什么我急着逃离。不管这儿算什么，我讨厌把这地方称作家。

我恨无果镇。

我恨住在里面的人。

我恨无果镇让我感受到的恶心。

我恨在这里所存在着的一切。

为什么这里总是如此的不冷不热？不穿夹克出门就冷，穿了就太热。出门闲逛的时候，我要么冻得发抖要么热的出汗。

私家车和货车里的臭傻逼们老是差一点就撞上我。就算有车前大灯也没用。当我被一些大傻逼的车前灯全白的时候我他娘的还看个屁的路。一半时间里，我甚至都分不清这些车里面是不是真有人。我从来没仔细观察过，也就看到些残影。

我得冷静。深呼吸。没关系的。这样只会让自己觉得更恶心。我的脚走路走得都酸了。感觉就像自己的鞋子不合脚。

有那么一瞬间，我恰巧和在这儿的另一个人擦肩而过。这太让我措手不及了，以至于我不得不突然停住脚步。我俩可能在那杵了几分钟，盯着对方，愣了一会才恍然大悟面前看着的是个啥。他看起来衣衫褴褛又脏兮兮的，浑身上下都是灰尘和泥土。他头发蓬乱，衣服也同皮肤一样缺少光泽。脱离困惑后，他调整了一下背着的登山包，一小会儿后抬步从我身边经过。

我回头，只是看着这个邋遢的男人继续行进。他一边走，一边举起水壶贴近嘴唇喝水。考虑到这地方有多荒凉，我很难想象他已经走了多久，更不用说在跋涉途中他除我外还有没有见过其他人。然而，我无权打扰这个可怜人。他和我如出一辙，又有些许不同。我能自己推断出他的思维方式。

嗡嗡嗡嗡

嗡嗡嗡嗡

嗡嗡嗡嗡

我向口袋中有节奏的电子嗡鸣声伸出手，拿出了正嗡嗡作响的手机。我怎能忘却？

Patterson，已经一整天了。你人跑哪去了？

我还搁这儿走呢。我仍能感觉到恶心反胃，而且我想远离一切，懂？我在回答我的治疗师给我列出的问题。而这只让我在这毫不顶用的小镇里更加生气。

这傻逼地方真的让我冒火。我感觉自己在这个该死的破小镇里面哪也去不成。我一直走着，而这儿就只有用于分隔工业区、一两个居民区的路，更多的傻逼路和园区…还有他们的蠢蛋商业园。你们这群人到底他娘的为什么都想要我回来？

我他妈恨我的故乡。

你费心填数据表了吗？检查下你的包。

没有，你应该早点告诉我而不是期望我能翻包找到它。从你们这群人让我回到这傻逼小镇开始，我就一直在走啊走，试图离开这儿。我不想把我本可以拿来走路的时间浪费在填你们的弱智狗屁实验表上面。

让我一个人静静。等老子想的的时候我再填这狗屎玩意。能不能让我用随身听好好听歌，度过他娘的一段平静时光。这是你们又把我丢回这地方之后至少能给老子的吧。

操你妈，傻逼们。


在我感觉到自己马上要气上头之前，我立刻挂断了他们的电话。我信任过他们。我告诉过他们我有多讨厌回到这里，而他们对此不屑一顾，仍决定让我回来。我还傻傻地认为他们会好好地补偿我。

我感觉到我的电话又响了。

我没管它。

我恨无果镇。

我一直走啊走，越走越久，时间拖得越来越晚，直到夜色覆盖了门廊的几盏灯和偶尔出现的刺眼车前灯。蒙蒙的迷雾仍萦绕四周，掩盖了前方的大部分路况。我只能勉强分辨出前方十字路口上信号灯不断变化的红绿光。

这就是那个地方。就这儿。

当我在一个十字路口停下来时，黑暗重新排列，逐渐安定下来并找到了它该呆的位置。我向前看去，而一看到它我就僵住了；小镇的尽头。在这个空荡荡的停车场中有着一个突兀的车站，一排整齐的针叶树将其分隔开。除此之外，是纯粹的黑暗，偶尔有光线在远处闪过。

平常我就是站在这儿等公交来。这里能有一种我总站在前面的建筑，当然只是因为这儿有个车站罢了。我总算有机会离开这了。就算我得在处于一片黑暗中的车站前杵上好几分钟，我也坚信公交最后一定会来。

而很快，我就看到它逐渐靠近了。

它吱吱嘎嘎地行进，正好在我面前停下。

付了两个25美分硬币后，我上了车，长松了一口气。

再见，无果镇，我不会想你的。没人会的。

沿着黑暗的街道一路前行，我凝视着窗外的种种。镇上的房屋和区域逐渐被浓雾吞噬殆尽，隐于其中。明亮的车前灯也没法穿透它。小镇消失了，我终于摆脱了它。头痛和愤怒消退了，我胃部的不适感也平息了，在路途中，我终于放松了大脑，回归了睡眠的宁静。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]
