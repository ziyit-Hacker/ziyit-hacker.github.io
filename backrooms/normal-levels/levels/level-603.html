Level 603 - “𩽾𩾌鱼”




在此之前，你也许进入了11的一间老旧工厂，穿过了20里一扇奇异的门，又或者是切入了61中哪一个漂浮着的电缆塔。无论你如何来到此处，敬请欣赏现在呈现在你眼前的全新景色，这里拥有着山丘、平原、河流、道路、城镇，以及最显而易见的：交错的数十万条电缆。

有人类居住痕迹的户外层级有很多——但没有一个如同此地一般单调。电线似乎全都朝着一个方向延伸，而此时回头便能看到远处的山峦正向下、向内弯曲直至与天空同色的虚空中。电缆发出着微弱的蜂鸣声，仿佛磁铁一般吸引着耳朵，仿佛正对太阳造成着微弱的影响——那个正在用自身热量敲打着你的太阳。 无处可去，外加上好奇心，你向着自己唯一能走的方向前进——跟着电缆。




生存难度：生存難度：

等级等級 2e - 自然环境

  • 不安全
  • 稳定
  • 无实体威胁

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

一对穿过牧场的电线

描述：

一张更久远的Level 603照片，拍摄于一处小型街区的中心位置

Level 603是一个大型景区，主要由在大多数西方国家出现的多种地理环境与人造物构成。该层级错落有致的乡村景观囊括了山脉、山谷和平原，分布着着农牧场、森林、带河流的草原和将它们分隔开的交错道路。该层级的景观缺乏物理变化，展现出无可比拟的单调，仅仅拥有大量地理地标，如河流、果园、山谷或山脉，紧邻数百条横穿层级的高架电缆线路。这些电缆塔紧靠着公路和与其平行的土路，似乎从未偏离至路旁或更远处。

这些电缆全部指向层级的中心，因地形本身并不复杂，大多数情况下跟着这些电缆便可以沿着正确方向前进。偶尔，电线会与其他线路合并成更大的输电缆，其风格也变得更加工业化。这些电缆塔也是Level 603中最高的事物，有时比它们本身的前厅版本还要大。正因如此，无论你在Level 603的哪个位置，它们总是处于你的感知范围内——这得益于其本身持续充满机械感、有旋律的蜂鸣声，此声音由流经的电流发出。







在层级中度过几个小时后，你开始理解层级的规律。不仅道路沿着头顶的电缆延伸，整个层级的地形似乎亦是如此。你离这些看似神圣的电缆支柱越远，这个层级的环境就变得越简单，越容易让人迷失方向。这感觉像是一个圈套，一个陷阱，但同时也像是最清晰的前进路线。尽管你的直觉正在脑中嗡嗡作响，提醒你这一切并不简单，但你决定继续跟着电缆前进。




Level 603中的一个小型建筑群

Level 603的一个街区中一条路的一侧，看起来极其单调重复

虽然只是外表相似的仿造物，但房屋有时确实会出现在孤立的区域，或是以组为单位大致模拟成定居点的样子。在定居点的街道旁总是可以看到位置靠近电缆塔的建筑。尽管如此，这些村庄规模的建筑群通常没有关注价值。建筑群中的道路布局遵循最基本和简单的街区形式，许多建筑的外表多次出现，甚至经常出现在同一个村庄内。

因城镇的重复性质，有时流浪者会迷失方向，此时可以通过远处的电线塔来恢复方向感。这些城镇的基本街区结构有着完全相同的细节和瑕疵，如在一整排树木或路灯柱前的道路上复制出现的坑洞或是很少有细节的裂缝。同时，不尽人意的一致构景水平也体现在房屋的内部，此处完全没有家具，最多拥有瓷砖、木地板或地毯地板，以及墙壁上最基础的一层油漆。












起初，这些城镇给人一种清新的感觉，或者至少不失为一种独特的、不同于偶尔空空如也的谷仓或农舍的感觉。走过第一条街时似乎没什么问题，第二条、第三条、第四条和第五条也是如此。然而渐渐地，它们开始相互融合，你几乎无法辨别你走过哪些街道。当你最终走进这些建筑内部却发现里面空无一人时，那种感觉才会更加强烈。这里的一切都令人困惑，重复，空荡，所有的路看起来都一样。直到你抬头看到远处的一根电缆断了。

这些电缆总是易于找到，几乎就像指南针一般，仿佛层级正引导着，让你回到正轨上。在城镇中，没有工具，没有武器，没有科技造物，也没有食物。长期呆在这地方似乎不可能，这使得跟随电线前进变成一种必然。也因如此，你心中的不情愿被你腹部的隆隆声所盖过，你屈服了，重新跟随起电缆塔。




Level 603深处更干燥，更贫瘠的土地

Level 603中心几乎死气沉沉的景色，几乎被电缆塔覆盖满

沿着Level 603行进得越远，层级便会变得越干旱且单调。多样的地理环境和地形逐渐被平坦的沙漠所取代，只有偶尔被灌木覆盖——大多数灌木丛要么已经死亡，要么在枯萎边缘。电缆的数量也大量增加，因为该层级其他部分的电缆塔也均向中心处集中，空气中弥漫着电子蜂鸣声和重工业的氛围。

当流浪者随着时间流逝靠近中心时，通常是几天甚至一周后，很可能会感到极度干燥饥渴。当他们沿着电缆前进时，温度和湿度的改变大概率会使流浪者感受到受尽折磨，支持流浪者前进的唯一动力便是此处没有其他离开的途径。随着行进越来越深，流浪者可能会觉得几乎无法到达电缆汇聚的地点。但当流浪者真正到达时，其会观测到一圈紧凑排列的电缆塔。这些塔围绕着一个巨大工厂形成了一个圆圈——电缆逐渐地延伸到这个巨型建筑内。其发出的蜂鸣声在传输至工厂内时变得更大，仿佛正邀请着疲惫的流浪者走入。










至此，在不动的正午烈日下行走了几天之后，风景开始发生变化，尽管肯定不是以你预期的方式。甜蜜、多样、几乎称得上是美丽的地形已经开始在数英里外消失，取而代之的是更加无情和破败的环境。你脚下尽是泥土和沙子的混合物，或许这里曾经与后方一样，但如今眼前所见早已变成了遗迹，被焚烧掩埋得面目全非。更奇怪的是，眼前的景观在目光所及之处都是一致的——哪怕不在铁塔附近。

感觉像是层级忽略了自己本身的规则，使电缆塔在行进的过程中逐渐失去了自己的特别和重要性。至少，书面上是这么说的。事实上，这种电缆塔的变化及其内涵几乎没有被注意到。你的双腿无力，你的腹中空虚，你知道身后的任何事物都无法改变现状。也许这一切都是被设计好的，也许你在层级中陷得太深，无暇顾及自身的需求。又或者这两种可能性都不重要。重要的是你必须活下来，而沿着电缆塔走似乎是你最好的选择。




工厂惊奇的工业风格入口

深入工厂中心

在铁丝网围墙之内坐落着一座极其复杂的工厂，由炼油厂、火力发电厂和其他拥有排烟管的普通工厂组成。机器的呼啸声取代了电缆的蜂鸣声，当这些声音引导着疲惫的人们在管道壁和可降解材料的容器之间徘徊时，甚至使得流浪者感觉这声响好似有几分旋律。这些大型装置都与工厂正中心的几栋建筑相连，所有这些建筑都是由预制材料和金属混合建造的。

这些建筑的内部就像工厂的外部一样复杂——这里面充满了狭窄的走廊、挤满机器的中庭上方的天桥，以及其他难以描述的工业杂物。尽管室内陈设杂乱无章，流浪者仍然会沿着预先确定的路线前进，有时会连续几天或几周都依凭着难以理解的平面图前进。然而，无论室内布局多么复杂，走廊最终都会给人一种慰藉。用一种用令人难以置信的甜美而机械的旋律向流浪者发出信号。












在你于这命中注定的工厂中走了足够长的时间后，你突然感到一阵疼痛传遍全身。你的大脑在最后一刻都忘记了你要去哪里，陷入了没有思想的漫游中。在黑暗吞噬你之前，最后映入你眼帘的是一个工业用的圆柱形设备，它发出的噪音比其他机器都要连续、低沉而尖锐。骨头崩碎，组织撕裂，意识消失。你被喂给了工厂。你本可以逃到62、80甚至113，但你没有。这个层级从一开始就钩住了你，从你看到的第一个塔便开始引导你，直至你把自己送进它的肚子里。
