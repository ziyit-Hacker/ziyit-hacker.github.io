翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

如何使用：

]]


class 处的可用参数包括以下内容，支持简繁体及英文输入。

unknown 未知 未知

deadzone 死区 死區
pending 等待分级 等待分級
n/a 不适用 不適用
amended 修正 修正

该组件支持简繁切换，如下方代码所示：

|lang=cn/tr

]]


在lang 处选择语言，cn 表示简体中文，tr 表示繁体中文，不填默认选择简体中文。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

主区域的照片。

Level 400 是后室的第 401 层。

描述：

Level 400 为一具有金属与瓷砖铺设的地板的巨大仓库，其正中有一颜色暗淡的金字塔。 编码员在此层级内横行，故应当尽量避免进入此层级。这是编码员唯一出现的层级。深入层级有可能发现一个房间，其中放满了科技产品（电脑、笔记本电脑、路由器等）。建议不要触摸这些物体，因为这样做似乎会使得附近的编码员受提醒。

充满了科技产品的房间。

该房间中央有一个金字塔，强烈建议不要进入其中，因为大多数与编码员的遭遇都是在那里出现的。由于此建筑颇为巨大，金字塔内部具有的事物的类型与性质是未知的。假若进入该金字塔便无法回头。可以避免进入金字塔，因为该层级相当大（大约两个奥林匹克游泳池或1.5个足球场的大小），但假若流浪者确实发现自己进入了金字塔，可以通过跳过其中计算机的其中之一这一方法，通过这个小出口进入到谧碼 。

异界代码：

当与电子设备进行连接时。编码员似乎使用特殊的编码语言。这种代码对人类来说是陌生的，任何非编码员都无法理解。因此，此代码无法进行编辑。如果尝试将异界代码下载到笔式驱动器或闪存驱动器上，它会自毁。

计算机：

层级内部有一使得值得冒着风险进入此层级的物件——在金字塔的正中央，有一台可以编辑/前往层群 1 中大量层级的计算机。想要离开的话，唯一要做的是在计算机上选择一个显示为文件的层级，比如说 Level 0。然后便会从站立处立即切出该层级（穿过地板前往那个层级），不论是在哪里站定。尝试将电脑文件拷贝到 USB 上会使得 USB 上的拷贝文件立即消失。

这一特殊计算机上的文件是用上述“异界代码”编写的，使得除了编码员之外，任何智慧生物体1都无法编辑信息。由于未知原因，无法从计算机中删除文件。计算机连接到互联网，可以使用管理员的权限访问 M.E.G. 数据库，允许编码人员编辑或删除他们想要的任何条目。

编码层级：

有时，在与一位编码员进行争吵之后，它们会让与之争吵的人认为自己切出到了其它层级，实际上他们只是进入了“被编码的”层级。以下列出一些不完全的例子—这个人可能会被传送到一个反转版的 Level 0，其中并不具有黄色墙壁与大声运作的荧光灯，而是有紫色墙壁和无声的灯光。
M.E.G. 特工 Jamison 有一个理论，即编码员位于许多子层级的后方，并且以某种方式与 Level 404 相关联，因为该层级与这些实体的数据和引诱行为有共同的联系，例如在其中一个房间中出现的“异界代码”流。
对于这个理论中子层级部分的解释是这些“被编码的”层级与子层级的一般呈现状态近似，Level 1.5 是最好的，可以预测“被编码的”层级的外观的例子。
鉴于这些“被编码的”层级在进入不久之后就会崩溃这一事实，理论上来说编码员位于这个子层级的后方。层级的构造方式导致其特征高度混乱。相比于一般的整洁稳定的后室层级来说，这些“被编码的”层级一般更加混乱，且看上去像是被生成出来的。

艺术家对进入金字塔后所见的描绘。

基地，前哨与社区：

由于大部分进入此层级的人员无法在存活状态下离开该层级，该层级没有基地，前哨与社区。

入口与出口：

入口

可以通过在终点打开电脑上一名为“大脑已1是软0件”的程序进入此层级。滑下 Level 119 的绿色滑梯也可以抵达。与终点的那条路径相似，可以在 level-201 的一个终端上打开“大脑已1是软0件”到达此层级。可以通过将自己的生命承诺给代码和代码上的数据进入，也可以通过 Level 188 一处流出数据流的窗口进入此层级。

出口

可以通过切出层级的墙壁离开层级，此方法由一 M.E.G. 的未知员工发现。走到金字塔中的计算机前，点击其中一个层级文件可以离开此层级。有时也会通过未知的方式随机离开这个层级。强烈建议离开层级者检查自己到达的为一实际层级，而非編碼员创造的虚拟层级。
