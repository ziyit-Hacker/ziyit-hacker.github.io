物体编号：39

描述

Object 39，也就是“后室地铁”，是一辆大型地铁列车，人们可以看到它穿过后室的多个不同层级。后室地铁采用了典型的地铁列车的外观，外观偏长方形，有多个车厢，足够的座位，和一个驾驶员车厢。目前，关于它的信息并不多，这份文件中的大部分信息都来自于对目击者的采访以及M.E.G.的一些测试。

有一种理论认为，后室地铁实际上是多种不同的列车，因为不同的流浪者对它的描述不同。第一次发现它是在Level 7的一次与其不相关的研究任务中。现场的特工描述了一辆蓝色和灰色的列车穿过水域，就像水域是铁轨一样。列车一到特工那里，似乎就放慢了速度，打开了车门，似乎在邀请他们进去。他们等了几分钟，看看还会发生什么事，并尽可能多地记录下列车的情况，然后列车再次关上车门开走了。

一张在Level 3由一名目击者从后室地铁内部拍摄的关于地铁中一扇被修复过的车窗的照片。

后室地铁很快又出现在了Level 3，这次是在B.N.T.G.的“存储设施”前面。当天值班的成员描述说，一列黄色的列车突然穿过墙壁，并在基地前面停下。由于Level 3的空间较狭小，列车的一部分实际上被卡在了墙上，这进一步引起了保安人员的震惊。门打开后，一个名叫Sam Willis的勇敢的保安人员纯粹出于好奇决定走进去。

在后来的采访中，Sam表示车门在他上车后便关上了。随后列车开动，导致Sam倒在了一个座位上。Sam从车厢里拍下了列车运行的照片。值得注意的一件奇怪的事情是，一扇车窗似乎在更换之前曾被打破过，如图所示。

然后，Sam描述列车在层级中以极快的速度移动，并直接穿过了本该撞上的多面墙壁。这种情况发生了几次之后，列车突然进入Level 188，这是此前没有记录的Level 3的一个脱离方法。

性质

尽管有一个驾驶员车厢，后室地铁似乎是自动驾驶的。后室地铁通常是全空的，里面没有其他值得注意的人、实体或有价值的物体。偶尔可以找到用未知语言写的杂志和报纸，但里面没有其他值得注意的东西。

正如前面所提到的，后室地铁似乎可以随意穿越任何层级。这个物体究竟是如何做到这一点的尚不清楚，但这辆列车轻松通过层级的能力是引起M.E.G.注意的原因。

后室地铁的乘客报告列车的移动速度异常得高——高到在撞上墙壁时能轻易地摧毁墙壁。尽管如此，后室地铁从来没有造成过破坏、人员伤亡，甚至连刹车痕迹之类的痕迹都没有。M.E.G.在其中一项测试中记录下了后室地铁的速度:平均约87英里/小时。然而，也有一些流浪者表示，后室地铁的速度太快了，以至于他们在后室地铁运行时无法从座位上站起来。

这辆列车的另一个奇怪之处是它能够在不同的层级之间随机移动。人们看到列车突然穿过墙壁，进入此前没有记录在案的出口。第一个记录在案的例子是后室地铁从Level 3到Level 188的旅行，目前认为通过人类常规的切出方法是不可能做到这点的。

用途

目前，还没有一种已知的方法来“召唤”后室地铁，或控制它在哪里停止。在所有记录在案的目击事件中，它突然出现在一堵墙外，而且其位置完全是随机的。后室地铁是否对出现在特定的层级有偏好，还是对所有层级都一视同仁，目前仍在讨论中。地铁目前还不被认为是危险的，但在上车时仍应谨慎。任何危险的效果，实体，物体，或任何其他未记录在地铁上的事件都应该尽快报告给M.E.G.。

实体编号：756

栖息地：所有层级

在Level 3从后室地铁内部拍下的一扇被修复过的窗户的照片。

一张关于一个后室地铁车厢内部的照片。

描述

Entity 756，即前Object 39，是一辆大型地铁列车，在后室的各个楼层都能找到。广为人知的是，这辆列车被视为随机穿越各层级，并可作为该层级的一个简易出口。

后室地铁的外观是一辆现代地铁列车，可以随意穿过固体物质。后室地铁似乎使用这种能力作为其在层级间旅行的方法。它究竟是如何实现这一壮举的，目前还不得而知，但有人推测它具有某种能力，使它能比其他生物更容易地切出，类似于黑骑士和杰瑞。

该列车也可以在不需要轨道的情况下穿越一些区域。不仅有它滑行着穿过迷宫般的区域的记录，如Level 3，而且还有其驶过不可能的表面的记录，如能够驶过Level 7的海洋顶部而不下沉。它甚至被记录过，可以漂浮在Level 149的虚空中，就像行驶在看不见的轨道上一样。

也许这种能力的最大优势在于其难以捉摸的性质。在所有有记载的目击事件中，人们看到后室地铁随意地驶来，不久之后就驶去，没有留下任何痕迹。据记载，后室地铁从未对任何墙壁、物体或人造成任何损害。在其停留期间，甚至没有留下一丝灰尘。

行为

关于后室地铁应该被认为是一个物体还是一个实体这个问题，已经产生了大量的争论，而且目前仍在进行中。地铁最初被认为是一辆自动驾驶的列车，可以随机地在各个层级上快速行驶。进一步的研究使这些假设受到质疑。后室地铁有一个奇怪的特性，即它总是被看到在人类的正前方打开，这些人要么是独自一人，要么是一小群人。地铁的停靠地点似乎是特意设计的，它从来没有被记录在Level 11这样的地方停在大群人的中间。后室地铁也被证明只会在它所搭载的乘客能够下车的地点停下。

第一个有记载的例子是流浪者Jonathan Swartz的案例。Jonathan表示，他在乘坐后室地铁时，碰巧接到了他朋友的电话。在乘车过程中，Jonathan通过电话和朋友计划在Level 6.1见面。奇怪的是，后室地铁很快就改变了路线，在通话结束后仅几分钟就出现在Level 6.1。一个更值得注意的细节是，这辆车正好停在Jonathan计划见面的朋友面前。正是这一事件引起了后室地铁可能是一个实体的争论。

在这次发现之后，人们又进行了进一步的测试，以了解后室地铁可能具有的智能。两名发现后室地铁并上车的特工被指示在他们之间讨论前往Level 149的想法，而在此文写著时，这一层只有一个已知的入口。就像Jonathan的故事一样，后室地铁突然改变了路线，在几分钟内就飞到了Level 149。列车在虚空中漂浮，就像在看不见的轨道上一样，然后让这对夫妇在其中一个岛屿上下车。

在另一次测试中，乘客被要求在整个乘车过程中保持沉默，并不断思考如何前往Level 563。令他们惊讶的是，后室地铁在Level 563停了下来，让他们在土路上下车。

在达成共识之前的最后测试是测试后室地铁本身的能力。行动人员被指示讨论前往被称为“空无层”的隐秘层级的愿望。测试的日志已附在下面。

生物学特征

由于后室地铁的行驶路线不连贯，其确切的生物学特性一直难以研究。后室地铁似乎由四个车厢组成：驾驶员车厢，和三个客运车厢。客运车厢看起来很正常，除了之前提到的奇怪的、破碎的窗户。除此以外，后室地铁似乎不会承受任何新的破坏。在一次测试中，操作人员被要求试图用锤子破坏地铁的内壁，但他们甚至无法造成一个凹痕。列车员的车厢由于一直被锁着，所以没有被探索过。地铁的高速行驶也使得列车开始移动后很难从内部观察它。

据推测，后室地铁大约有120英尺（37米）长，但这只是根据对该实体的有限了解而作出的粗略估计。鉴于没有人对车厢进行维护，后室地铁到底是如何供电的也是一个谜。尽管如此，所有关于后室地铁的报道都将该列车描述为维护得非常好，非常干净。

行为准则：

应当：

  • 在后室地铁来时乘坐它。
  • 在乘坐后室地铁时意图前往安全的层级。
  • 尽快向M.E.G.报告任何有关于后室地铁的信息。

不应：

  • 在乘坐后室地铁时意图前往未发现或不安全的层级。

使用 CSS 进行自定义：

“后室地铁”是对一个长长的地铁站的称呼，该地铁站的有感知的地铁列车可以随意前往任何层级。

描述

“后室地铁”，作为一个层级，类似于一个人口众多的城市中的典型的地下地铁站。后室地铁的地面是由灰色的砖块构成的，在道路的两侧有两条轨道。整个区域内有时会出现楼梯，但总是被障碍物挡住或有墙体阻隔。走道被细长的荧光灯照得很亮，还有各种亮着的不明语言的标志。

目前所知的“后室地铁”，最初被认为是一个具有奇怪属性的物体，在Level 7被发现。当时，人们所知道的是存在一种奇怪的列车，它可以穿过固体物质，并通过未知的方式在各层级之间旅行。经过进一步的研究，人们发现你可以通过在里面表达对某一地点的兴趣来控制后室地铁的旅行地点。这引起了关于它可能是一个实体的争论，后来它被重新归类为实体。经过进一步的研究，人们发现了一个类似于“地铁站”的东西，可以说是后室地铁的“大本营”。它又被重新归类为目前的形式，这是一个由一群有感知力的地铁组成的关卡，统称为“后室地铁”。

该层级的发现主要证实了存在多辆列车的理论，每辆列车都非常相似，但在细节上有所不同。例如，这些列车各有不同颜色的条纹、灯光、座椅、贴纸等。其他诸如涂鸦、现实生活中国家的旗帜、各种语言——有些是未知语言——和带有方言的广告，以及其他类似的东西都被记录下来。目前还不知道到底有多少辆列车，因为从来没有人在同一时间看到过两辆列车，但至少有5种不同的列车被记录下来。

地铁站通道的每一侧都有一组轨道，供车辆行驶。左边通常是空的，除了正在使用的列车在继续行驶前会在这里停一下。右边是一节休眠的列车，似乎无休止地延伸到整个楼层。大量的车厢已经变成了人类的基地，其中一些被用作贸易前哨站或汽车旅馆，而另一些则对不速之客充满了危险和敌意。

后室地铁在充当各层级之间的桥梁的同时，还充当了流浪者的安全避难所，有些人甚至将该层视为他们永久的生活空间。由于没有任何敌对的实体或环境条件，后室地铁被认为是宜居的。

关于地铁站到底有多长，我们无法得知。但据推测，其长度至少有100英里长。如前所述，该层的主要部分——地铁车辆停靠的区域——是流浪者的主要活动中心。它被认为是交易、流浪者之间的交际和居住的第二好的地方，仅次于Level 6.1。这里以及本层级的任何地方都不存在危险。即使有人掉在铁轨上，由于之前提到的后室地铁能够穿越物质的能力，流浪者也不会受到伤害。

实体

该层级完全没有敌对的实体，只有一些友善的无面灵和从Level 11来到地铁的人类在一起。除了无面灵之外，这里唯一的实体就是是后室地铁列车。后室地铁每隔几个小时就会从左侧的轨道下来，等待大约10分钟后继续行驶。

后室地铁只表现出中立意识，对流浪者没有敌意，但也不直接提供帮助，除了接受乘客的目的地请求之外。由于缺乏文献资料，不知道是否有可能激起后室地铁的敌意。后室地铁的乘客描述说，后室地铁的车速非常快，使得你几乎不可能离开你的座位研究细节。据报告，后室地铁的速度在60英里/小时以上，最高到3马赫。尽管列车的速度非同寻常，但流浪者从未报告过拉伤、骨骼或肌肉脱臼的症状，或受到任何其他伤害。

入口和出口

进入该层级的唯一方法是在后室地铁毫无征兆地到来时登上它。由于后室地铁的不可预测性，这一点很难做到，因为它不是通过旅行请求来控制的。只有在停靠期间登上列车，才有可能离开。

但所有人都知道，当灯光熄灭时，黑暗就会涌来。
