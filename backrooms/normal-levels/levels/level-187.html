Level 187 - “无人之盛夏”

夏夜时分，我无法噤声，但潸然泪下。在无垠的麦田与其他各色庄稼缀成的乡野内，它们正以一种难以言喻的方式左右倾伏着，而我则在田野的抱拥中听取着聒噪不已的夏蝉的哀怨声。Level 187是属于空寂无人的盛夏。这方热土不曾吸引到一丝人踪气息；唯一违和的是时而突兀出现的人造房屋。然而，对我而言此处尚有一个异常疑点。那便是孤立在一片空旷泥地的，一台售卖Oi Ocha1——瓶装绿茶的自动贩卖机——就在那里。我慵懒地躺倒在贩卖机旁，它所送出的清冷的空气在暖风熏得游人醉的今宵就如气态的绿洲一般宜人。在我到达此地时，已是日薄西山，警示着我去寻找一处庇护所以度过长夜。然而我却无处寻觅逆旅，因为散落于田野图景内的房屋皆仅仅是徒有其表。每处厝内里除一方煤气供能的热暖器外皆四壁徒然——宛若一个丧心病狂的玩笑。

我从来都不是一个夏日的拥护者。缘故全可归咎于社交问题。若无可伴你迷醉在骄阳之下的人，那么你便只能成为家中的一头困兽，仅有嗡嗡作响的空调外机见证着你孑然一身的窘态。兴许这Level 187就是为嘲弄我而生的。后室亦是因我内向自封而趁此产生出的一堆场境，以对我肆意讥讽。或者，也许，是我太愤世嫉俗了。

想在这里入眠是不可能的。不可否认的是，这台贩卖机的确成为了一处调控温度的清凉夜港，但周身的闷热环境却可令人辗转反侧。自饮料贩卖机发出的灯光是自暮色降临后唯一能救我于全然黑暗之中的事物，但它同时也加剧了包围着我的此起彼伏的噪声。这是一曲熟悉而混沌的啸叫声的交响乐章。绕梁不绝的寒蝉鸣泣之声较其原先之状更加令人心急火燎，身边植物内蹒跚行步的窸窣声亦令我回想起曾被昆虫袭击的轶事。然而新的噪声也掺和了进来；于身旁迸发的花火之声让我在四面八方传来的爆裂声声与孩童们玩耍的回响中蜷缩战栗。尽管，除此以外，这里再未有可表明有他人正在此地的征兆了。

不知何故，我开始声泪俱下了。在夏日之中此事屡见不鲜。也是这是因为我感到自己已被世人遗弃了。我总殷切期望着能与别人执手相看人间焰火；这是种只能与他人相伴才能同享的美景。但是，友人们却已如朝露般飘逝而去，我从没能在友谊寿终正寝前与他们一起共度人生欢愉之时。

周围的声音在不经意间已骤然止息；皆在一念间，已成静默之音。我曾觉得噪声对于安眠可谓大敌一个，但这片死寂却加倍地令人难熬。此情难以言喻，但天穹苍野内的悄悄静静却有着震耳欲聋之感。我的思绪不尽自然地放声嘶吼。我的心智已把我丢至九霄云上的狂乱之态，正如太鼓作声可达此情。片刻，惊起天上人语，我亦释负自如。天上宫阙，倾耳女声，如此而言：

我恩赐你一片金黄色的蜃影。
一位狂乱迷醉的追随者，喷吐着激燃的告词。

是的，在沉闷熏烧的烈日前静滞，
化落成烬碾作尘，斯人沉入虚无坟。


踌躇不再，我箭步冲向声源处。站立不得，那我便紧锣密鼓地快速向那爬去。但是，在如此作为时，我的肉身却崩裂为熔渣粒粒。始于腿，衡于躯。身后唯余火中噼啪作响的身体碎块，即便如此，我依然在坚定前行。我自地面抬头向声源处望去——那是一个发光的球体正向我灌输着不绝的希望。它一定已经看见了我正向它奔赴而去，此时正尝试着引导我而去！我对发肤焦烂的痛楚已浑然不觉。它如秋叶般荫庇着我；也许它正是蒙上了痛苦假面的夏日。无需证实，我的崩裂瓦解已然降临，因为我自己的双臂终究在触碰到那环形的尤物前焚烧殆尽。操着一口鄙夷的腔调，它仅仅是在述说着我的败迹种种罢了，言尽如此：

为了什么？

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

安全保障流程：

Level 187的两个主要效应都可影响到层级温度与人类的睡眠习性；因此，若有人可进入此层级，那么我们高度建议其在进入此层级前先行做好充分准备。在此层级行进时，出口极为少见，且出口之间相去甚远，故预计其最终可能会在严苛的环境内停留上数日之久，且无法入睡。流浪者在此层级内完全无法进行休整；切忌在层级内游荡，否则流浪者将会经受睡眠剥夺的标准影响2。 层级内的气候极度有害，且变化不定。应保证随身携带：

  • 充足的饮用水补给。
  • 应对热浪的适当衣物。
  • 气象防护装备。
  • 便携式遮蔽物3。

描述：

Level 187处在一种永久的夏季状态中。

Level 187因其标志性的此起彼伏的金黄田野而知名，其中时而可见干草垛。远处则可看见连绵不绝的林木线，但无论流浪者在着无垠的层级之内前进多远，林木线都是无法到达的。整个层级之内吹拂着闷热的阵风，头顶的太阳光耀灼人；记录到温度约为98° F，太阳落山后温度却吊诡地上升至了112° F。理论上该太阳仅是一种视错觉，且以一种错乱地性质循环升落着，尽管该理论并无实际的证据进行支撑。

田野之间偶尔可见几处房屋，但因屋内仅有加热器之缘故而成为了条件恶劣的庇护所。奇怪的是，这些房屋多数采用受日式风格影响的设计构造，与近郊样式尤为相似。其他人造结构则较为罕见，但互不重样。某些建筑内可找到雕塑，其余的则是些风格不明的庙宇。

正如之前所提到的，睡眠因未知原因在此层级内不可能做到的。该现象，加上此层级出口所具的隐秘特点，令在此层级内停留的时间之延长变得无法预测。为克服此困难，许多在此层级内行进的人们都会摄入大量咖啡因以支撑身体运转直到其已离开此层级。但是通常而言，我们是不建议采取这一举措的，因为咖啡因所致的副作用会让人相比未使用咖啡因的状态变得更加疲惫。

实体及可见异象：

夜间，层级之内的实体便会活跃起来。其中唯一已被记录的生物仅有之前所述的干草垛，被人戏称为“草-垛”。这些草-垛会在活跃状态下发出特定的声音，自蝉鸣声到人声还有烟花声皆有之。除其发声活动外，它们因不具发达脑部缘故而没有感知能力。但是它们却与水母更为相似，全身几乎都由水、结构蛋白、肌束和神经细胞构成。虽然干草外皮并非其生理结构的一部分，但它们在身体外部却覆盖着一层此类物质，以保护其脆弱的内容物。在受外部刺激时，它们会缓慢地滚走以作反应，但此外就鲜见行动了。

因层级表现出的温度及睡眠相关的异常性质，流浪者在其中出现视听幻觉属常见现象，而这些幻象亦会展现出怪异的性质。最为常见的是幻象的具象化，且不论其性质何其虚幻。了解此现象的流浪者可轻而易举地利用此性质克服层级内出现的危险，但倘若被恐惧所吞噬，那么该现象经常则会使流浪者陷入遭受这些影响的危险之中。这些幻觉的共同主题是引火上身——多数时候会在视觉上以火焰将受害者包围。

入口：

  • 在Level 33内引燃自己将会使流浪者在Level 187内的房屋处苏醒。
  • 在Level 81内时常可找到蝉蜕壳；食用蝉蜕壳可让流浪者在一个草-垛的顶上苏醒。
  • 在Level 130内引燃格拉奴逻的残骸将会使流浪者于下次入睡后在Level 187内的泥潭处拔地而出。
  • 在Level 290内叩击一扇红门，并不打开它，会使流浪者在下次食用任意一种禽肉后于Level 187醒来。
  • 在Level 480说出“夏日”一词会令流浪者在此层级内诸多房屋之一内醒来。

出口：

  • Level 187内仅存在一种出口；那便是完全吃下层级内的任一异常建筑，这将会把流浪者完全带至Level 52或level-172内。这是一项十分艰巨的工作，因为层级的这些结构多数都是难以食用的。
