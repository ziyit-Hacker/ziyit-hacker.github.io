翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

在lang 处选择语言，cn 表示简体中文，tr 表示繁体中文，不填默认选择简体中文。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

Level 52的照片。

描述

Level 52是一大型洞穴，从中心分支出数条小隧道，不清楚是否存在物理意义上的出入口。层级过于宽广，无法准确测量，估计约20万平方英尺。洞穴的组成为各类岩石，具体视区域而定，包括但不限于：石灰岩、白云石、石膏、大理石、板岩和花岗岩。Level 52内有部分珍贵的金属和水晶石，很少出现且数量有限，因此对商人很有价值，也成为流浪者进入该层级的主要原因。矿种有黄金、石英、钻石、铂金和银等。层级并非无限大，流浪者可以高效探索，但还是过于宽广，速度会比较慢。

Level 52可能是年代最为久远的后室层级之一。更新世中期的尼安德特人曾定居于该层级。现在仍有可能，证据是岩壁上有原始的记号、洞穴深处偶尔传来呻吟声（非决定性证据），发现过尼安德特人的骸骨。该物种若确实存在，则可能始终避开人类，藏在洞穴的边边角角。尚不清楚尼安德特人为何能存活这么久，似乎已经演化，并适应了该层级的独有特征。

洞穴里放置了火把，可提供适度照明，然而间隔很远，不少角落和过道完全没有光照。火把不会熄灭，也无法燃尽，所有尝试皆以失败告终。但照明并不连续，因此只要有可能，笑魇会钻进任何角落。层级内还发现了其他实体，如无面灵、悲尸、 猎犬等，但与现今有一定差别，进化出了其他性状，以适应Level 52的环境。猎犬使用回声定位——听觉尤为敏感——悲尸和无面人也表现异常，行为较被动，只会盯着过往物体。以上实体未得到完整记录，故应避免接触。

该层级的诡异表现于多方面。你会感觉自己老被人盯着，非常诡异。呆得太久，则这种感觉会极度消磨心智：这或许能解释实体为何行为诡异，以及咕哝声的来源问题。偶然可听到不明脚步声，影子会凭空出现，据称逗留得越久，脑内就会产生愈发强烈的静噪，应随时备好杏仁水。

前言：以下是数份日志，展现了该层级产生的精神影响。这些日志寻回于Level 52入口处的水中，不清楚为何在此重新出现。

第一天

我完全搞不清楚自己在哪儿。身边啥都没有，连吃的都没，一无所有。手里就这么个破录音机，和一瓶水。这地方让人心神不宁，绝对不正常，感觉比实际大得多。有的地方岩壁光滑得不像话，好像是假的——就是为了作记号准备的。肯定有东西和我在一块，我能感觉到它的目光穿过我后背。

第二天

我敢说刚刚绝对有什么东西在我背后。我真听到了，绝对是脚步声，靠，就在我背后，但啥都没有——空荡荡的，火把劈啪响。我开始听到别的什么东西发出静噪和咕哝了。

第三天

老天，补给找到了。我从一个背包里找到些吃的，可能是以前有谁留在这了，我谢谢你。我来这路上碰到了个东西——是窃皮者，谢天谢地，它不饿。它那样盯着我，好像我不存在——看着像在竖起耳朵听什么，我没出声。

第四天

我不知道已经待了多久。感觉才过了几个小时，但我知道肯定只是错觉。背包里也没有杏仁水；我还在找一些东西来——隐约能听到一声喘息，紧接着是狂乱的脚步声和喘息声。录音突然中断数秒，然后继续。我不知道那特么是啥，可能是猎犬，我觉得。它看起来……不对头，没想追我。

第五天

千万别来这。如果你看到这，告诉你认识的每一个人。这地方本身并不是孤立的，但岩壁好像在向我靠拢。我找不到回到入口的路了。这些洞穴越来越窄，感觉它们在把我往某个地方引，无论我走到哪里，那些眼睛总在盯着我，我每吸一口气，空气就愈发沉重。

第六天

影子都是冒牌的，不是真影子，假的，全都是假的，它们动起来就像活的一样，监视我的一举一动。连石头都在动，我敢说。总感觉有什么东西在跟着我，但好像啥也没有。那些窃皮者呢，猎犬呢？都是假的，道具或者谁请的演员，没一个真的。

第七天

可听见喘息声。我本能地跟着火把走，感觉它们在诱导我去什么地。一声嚎叫，紧接着音频突然中断

备注：

设备进水导致之后数天的记录损坏，尚未确认该音频中的人物身份。

入口和出口

入口

Level 445中有块大石头，切入即可到达Level 52。从Level 2.1切出亦可进入层级。

出口

少数情况下，可以通过随处可见的小隧道离开Level 52，有记号可以表明通向哪个层级。比如Level 11，就用建筑物的图案标记，旁边还记载了一些无法释读的古代文字。部分隧道的标记有误，终点是随机层级。
