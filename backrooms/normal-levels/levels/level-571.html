翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

Level 571 是后室的第 572 层，于 2020/11/17 被发现。它最初被呈现为一个现代风格的设施，并通常处于清洁、正确的状态。

描述：

Level 571 为一大约六层楼的现代风格急救中心。楼层的真实数字由于每隔 2.5 小时出现的数个建筑结构上的迁移而无法确定1。 这些转移似乎并不遵循任何已知的规律，并且会对内部产生较大的改造。 然而，要注意的是 1 楼（三级护理处）和 3 楼（急救处）似乎完全不受这些迁移的影响。

类似于常规的迁移，这一层级偶尔会经历一场“黑暗迁移”。 目前仍未测量出这种黑暗迁移发生的频率，它们似乎是完全随机的。在发生黑暗迁移时，这一层级将会暂时性突变为一个残破得多的环境，直到下一次的“常规迁移”到来。 在此期间，某些楼层会有额外的，或者是与以往完全不同的实体出没。这些实体将会随着每个黑暗迁移终焉的到来而消失2。

1 楼

“三级护理处”安置着常规的医疗器械与设施。 除这些设备以外，这一楼层也遍布着多个饮水器。这种水（？）呈现一种浅淡的蓝色，微微回甜，在喝下后会让你产生恢复活力的体感。目前为止，只在该楼层发现过这样的饮水设施。这一层没有已知实体存在。 一个娃娃脸被人听到在位于该楼层中心一扇坚不可摧的大门后窃窃私语3。除此之外该层的其他门都能够正常开关。

2 楼

“确定性护理处”疑似安置着外科手术用的器械设施。一些诸如手术刀和外科口罩的医疗用具似乎已出现老化，开始生锈发霉。这种霉变的真菌能够烧伤皮肤与毛发。在这层楼的西部，有一团这种霉菌所组成的，飘忽不散的“云朵”。其不受常规迁移所影响，但它的腐蚀性曾在一次黑暗迁移中被大幅度增强。目前没有发现栖息于该楼层的实体。

3 楼

“急救处”有些像 2 楼的一个先进得多的版本。在此滞留半小时以上后，有可能在里面听到有流水的声音。此声音来源不明。这层楼同样是第一个在 Level 571 中有敌对实体公开出现的地方，例如钩头和疫疾同时在此出没。

4 楼

“生命维持与重度创伤中心”安置着生命维持系统与治疗“更高级创伤”用的医疗设备。最好尽你所能地避免进入该楼层，因为有警告风筝，窃皮者，和无面灵于此出没。

经历一次黑暗迁移后，将只有影和六臂栖息在该楼层。另外，似乎有一个六臂组成的集群栖息于 4 楼的北边（？）。

5 楼

“门诊与中转处”似乎是为诊断疾病和将病患转移至更高级护理而设置的房屋设施。 5 楼的大部分似乎都被笼罩在一片不受任何迁移撼动存在的黑雾之中。在一次黑暗迁移期间，雾似乎随着迁移的进行相较以往显著变薄了许多。一只悲尸单独地在本层游荡，体型与成年男性相近，手中抓着一把手术刀和一床枕头。
经历一次黑暗迁移后，绽放之眼也开始在此出现4。之前提到的悲尸仍旧存在。
一扇铁门在此楼层随机出现，它通往一条怪异的通道。这条通道连接一个尚不确定的层级，或许是一系列完全随机的层级中的一个5。

地下室

地下室是迄今为止 Level 571 中最不稳定的一个楼层。由于各个楼层都会随机生成通往地下室的楼梯，它可以从任何楼层进入。由于其近乎无限的面积，该楼层的整体仍有待探索。地下室已经探索过的部分全部被一种不明成分的腐臭液体所淹没。虽然液体本身似乎无害，然而，却有一只牧蛇潜伏其中。

朝着地下室深处继续探索，你可能会看见岛屿一样的结构漂浮于这片腐烂的海洋。这预示着它将会随前进变得越发深邃。同样，这里有奇怪的，类似小屋的建筑立于多个岛屿之上。其中的岛屿之一栖息着一个洛特卡的小型群落。

仍未观测出黑暗迁移对地下室的影响，然而，它所拥有的危险程度很可能与第五层相当。

入口和出口：

入口

有两种进入 Level 571 的方式。第一种是冲破 Level 143.3 东面的墙，这会让你切入进来。第二种方法是在一间 Level 401 的清洁室橱柜陷入沉睡。传送花费的时间截至目前为止仍未知。

出口

一扇5楼的异常金属门是离开 Level 571 的唯一出口。
