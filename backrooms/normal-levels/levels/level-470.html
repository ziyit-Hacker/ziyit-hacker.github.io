翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

描述

Level 470 是一栋外观因观察者而异的房屋。流浪者将会遇见其朋友的房屋，而据报告称出现的房屋通常归属于已死亡或失去联络的朋友。流浪者可以前往房屋区域外，但其仅可见到一片无尽的原野。远处模糊可见山脉的暗色剪影，其上长有数种不同的草。在房屋外部不存在诸如小虫或飞鸟等有机生命体，且也因此不存在除由流浪者制造的声音以及某些自然声音（比如风声）之外的任何声音。该层级的温度较为阴冷，范围为 15°C 到 22°C 之间，且房屋内的温度亦与外界相同。虽然不是所有的房屋都会配有锅炉，但是亦会提供御寒物品，所以不会有被冻死的风险。房屋本身是根据每个流浪者的记忆不同而改变的，所以房屋的结构并不明确。房屋内所有的家具与房间都与朋友的真实住房完全一致。

房屋内有所有的必需品，比如卫生纸、洗浴用品以及厨房餐具等，且会在每日早晨自动补充。冰箱内有供流浪者享用的食物与饮料。橱柜里有某些他们孩童时所穿的衣物，且衣物大小对流浪者来说恰好合身。墙壁上所挂的相框展示有相机所无法记录下的回忆。房屋内还弥散着一种令人舒适的香水味。流浪者可以在房屋内观看他们曾观看过的电视节目，游玩他们曾游玩过的游戏。虽然流浪者无法在 Level 470 内遇见其它人，但据称他们未曾感受到过任何比如孤独之类的负面情绪，相反，他们声称自己会感受到满足的感觉。

流浪者可以在走到房屋外面时发现一堵木栅栏。该栅栏禁止任何人跨越，且如果有人尝试跨越栅栏，那么其将被移动至该层级的房屋内。层级内的季节被锁定为春天，所以房屋外面的景色永远都是一片草绿。外界的景色同样也是不明确的，比如，栅栏与房屋之间的距离永远是相同的，但地势与山丘的形状却是因人而异的。由于流浪者可以从极远处目视房屋，所以并没有迷路的风险。

Level 470 有着与前厅相同的昼夜循环。在晚上，月光会变得极其明亮，使得流浪者可以在没有灯光的情况下轻易看清周围环境。天空中闪耀着星星，月亮则隐藏在黑云之后。流浪者在 Level 470 可以使用手机或电脑与其他人进行联络，亦可以拍照或录像，但在 Level 470 中传送照片或视频时所需的数据量过多，所以并没有与层级有关的照片存在。

根据数名流浪者所述，在 Level 470 中没有任何有人居住过的迹象。所有流浪者都声称在房屋内居住时没有遇到任何不便。没有任何人曾经报告过有第二次遇到该层级。

相关地点

虽然层级会因流浪者不同而有所变化，但 Level 470 中仍会出现某些相同的地点。

木栅栏

如上所述，如果流浪者移动至离房屋过远的地方（约 2km），则其能够在此发现一堵无限长度的木栅栏。木栅栏上未能发现任何伤痕或侵蚀迹象，且因为这一点，目前可以确信在栅栏上留下标记是不可能的。

栅栏另一边是一片广阔的郊野，远处则是高耸的群山。

步行小道

房屋前方有一条步行小道。该小道由泥土与模糊留在小道上的拖拉机印或脚印等小印痕组成。虽然不太常见，但步行小道两旁会随机出现人工种植的树木以及破损的栅栏（与上文描述的木栅栏完全无关）。小道绵延约半公里，其尽头为一片草地。

步行小道并不存在于流浪者的记忆之中，但某些人声称当其走在小道上时，其能够感受到一种未知的敬畏感与冷静感。

实体

层级中不存在实体。

基地、前哨与社区

由于 Level 470 同一时间只会存在一名流浪者，所以任何基地都是不可能建造起来的。

入口与出口

入口

流浪者可以通过于 Level 11 的室内中央进行切行以进入 Level 470。
某些流浪者声称其在前厅中因为失去某些极为珍视的人而陷入极度的悲伤时进入了 Level 470。

出口

房屋内有着一扇写有“是时候回去了”的门。这扇门通往 Level 11。
