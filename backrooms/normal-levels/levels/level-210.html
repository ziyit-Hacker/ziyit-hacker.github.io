生存难度：生存難度：

翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;

--class-n-a:38,38,38;

[[/module]]

Level 210是后室的第211层。

描述

Level 210的一些小径。

Level 210是一个狭小，封闭，以多个类似公寓单元为中心的空间。公寓呈现出意大利式建筑特征，建筑之间的空间有大约750平方米1。该层级没有昼夜循环，时间永远停止在9:00左右。整个层级的温度保持在较为宜人的25°C2，层级中偶尔会散发干净衣服的气味，气味的来源暂且未知。
有流浪者报告在切入Level 210时似乎感到了温暖与热情，并且这种感觉随着与任意一栋公寓的距离减少而持续增长。
该层级大约有36栋房屋，各配置花园，大门和露台。每栋建筑的布局都有所差异，然而它们一致地被漆成白色并且带有一个配备桌椅的类似露台。它们全部保持在九成新，并且所有的家具似乎都出自同一厂家。流浪者可以进入任意公寓单元，虽然单元内空无一物。公寓单元内外部皆呈白色，并且不具备任何设施。有部分流浪者报告在公寓单元内找到了瓶装杏仁水，然而这些报告并未得到证实。
连接各栋公寓单元的是一片占据了楼层大部分的庭院，有通往各栋房屋的小径。

庭院

Level 210的主要区域。

庭院由一个主要区域和若干条小径组成，此外主要区域还包含一个游泳池，游泳池内装满了与Level 3703中出现的成分相同的水。庭院还配置了较为破旧的篮球与网球场，皆由混凝土制成地面，其上方覆盖了大量裂缝致使表面被破坏。网球场丢失了一张网，篮球场其中一个篮球框稍有下弯；在部分裂缝中发现已经长出了野草。在层级的某些地方，流浪者可以俯瞰整个层级和层级外的某些地方，但是只能看见一片黑暗。主要区域被认为是最适合流浪者稍作休息的地方。
从中分支出来的是多条分叉的小径，这些路径随着流浪者探索的越远而逐渐变小。大部分小径指向一栋或几栋房屋；然而部分小径会突然终止并指向一片黑色虚空，鉴于其特性未知，不建议流浪者接近黑色虚空。小径铺满了不规则的白色鹅卵石碎片，这些小径大多指向公寓单元的大门。当小径接近黑色虚空或公寓大门时，这些小径会逐渐缩小并在距它们100m处消失。长椅，树和街灯4偶尔在它们具有足够的空间时散布于小径。

实体

我们

“我们”是一个栖息在Level 210的友好实体群体。虽然他们不可被看见，但可以听见他们使用一种未知的语言交流以及在露台用餐。他们一般食用前厅中普遍流传的食物，比如不同种类的面包和意大利面。在他们的桌上没有发现任何饮品，但他们中某些人曾传出过喝汤的声音。如果流浪者想与他们用餐，其中一个实体将起身为流浪者拿一份餐。就算语言上有障碍，“我们”仍然会以笑声与喜悦填满露台。由于语言障碍，交流措辞显然不会生效。当流浪者询问他们的身份时，他们会以英语回复：“我们。”随后“我们”将继续与另一个人开玩笑。
激怒“我们”将导致流浪者被强制切出层级。已有许多流浪者反馈在以这种方法强制切出层级后，再以任何方法尝试切入层级会使流浪者掉下Level 210的地面并掉出层级。在任何情况下都绝不要尝试杀死“我们”中的实体之一——所有尝试这么做的流浪者至今都杳无音信。强烈建议不要与“我们”敌对。

猫咪

层级中有若干只猫在其中徘徊。它们通常仅会在庭院的主要部分或是小径上出现，虽然有时它们被发现在公寓的露台或屋顶。它们通常非常友好并且喜欢检查流浪者。这些猫呈现出低过敏性，那些对猫有严重过敏的人可以近距离接触而并不会出现过敏反应。这可能是由于猫不能被触摸，而试图这样做只会导致流浪者的手从猫身体中切出。不过，这些猫性状仍呈固体，且它们可以站在物体上。据推测，人类只是简单地穿过它们。

目前没有发现这些猫对人类具有任何的敌意，尽管它们在沿小径散步时偶尔会徒劳地拍击流浪者的脚。多数流浪者在接近它们时感到与接近公寓时一样的感觉。

M.E.G. 文件类型： 录音日志
注： 探险者总署采访了一位探索过Level 210并遭遇过实体的流浪者。流浪者决定使用John这个名字以保持匿名。

日志开始

M.E.G. 特工：好的，可以开始了吧？你的名字是John，并且你近期有切入并探索过Level 210。是这样吗？

John：对的。

M.E.G. 特工：好嘞。那么，John，你能告诉我你在那里看见了什么吗？

John：啊嘞，我想想……第一次切入的时候，它看起来像个很小很简单的层级。但在我沿着几条小径回来之前，它们好像发生了些变化。长椅不在原来的地方，树的布局也不一样了。大概公寓也移动了吧。

M.E.G. 特工：好。你有在这个层级遭遇过实体吗？

John：有。有一些猫，还有“我们”。

M.E.G. 特工：你能描述一下那些猫吗？

John：是这样的，我对猫严重过敏。但奇怪的是接近那些猫咪并不会引起任何不适，还真让我蛮困惑的。它们很可爱很友好，但它们似乎没有形体。怎么说，类似“它看起来在那，但实际上不是”。懂吧？

M.E.G. 特工：嘶，我明白了。关于“我们”有什么可以讲的吗？

John：我有次听见其中一栋房子的露台上有吃东西的声音，所以我过去了。“我们”对我好像很热情，像是早知道我会来一样，尽管我听不懂他们在说什么。“我们”里面的一个还替我去拿了块披萨，奇怪的是它直接从房子里飞了出来。公寓一整个都是空的，所以我不清楚它是从哪儿变来什么的。

M.E.G.特工：你最喜欢的食物应该也是披萨吧？

John：就是啊。

M.E.G. 特工：你和“我们”有过身体接触吗？以及，为什么你要叫他们“我们”？

John：有，两次。我碰上了它们中的一个，他明显不是很开心，用他们奇怪的语言朝我大叫。至于第二次……我不是很想讲。我叫他们“我们”是因为他们就是这么告诉我的，他们能用英语说的唯一一句话就是“我们”。

M.E.G. 特工：你能告诉我接触他们的时候你的触感吗？

John：嘶，两次都跟触摸皮肤一样，但是很冷，很湿。这也挺怪的。

M.E.G. 特工：你有见过“我们”与猫接触过吗？

John：还没有。猫咪好像很害怕他们——它们从不接近“我们”。

M.E.G. 特工：你有见到过有人对“我们”抱有敌意吗？

John：有。另外一个流浪者拿出小刀捅了“我们”中的一个。

M.E.G. 特工：那位流浪者最后死了吗？

John：这我不清楚。可能吧？可以确定的是他消失了。

M.E.G. 特工：可以描述一下那位流浪者怎么了吗？

John：好。四周突然寂静得可怕，跟坟墓一样。他开始大叫、向我恳求帮助。我看见他的身上布满奇怪的手印，就像要紧揪住他一样。然后他就这样消失了。消失于稀薄的空气中。我觉得……他……他可能成为了“我们”之一。

M.E.G.特工：能看出这件事对你影响挺大的。还需要补充什么吗？

John：我看见有些人在尝试探索虚空。

M.E.G.特工：嗯？他们具体是在干什么？

John：他们在往里面扔东西，尝试测量它的深度。

M.E.G.特工：这个举动有导致了什么吗？

John：有个人掉进了虚空里，现在杳无音讯。他大概是死了吧。

M.E.G.特工：在考虑接触之前，这些虚空仍然需要更多调查与探索。还有需要补充的吗？

John：呃……没了，大概就是这样。

M.E.G.特工：再次感谢你对这次采访的配合。待会来点杏仁水？

日志结束

入口与出口

入口

Level 210最常见的入口是穿过任意一堵5涂有国际象棋棋盘图案的墙。
触摸一盏故障的路灯会使流浪者来到这个层级。
打破Level 370的瓷砖有小概率将流浪者引向Level 210。

出口

目前该层级仅有三个已知出口。第一个出口是最方便且最安全的——等待。由于该层级的特性，流浪者无法在该层级中停留超6个小时。6个小时过后，流浪者将会陷入沉睡并切入后室的任意一个层级。

不推荐从第二个出口离开该层级。当与“我们”共进晚餐时，对“我们”抱有敌意将激怒“我们”。第一次，“我们”将原谅流浪者。但当流浪者第二次被“我们”视为抱有敌意时，“我们”将使流浪者从地面切出至Level 0。尝试触碰、伤害、威胁“我们”都将被视作对“我们”抱有敌意。任何物理接触对“我们”而言也是抱有敌意的行为，如握手等。

第三个出口是最危险且最不可信的一个出口。在公寓的房子周围存在着防止流浪者前往更远处的隐形屏障。触碰其或与其互动并无危害，但尝试破坏屏障将使流浪者从地面切出并来到Level 11。鉴于该屏障十分不稳定，也意味着这个离开层级的方法极不可靠且可能致死，我们极不推荐使用该方法。
