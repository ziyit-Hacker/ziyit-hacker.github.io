翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

描述

Level 126表现为一间画廊，拥有多个展示艺术作品的房间和大厅，其中大部分为文艺复兴时期画作，包括大量当时名家的作品。除少数有显著差异外，这些画作都是对原件的精确复制，甚至使用的颜料和材料都完全相同。

来到Level 126时，进入者会身处一个白色小型房间，房门为木质双开门，其上用蓝色油漆写着“用眼睛去看”。门右侧的墙上为层级平面图，但由于每次进入时层级布局都有所不同，这张平面图总是不准确的。走出门会到达画廊的随机部分。

尽管可以有多人同时进入Level 126，但从每个人的视角看，层级内永远是空无一人的。若两人同时进入层级，走出门后他们就会分开，直至离开层级后才会再次相见。

Level 126中，仅有希罗尼穆斯·博斯的少数作品与现实原件不同1，其中出现了众多原作不存在的人物，除此之外的部分与原作几乎完全一致。发现Level 126时画中多出的人数尚不明确，而随着对本层级效应的测试，画中的人数正在增长。

Level 126本身是绝对安全的，最危险的特性在于记录层级的方式。如果文档的长度超过了999个字词，作者（们）会在写下第1000个字词后突然消失，同时，他（们）的样貌将会出现在其中一幅异常画作上。语言、加密和记录方式（如手写、线上写作、录音等）均不会影响该现象的发生。

如果关于Level 126的信息带有层级图片，或者图片上带有信息，该现象也会立即发生，不过，除非以记录为目的，否则对层级或画作的非正式讨论不在此列。“被困”于画作者的真实状态尚不明确，目前也暂未有联系他们或将他们复原的方法。

Level 126入口处的字样，以及层级内部的种种迹象都表明，该层级的创始人（或者说，至少是维护人）名为“霍洛韦先生”，经过M.E.G.等团体的广泛调查，未能确定其身份和下落。

一位匿名流浪者在各大论坛和讨论版对Level 126表达兴趣之后，各团体收到了署名“FH”的回复：

我发誓，以前事情简单得多，不会有人死扣每一个细节，恨不得把艺术家的脑袋挖开去找答案。这就是父亲希望人们明白的道理，看来你们还是没放在心上。就这样吧，记住，要用眼睛去看。

此后，大部分团体调低了对Level 126进行研究和调查的优先级。

入口和出口

Level 126可以从Level 11和Level 230进入。在Level 11进入一栋门上方写着“霍洛韦先生的盛大展览”的建筑将会到达Level 126。在Level 230进入一扇写着“哈迪·霍洛的勤勉之厅”的门也可到达Level 126。

可以通过返回入口来离开Level 126，你会回到进入时的层级。
