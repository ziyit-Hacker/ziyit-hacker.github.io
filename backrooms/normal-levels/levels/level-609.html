翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

Level 609是一座宅邸，其建筑与装潢类似于19世纪末20世纪初的风格。

衰变带是蓝色通道的子层级，于2012年被发现。

衰变带是一座逐渐衰变的宅邸。它曾经的名称是Level 609。

描述:

Level 609的外观是一座建立于19世纪末20世纪初的英国宅邸，不过这里偶尔会出现无面灵，这些无面灵都穿着19世纪的女仆装。该层级有厨房、卧室、餐厅、走廊、画廊，以及佣人的房间。这些房间内存在大量的补给，可能是普通的食物或是杏仁水。

在该层级中偶尔能遇到几个房间，相较于一般的房间，它们有着更为明显的破败和废弃的痕迹，比如随处可见的蜘蛛网，或是明显缺失的家具。偶尔可以看到房间里有椅子、桌子、空书架或壁炉。这些房间里没有补给，而且实体数量也有所增加。除了更多的无面灵之外，据报告称该房间还会出现猎犬，有时也会遇到Lighter1，或是在墙上发现寄生涂料。

在这些房间中偶尔能找到一些窗户，通过这些窗户可以看到一片田野，以及远处的一个矿城。目前尚不清楚这是去往另一个未知层级的出口，还是说它只是通向Level 609的第二部分。

由于近期发生的事件，Level 609被更名为衰变带。原始版本的层级描述中提到了一些破败的房间，现在这些房间的数量不断增加，这事实上就是该层级衰变的信号。现在衰变已经遍布整个层级，为准确地描述该层级目前的环境状况，现已对该层级的描述进行了更新。

第一次修订

衰变带的外观是一座废弃的宅邸，在该层级的任何房间内都几乎不存在家具。偶尔能找到的几件家具包括椅子、桌子、火炉、储物柜、衣柜和暖气片。地板由中棕色的木材制成，走上去嘎吱作响，这可能会吸引实体或是引起其他不必要的注意。该层级的实体种类很多，如笑魇、猎犬和无面灵（不过他们表现得异常消极）。

墙上出现了一些破洞，露出之前未被发现的楼梯。尽管看上去你似乎可以在这一层级内无限地上升或下降，但实际上衰变带仅由三层楼构成，而当你不停地上楼或下楼时，你会这三层内不断循环。该层级的每层楼之间或多或少有一些相同之处，这会导致你难以判断自己正处于哪一楼层。不过楼层之间也存在着一些关键性的差异，这些差异有助于判断你所处的位置。

  • 第一层不存在能通过一般方式发现的楼梯，不过这些楼梯通常能在有破洞的墙后被找到。
  • 在第二、三层偶尔会遇到一些地板开裂的房间。已知穿过这些地板上的洞会将你传送至蓝色通道。
  • 第一层有一间古老书房的遗迹。书架的残骸散落在这片区域内，偶尔能从里面找到几本书。据说如果能够罗列之前存在过的所有书籍，或许它们可以呈现出一幅能够揭露某些谜团的图景。
  • 第三层存在唯一的通向Level -7的出口，方法是通过一扇门。尽管打破其他楼层的窗户也可能离开该层级，但不建议这样做，因为从高处坠落可能会造成伤害。
  • 在第一层，你偶尔可以发现一些血迹或是M.E.G.的旧物件。它们很有可能是在转移事件发生前建立的前哨站或其成员的遗物。

第二次修订

截至2020年7月10日，所有的实体似乎完全地从这个层级中消失了。与此同时，该层级开始展现出一些非欧几里得属性。看起来向上的楼梯能使你下降一层，反之亦然；看起来很长的走廊只需要几秒钟就能穿过。极少数情况下，如果沿着一条顶棚下斜的走廊前进，可能会出现尺度上的异常转变。这被认为是衰变的最终阶段，到最后，层级本身将变成一个完全的抽象概念。

当进入这一阶段，理论上来说该层级不再适合居住。因此，没有新的M.E.G.前哨站被批准建立，而整个衰变带也将被放弃。当该层级完全衰变后会发生什么仍然未知，据估计，距离该层级完全衰变还有约4年的时间。

基地、前哨和社区

M.E.G.（探险者总署）“佣人工作者”：

  • 小型M.E.G.基地，由10人组成。
  • 驻扎于层级内的一间卧室和一间厨房。
  • 从Level 101获取补给。

本层级没有已知的基地、前哨站或社区。

“转移事件”

通往Level 486的出口。

“转移事件”是一起将该层级从Level 609移动到目前未知区域的事件。据当时一个仍在正常工作的摄像机拍摄到的画面显示，层级内所有的灯突然关闭。2分钟后，可以听到隆隆的噪音，同时该层级似乎正在向左移动。移动停止的瞬间，该层级像是被突然向上发射一般，强烈且突然的重力压碎了家具，层级内的M.E.G.工作人员瞬间化为一滩肉泥。当该层级停止移动时，灯仍然保持关闭，墙壁接连坍塌，使该层级变成了现在的模样。

入口和出口

入口

Level 609能通过一扇Level 101的门进入。也可以从Level 125的第三个卧室进入该层级。

衰变带能通过Level 486的一座老宅邸进入，或是打破Level 0的一盏灯进入2。在尝试进入Level 27时也可能进入该层级。

出口

进入Level 609后，通常能以相同的方式离开。你也可以在餐厅内找到一扇通往Level 165的大门离开这一层级。

要离开衰变带，你可以找到一些门，或是打破窗户，它们都通往Level 486。另外，跳入第二层地板的洞会将你传送至蓝色通道。
