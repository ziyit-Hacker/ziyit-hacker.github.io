翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

一些存在于坎贝尔维勒内的风雨板

描述

每位进入了Level 237的旅人都会来到一个共同的地点，即一处位于单轨铁路站内的月台之上。 该站台自带一个标牌，标牌上有用油漆写就的字迹，但已因年代久远而淡去，故此仅能从已被阳光晒白的木牌上细微的色调差别中辨别出几个斑驳的字母——写作坎贝尔维勒。

轨道以单直线状呈无限延伸之态。火车站后则坐落着一个废弃已久的小型城镇。城镇中有多座房屋、一个汽车旅馆、一个杂货店和一个小酒馆。短道之一的路边有着一座学校和一处地上泳池，由砖块和其外部的混凝土建成。共六条街道组成了坎贝尔维勒的街区，但仅有处在火车站之后的那条街道经过铺设——退一步讲，这是唯一一条显示出了其曾被人为铺设的道路。

万物皆虚。

火车站本身感觉起来也不像实物。它自身带有一种并非实质的感觉，如一个陪伴着无人乡的无人车站。于是当你立足在了这个已是几乎半透明的月台之上，只为等候那列抵达与否揣测不得的列车时，坎贝尔维勒便会向你招手。一缕想要深入探幽的渴望回荡于你的胸膛，并在其中扎根，永不离弃。

在你行走于组成这个城镇的屈指可数的街道之上时，这些建筑开始变得更加实物化了。探险的召唤演化成了一种深深的怅然若失之感。太寂寥了。这份寂寥保持了太长时间了。

或许你会想驻足于此。

房屋上的风雨板除在屋檐窗沿垂挂之上仍然可见的褪去的油漆色彩外别无二致。前庭内生长着星星点点的草皮，亦有他者在已然弯曲的篱下滋长。这层植被还顽固地扎根于它之蔓延所向的土壤之上，即便在别处你已无法看见其他草类植物。

正当你走过一座有着两间房的学校前的操场时，你感到自己的孤寂阵痛开始减轻了。狂暴实体们的缺失让你开始疑虑为何此处会无人建立社区。

你能做到的。你可以长存于此。

你愈发深入坎贝尔维勒，这个城镇就会变得愈发真实。它感觉起来再也不像一片海市蜃楼了。或许甚至比你更加具象。

在建筑变得真实可感之际，你便开始消逝淡去。道路上席卷而来的尘埃不会再黏在你的鞋子上了，并直直穿过你的双脚。你也会注意到自己的发肤和衣物沾上了些许黑色。你也会回头瞧瞧自己影子的轮廓，一度被骄阳显而易见地投射于地面的它亦开始动摇了它的存在。

但这无伤大雅。没有什么东西被伤及分毫。终于，你已处在应在之处，仅存的一丝扰人思绪在提醒着你速速返回那处幽灵车站的界限内，去等候，去倾听列车的来临。司机将会为你而停，若你的形体足够实在的话。

在你消逝之时，你感到了这个城镇荒凉气息的缓和，你不该及时返回的。若你无法握住门把手去成排的房中一探究竟的那也不要紧，因为你现在已能够直接在墙壁间穿梭自如。

片刻后，叨扰你的最后一丝思绪将会转变为对时光流逝的简约愉悦——这是大多数探险者们都尚无时间去理解的一种极乐。当你感受到此种欢欣时，你已被全然磨灭。

你并未感到已被磨灭。你感到开心无比，在此素未谋面之地你从骨子里感到你一定知道过这处地方。很快，你的存在就将完全淡去，这方城镇会再次为它失去之物失声痛哭。

它亦会为你泣不成声。

基地、前哨和社区

除进行短暂停留外，在坎贝尔维勒内建立长期据点是不可能的。流浪者在坎贝尔维勒内从未遇见过他人——仅有一位探险者能独自在此消磨时间。但乘坐同趟列车来到此处的成群探险者并不会被拆散。

火车站

坎贝尔维勒内仅有一处相对安全之地。火车站为已长条状且覆有风雨板的建筑，其内部因时间流逝造成的损害似乎微乎其微。
车站内部由两个房间组成，在此流浪者可停留数日。较大的主厅内有着排列于墙边的长条椅，拐角处则立着一个空空如也的售票处。车站的内部空间为经抛光的暗色木板所覆盖，但流浪者们所能闻到的不是抛光蜡剂的香气，而是会注意到十分明显的尘埃气息。
在远小于主厅的储藏室内有着一些饮食补给。它们都可安全使用，然而其中的杏仁水却无法弥补实形肉体的缺失。
整个火车站由一种已经褪色的漆料粉刷。其中偶尔会有像老电影之内斑点一样闪动光点的出现及消失。显然，这个火车站也并非实物。
尽管这已是坎贝尔维勒内最不危险的地方，在此停留超数晚的流浪者亦会察觉到自身开始消逝，而车站则变得更加具象。

坎贝尔维勒股息券


所有已离开坎贝尔维勒的旅人都会在其口袋内找到一张来自坎贝尔矿业公司的股息券。上面有着如下文字：

坎贝尔矿业公司
在坎贝尔维勒的商铺或沙龙内，持券人可将其等值折换为价位为15美分的物品

若一个探险者团体的成员之一在坎贝尔维勒处迷失，那么该股息券的面值将按该成员所有的15美分之同等份额增加。
探险者们会发现这份“纪念品”是几乎无法丢弃的，在目光抵及之时他们会有一种强烈的怅然若失之感。
一位设法撕毁了这张股息券的探险者报告到如此为之时，其难受程度与目睹着他童年所居的家因修建高速公路而被拆毁无异。

入口和出口

没有哪位流浪者能够二次进入Level 237。

入口

  • 在后室之内任意层级中的火车最终将会停靠在坎贝尔维勒处。
  • 在前厅内的一趟长途列车旅行中入睡，这将可能导致该个体在一趟停靠于Level 237中的火车站的列车内醒来。

出口

  • 一趟列车到来时，若流浪者之形体仍然可见，那么司机将会停车并让流浪者登上列车。
  • 曾有已受到严重消逝现象影响的探险者报道过在极少数情况下，于列车靠站时站立于火车之前，并奋力想象着他们渴望去到的层级可令火车将其冲撞至所想层级内。


在你离开Level 237后你会黯然神伤，感极而泣。但这无伤大雅——人人皆会青衫湿。
