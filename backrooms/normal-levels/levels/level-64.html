翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

包裹在黑暗中的Level 64的照片。

Level 64是后室的第65层。Level 64似乎是一间无限的房屋，其中的照明设备尽数运转失常。

描述：

Level 64是一间无限的房屋，内有房间、走廊与楼梯。层级中，房屋装饰散落四处，其数目之多远远超过了一般日常家庭的规模。Level 64的黑暗会吸收光线，且光源在此无效。目前，M.E.G.正在构想一种能起效的方法。没有智慧生命观察时，房屋的结构似乎会发生变化，可能导致流浪者感到焦虑和/或偏执。而随着流浪者在黑暗中度过的时间越来越久，Level 64也可能导致流浪者罹患类似于黑暗恐惧症的症状。

Level 64中的家具与在前厅能找到的十分相似。不过，所有表面上都能发现规模明显的霉菌与灰尘。层级中的大部分区域都散落着大量物品，以至于一些物品以不可能的方式摆放着。层级中有着许多光源，但无法点亮——如果它们其实能点亮的话。所有书籍和其它文字材料的内容都是一片空白。在Level 64中能找到的许多房间和走廊都可能与正常情况完全不同，例如有房间摆满了滴答作响的钟表，而中心还有一尊老爷钟摆在其它许多钟表上，还有上下颠倒的走廊，空无一物的漆黑走廊等等其它许多怪象。

只有一种实体似乎在Level 64中出现。它们被称作“潜伏者”。潜伏者是人形实体，但有虫状身体。实体身高一般估计为六（6）英尺（约1.8米），少数报告称有一只潜伏者有二十（20）英尺（约6米）高。凭它身体一侧就有五（5）条的大量附肢，潜伏者可以爬上任何平面。这种实体是敌对的。见到人的一瞬间就会发起攻击。快速移动离开它的视野范围是逃离潜伏者的最佳方法，因为它们无法听到声音。潜伏者对光线敏感，这可能也是它们在Level 64的大部分区域都不现身的原因。

Level 64会通过未知的方式转变为一间普通而有限的房屋室内空间，其中有许多入口与出口。所有光源都会被点亮，这个阶段中也不会有实体出现。目前还不清楚该事件发生的原因和原理，因为若在Level 64中穿越太远，似乎事件就会随机发生。建议在这个阶段内通过许多通行点位离开。
