翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

“于尔至深思绪中，你发现了我。
发肤为石。
既已沐浴在空虚世界的阳光下。
那便无妨再伸出双手，开辟视界。”
——忏悔圣母


忏悔圣母正在监视着她的花园。

描述

Level 214曾是一个更大型层级的碎片之一，亦被人称作“忏悔花园”，即一片边长为13米的正方形空间，疑似处于一个“天空盒”之内。一条石子小径，一个独立花园区域和包围着场地的精锻铁栅栏构成了层级的整体布局，而雏菊、蔷薇灌木丛和一棵榛子树则占据了花园内剩余的空间。

花园之内可以听见微风吹拂，尽管Level 214内的平面天空并不会移形换景。层级天空盒内光芒闪烁的太阳保持着静止与无法触及的状态。故此温度恒定，从未超过30°C。这也让层级内的各种花朵得以生长，并保持着开花状态。

在Level 214中的流浪者会有一种不同寻常的，无视其进入层级时状态的宁静感。这一感觉的成因尚不明确，有关理论则断定这也许至是因层级自身异常性质或是维护着层级的实体所致。这让Level 214和Level 369存在着不少相似之处，包括在任意时段中仅有一位流浪者能出现在忏悔花园之内这一事实。

在Level 214内采摘花朵是不可能的，剪下或是切除任何枝条、叶片还有花朵的尝试只会让刀片或是钳子断开。这被认为是层级的看守者——忏悔圣母——在将一切维持着原状。她会不惜一切代价将花园维持在正常的形态。

Level 214和Level 600具有直接关联，包括其他已在Level 600内找到的花群，以及连接着忏悔花园的墙体结构之风格。居住于本层级内的“忏悔圣母”，亦声称在此之前曾到过Level 600，但如上所述，并没有Level 600之冲突的幸存者称能认出她。

Level 600内冲突的幸存者甚至不能回想起曾见过Level 214内的花园，但多数人都声称它对他们来说确实感觉有点眼熟。出现于Level 214边界窗口处之映射的尸体仍未有人认出，但上述层级之战后的老兵却发誓出现于窗面反射者都是他们曾经认识的人。

忏悔圣母

在Level 214所剩的碎块内，有着一个自称“忏悔圣母”的具感情实体。尚不明确她已在这个花园内存在了多久，但她声称自己是维护着其存在的唯一力量。此外，忏悔圣母极有可能是无法移动的，采取了怀抱着一位孩童的圣母玛利亚雕塑之外观。其高约2米，由一种外观类似大理石的材质构成。

向忏悔圣母询问其为何且如何维持该花园之存在通常会得到诸如“我即良善之牧者，真相之羊倌；是处即为我领域”的回答。以上，还有忏悔圣母所具备的其他能力，让多个团体的成员推断出该实体在某种程度上是全知的。

忏悔圣母身上所观察及经受到的行为经常都会出现于其要求流浪者们聆听其至深秘密及真相之时。多支来自阿尔戈斯之眼的巡逻队会频繁造访Level 214以从该花园的实体处获取知识，尽管需要付出代价。圣母将会为几乎任何问题提供答案或是知识，但代价则是进行前罪的忏悔。亦已知她能够察觉谎言，并会在此之后消极非攻地要求流浪者对其坦诚相待。

除了她所具备的预知能力外，忏悔圣母据称是享受与造访本层级的流浪者畅所欲言的，但尚不明他们是如何进行对话的。她的声音只是从其石质身体处传出，如同一位母亲的平和低语。通常而言，她所进行的对话话题多变莫测，但它们无外乎是些闲聊杂谈，与对其他各色流浪者之真相的披露，即便这些真相有多么隐秘。因此，我们极少建议流浪者向忏悔圣母揭示任何个人之实。

忏悔圣母被限制在了她的层级之内，但这并不妨碍她向求问者赐予与时俱进的知识。在M.E.O.D.研究人员（还有来自其他知名团体的匿名人员）的共同努力下，我们发现了在忏悔圣母在被问及目标个体行踪之时，会给出其精准位置和具体细节。有此证据，我们便可认为她在某种意味上的确是全知的。

+Dr.Kyung的测验访谈
-关闭日志

Lee Hyo Kyung
2022年3月18日
Level 214 - 忏悔花园

我正在撰写此测验日志，以进一步研究Level 214内目前尚未命名的实体。我会尽己所能去将一切尽可能地准确记录。

在到达Level 214后，我以大声呼叫之形式让其知道了我的到来。我报上了自己的姓名，并随即告知了我的身份。我并未说出我此行的目的，主要是为了保证假使会有其他流浪者造访之时我的结果仍能保持精确。实体“忏悔圣母”表达了她对看见有人造访此地的愉悦之情，在欢迎我时将我称为“她的孩子”。

测试1（问题）： “为何您对人们的秘密这么感兴趣呢？”

按照惯例，在得到答案前我被要求先给出我自己的一个秘密。为何我会盼望着不同之事的发生呢？作为回应，我便进行了2号测试。

测试2： 在被要求给出秘密时给出错误的回答。

结果（测试2）： “忏悔圣母”很快便意识到了我的答案的无效性。并说到，“我可不是蒙昧之人，孩子。你最好再诚实点[原句如此]。”

对不当问题的答复与已被记录在有关Level 214现有信息之内者相似。我则通过揭示我自己的一些真相以推进流程。

回复（测试1问题）： “我即良善之牧者，真相之羊倌；是处即为我领域。”这一回复在向上述实体所提出的众多独特问题中都是一致的。在进一步发问（并提供更多事实）后，我仅能得到有着更为明晰之形式的一个答案，“这便是我想获悉的真相。”

测试3（问题）： “您是怎样看到别处发生的事的？”

回复（测试3问题）： 又一次，我得到了我在进行第一个测验时所听到的同样话语。但是，”忏悔圣母“拒绝对其进行详尽阐述，即便我以提供真相作为代价。

结论：名为“忏悔圣母”的该实体已得到恰当记录，已经达到了我们所能理解的最大程度。我们可以证实研究员Lane、Bin-Salman和Emerson的确已对记录文档之事业全力以赴了。

基地、前哨和社区

鉴于任何时候Level 214个体之内都无法出现一位以上的流浪者，所以层级内现在并不存在前哨。除此之外，Level 214内的空间对于容纳任何大型建构来说亦属于杯水车薪。

入口和出口

入口：

  • Level 369内极少数时候会出现一扇金属制花园大门，流浪者可从此进入Level 214。
  • 与之类似的大门会在Level 10内出现，可将流浪者带至Level 214内。
  • 在Level 165内找到一个隔断区域可将流浪者带至Level 214内。
  • 尝试在Level 84走出迷宫可让流浪者来到Level 214内，尽管希望渺茫。
  • Level 11内的花店有时可将流浪者传送至Level 214，但正如之前所提到的Level 84内的入口，这一情况发生的概率很低。

出口：

  • 自人们走进的大门处离开会将流浪者们带至369、165、10或是84等层级。
  • 自Level 214跳下并坠入天空盒内会将流浪者带至蓝色通道或是Level 371中。
