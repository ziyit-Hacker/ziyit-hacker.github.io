翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

Level 68其中一间房间的照片。本照片由一名已注销账号的未知用户拍摄。

Level 68是后室的第69层。其为一巨大的电影院；建筑像是美国东北部地区使用的风格。Level 68中的物品本质上都是生物性的，真菌的生长遍布此处。

描述：

Level 68的物理外观像是一巨大的影院建筑；具有延伸极长的走廊，走廊两侧的门各通向不同的房间。这些房间中放置有一排排座椅，每排各具不同的数量和造型；不过，它们始终是红色的，粘液状的物质覆盖在其表面。尽管存在这些异常且整体令人反感的特点，但人们通常还是会倾向于坐在距他们最近的座椅上，这通常被描述为异常舒适。

一旦房间中的所有个体都已入座，这些座椅将释放一种会快速液化并再固化人体组织与布料的化学酶；这通常会最终使个体与座椅融为一体，使得一个人不可能再凭一己之力从上面离开；不过由于这些座椅对人类精神的影响，人们通常不会想起离开座椅这件事。

一旦这一进程完成，在房间中的大荧幕上将会开始播放电影。不同房间播放的影像各不相同，而且不是任何后室外存在的电影。这些电影通常本质上只是一些图像；虽然人们在观看这些视频时通常不会做出排斥或厌恶的反应，但这可能意味着这些视频具有催眠作用。

一旦电影结束，观看它的人将在死于休克前被暴力地抓住。此后，他们的身体将被消化酶破坏，被座椅吸收，而残余物或许会被转移到Level 68的其他部分。鉴于此，并不建议身处Level 68的人进入这些房间。

基地、前哨和社区：

目前为止，在Level 68中并未找到人类基地；不过一些画作和文字使人们相信一些团体或许位于本层中某个未被发现的地方。

入口和出口：

入口

Level 68可通过在Level 11中寻找到一座电影院来进入。

出口
  • 切入荧幕将会带你去往Level 94。
  • 本层中存在一些位于拐落处的门扉，它们之中一些红色的门与Level 117中的一扇门十分相似。穿过这些门会带你去往Level 74。
