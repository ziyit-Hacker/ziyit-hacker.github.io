使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/

--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;

描述

Level 602的景观。

Level 602，最初名为PA462，为一片带有城镇及远处山峰之幻景，长度无限的盐原。及此刻落笔时1，据信该层级仅有的实在部分就是这片盐床、浓重而闷热的空气与蔚蓝的天空。这种遥远的地貌与非自然特征要么是一种热力幻景（一种幻觉），要么是一种来自非欧效应的永久的遥不可及感。

盐原的地面（由盐、陶土以及乳化了的鱼类化石组成）柔软且脆性，容易在重压下屈服。温度有波动但保持在300K（约27摄氏度）左右，且层级602内亦缺乏大规模风动气流，而不存在自然通风。

在Level 602内短期生存的唯一方法是利用好该层级内的烈日以获取可供风扇使用的太阳能。但由于其地面软泞，因此仅能在此支立起帆布质结构，而建造实用庇护所则不切实际。同时也已知，这里风速虽低，但含盐复合物也能损毁即便是最为现代的翻修与科技部的精巧发明。要么是出现于水分残留中的独特微粒所致，要么就是普遍的后室异常的原因，损毁的机械是无法修复的。

所以这些因素使得在此生存的尝试毫无作用。这里没有天然的食物与水源，也没任何可搜刮的东西，可学习的事物或是可前往的去处。此即表面，M.E.O.D.一直都乐意被证明其错谬。只要有人想大体加入Level 602的考察的话，他们便可向旅游、军事、研究或是探险部门报名参加。#广告位

入口与出口

Level 602仅能通过Level 688表面岩石处的一扇活板门到达。该活板门双向可用。

不为绝大多数如今的前M.E.O.D.公民所知的是，先前所提及部门的上层持续不断地批准着前往Level 602深处而毫无所获的勘探行动。很不幸也不出意外地，这些勘探队无一载果而归。任何没被解散或是杀害的队伍则都已丧命。由于在清剿之后再无文字记录留存，且因为在2095年前后M.E.O.D.实施的“除废政策”的缘故，这些行动一直得以批准的因由不甚明了。

那便表明，回收来的讯息刻画出了被施虐式腐败所利用着的毫无必要的官僚作风。几乎是在该层级被发现的当即，赌局文化便在部门领导与直属下级间遍地开花，持续不止，直到该团体消亡。
