这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;

[[/module]]

描述

Level 469是一片矢车菊田，被一条道路分割成两半。天气一贯晴朗温暖，但环境温度与表观温度会随风云变幻而浮动。道路两侧的路肩铺有砾石，一些区域表现出与机动车轮胎印吻合的凹陷。该层级表现为环状，沿道路行进或穿过花田终将回到原点。道路两侧各有一道栅栏，通常由短木梁构成，其间用金属丝或木横梁串连。栅栏的一些区域存在破损或缺失，可被轻易拆下并由此进入矢车菊田。道路显著表现出磨损与维修迹象，已知其上坑洞存在绊倒的风险。树木稀疏，没有原始的人造结构存在于此。

尽管矢车菊田里的花草被注意到随时间的推移枯萎并重生，但矢车菊通常保持盛开。一些土地上稀疏地混杂着德克萨斯州北部其他常见的野花，各种矢车菊皆可在田间被发现。矢车菊在田野上成片生长，对流浪者无害。相对彼此而言，这些田地通常不起眼，并且似乎会随时间的推移而发生变化。虽然采花是安全的，但从该层级将其移除会使其迅速枯萎。那些希望带走花的人应当在Level 469通过包裹、按压或干燥的方式将其保存，然后离开。这种迅速的枯萎只影响该层级的花，而不影响其他物品，如采摘的草或在废弃车辆中发现的物品。其原因未知。

车辆偶尔停于路肩，鲜少停在道路上。这些车辆以三厢小轿车和运动型多功能车为主，其内装有的物品包括但不限于包装零食、瓶装水和饮料、路线图、背包、笔记本、书写用具、便携式音乐播放器、手持游戏机、音乐光盘、带解冻冰袋的冷却器、衣服和纪念品。绝大多数机动车上了锁，但可以轻易破开。车辆发动机不可正常工作，油箱是空的；对其进行修复的尝试未能成功。车辆可能消失，新车会在未被观察时出现，形成一个新的、尽管有限的稳定补给来源。除这些车辆外，还罕有人造结构出现。该层级缺乏人类或动物生活的迹象。

由于缺乏地标，难以在初入该层级时利用景观确定方位。然而，流浪者常常通过记忆“永久”车辆1、道路方向的变化、景观中的山丘与溪谷以及流浪者建造的庇护所等值得注意的细节组合来学会导航。被流浪者长时间2占用的车辆似乎会成为永久车辆。流浪者对道路、栅栏、矢车菊田造成的破坏已被注意到随时间推移“自行修复”。永恒的白昼可能导致对时间的感知不再准确。尽管这并不危险，但可能使流浪者迷失方向，并导致流浪者在Level 469居住期间的慢性时间盲。

尽管Level 469相对安全稳定，但一些流浪者无法长期逗留。那些离开的人常说，该层级强烈的天电干扰与不变的自然环境使他们迷失方向并感到焦虑和担忧。这种对该层级的“容忍度”差异似乎并非后室的影响，而是个体之间的自然差异。

在此层级无法发现任何实体。仅有的居民是人类。

基地、前哨与社区

该层级不存在常驻社区。绝大多数居民都将汽车或户外庇护所作为个人居所。一些居民过着更短暂的生活，他们在游荡于该层级时随身携带物品。新来的流浪者会受欢迎，尽管该层级的居民是较为孤独的。那些计划在该层级定居的人被建议与该层级当前的居民会面。

著名地标：旅者阱

旅者阱是一个有着幽默名称的休息站，由一辆罕见的十八轮货运卡车改建而成。它是无人值守的，不受监控，流浪者被鼓励在前往其他层级或在Level 469找到永久居所之前暂时使用这片空间。长期“蹲”在旅者阱不受鼓励，因为居民们认为这违背了其作为临时公共设施的预期用途。作为存在于该层级的极少量大型车辆之一，其名被喷涂于货箱正对路面的一侧，极易被识别出。除用作休息站外，它也是贸易与信息的主要媒介。

著名流浪者：Angie

Angie声称自己是首个发现该层级的流浪者。其他多名居民已证实这一点，他们表示，当他们来到此处时，她已在场。尽管Angie作为社区领袖的特殊地位并未因此被承认，但她对该层级的了解也已导致创造了免费使用的粗略地图。Angie非常不喜欢居住于该层级，被其他居民称为“长期抱怨者”。尽管如此，她似乎是一名永久居民，并否认有任何离开的意愿。她常建议流浪者不要在该层级花费太多时间。据她说，人们会不可避免地被“困”于该层级。对于那些愿意倾听她的沮丧的人，Angie将赠送零食或小饰品等礼物以示感谢。

她的家是一辆绿色的运动型多功能车，通过放在砾石上货箱后的两个座位和悬挂于车内的帘幕可被轻易辨识出。

入口与出口

进入该层级最常见的方式是在穿过草地时或行路时向下看。离开需要相同的方法，穿过矢车菊田或道路。
