翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

该组件支持简繁切换，如下方代码所示：

在lang 处选择语言，cn 表示简体中文，tr 表示繁体中文，不填默认选择简体中文。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

Level 471，也被称为蛛网公路，是一个庞大的公路网络，没有可感知的起点或终点。

Level 471中公路的照片

描述

Level 471的公路构成蛛网般的多层网络，层层叠叠，无限延伸，直至渐渐淡出视野。永恒浓雾笼罩着公路，超出某一范围后便几乎视物不清。公路本身具有非欧几里得特性，以不可预测的方式移动、循环，与传统空间逻辑全然相悖。试图建立固定参考点的尝试均以失败告终——地标要么出现在错乱的位置，要么彻底消失。Level 471还具有与Level 0相同的孤立效应，使流浪者无法遇到其他同伴。尽管在此层级中能看到其他公路，却没有成功进入的途径。

在Level 471内，时间并非线性流逝，这致使流浪者的时间感知严重错乱。因此，有人称存在明显的记忆断层，另一些人则表示，短暂的瞬间会显得异常漫长，甚至被拉长成难以忍受的时长。Level 471中一个常见现象是高速车辆的出现——这类车辆多从雾中骤然现身。据流浪者描述，远方会骤然亮起刺眼的车头灯，高速朝他们冲来；然而，在疾驰数秒后，这些车辆便瞬间消失。

这一层各处散布着大量标牌，位置似乎杂乱无章。其中不少已严重锈蚀，虽看似不堪一击，却又坚不可摧。奇怪的是，这些标牌的信息显示方式与普通标牌截然不同——文字已近乎褪色、模糊难辨，但人们仍发现上面显示着各类文字，比如：

  • 晦涩的信息
  • 二进制代码
  • 无意义的词汇
  • 用未知语言书写的信息

停电

“停电”是一种异常事件，当流浪者在Level 471停留过久时便会触发。事件发生时，路灯骤然熄灭，公路陷入一片无法穿透的黑暗，与Level 6的黑暗颇为近似。任何人造光源都会彻底失效。 此时，能听到低吼与尖叫从周遭黑暗中回荡。这些声音常被描述为非人的，且令人不安地迫近，但其确切来源始终成谜。

一旦这类事件开始，你最好立刻离开这个层级。天知道黑暗中可能潜伏着什么。

基地、前哨和社区

尝试建立此类定居点被认为是不可能的，因为该层级缺乏任何必要的资源，且不适合人类定居。

入口与出口

入口

  • 若流浪者驾车撞向Level 69的混凝土墙，便会进入Level 471，因为这会导致切出事件的发生。
  • 此外，通过进入Level 4中一个门上有类似高速公路标志的房间，也能进入Level 471。

出口

  • Level 471可以通过一个下水道井盖离开；这会将流浪者引向Level 34。
  • 试图破坏标牌会将流浪者传送到Level 9。
  • 从高速公路上掉落会将流浪者引向Level 78。
