翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

在lang 处选择语言，cn 表示简体中文，tr 表示繁体中文，不填默认选择简体中文。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

太空景观是后室中的一个隐秘层级。

该层级是一颗被命名为“Kryok（科莱欧克）”的行星。

描述

对太空景观中星空的描绘。

太空景观是一颗红青相间的行星，其名为“Kryok”。唯一一种出入该层级的方法是在后室中陷入昏迷，随后醒来。该层级内的重力系数较低，与月球相近。由于抵达过太空景观/Kryok星的流浪者为数不多，我们目前依旧对其所知甚少。

出入太空景观的方法非常特殊，如上文所述，你可以通过在后室内昏迷来出入该层级。流浪者具体抵达该层级的过程是未知的，他们在此期间仍然清醒，但会陷入某种精神恍惚的状态，直至在太空景观内醒来。

与水星类似，行星之上存在着一座巨大的火山口，该火山口被命名为“CRAT-2736”。尽管探索者们已努力尝试，但迄今为止尚未有人成功翻越过该火山口。在该层级内会出现的实体并不多，然而有人表示，他们曾用余光瞥见过穿着宇航服的人，且Kryok星上也存在着异星人1。此外，你在该层级内无法死去。在该层级内，无论你使用何种物品自残或自杀，都只会导致物品穿过你的身体，而你安然无恙。

除火山口之外，同样也有多处景观/地形结构被发现。其中最令人在意的是，部分流浪者与M.E.G.成员曾发现过一些建筑，其外观酷似冰屋。在这些建筑内会出现桌椅、床铺、学习用具、空置的小冰柜与破损的宇航服。这些宇航服通常以白色为底色、漆着黑色条纹，并绘有LOGO图案；LOGO图案类似一个黑色的正方形，其内包含一个黑色的“X”，方形之外则有一些角状花纹。根据报告来看，这些宇航服的尺寸与型号似乎都是相同的。同样值得注意的是，一旦离开建筑物的半圆穹顶，建筑将即刻消失，再也无法返回。

Kryok星似乎处于一个星系之中，与前厅内的太阳系类似。然而由于该行星上微重力的特点，前往其他行星几乎是不可能的。星系之中的其他行星分别被命名为“Zeek（齐克）”、“Proto（普罗托）”、“Visti（维斯提）”、“Moik（莫意克）”、“Crypt（窖）”、“EX-123”与“POZA-808”。虽然存在着诸多行星，但是它们似乎都没有卫星。它们似乎都会自转，但不会在整个星系内公转。这些行星的外观如下：

  • Zeek：距离Kryok星最近的行星。该行星整体呈橙黄色，其上有一个巨大的白色斑点以及数条黑色环线。
  • Proto：距离Kryok星第二近的行星，颜色发绿，其外有与土星相似的星环。
  • Visti：距离Kryok星第三近的行星，颜色呈粉紫色，且似乎不会自转。有传言说该行星上曾经坠毁过一艘巨大的UFO，将其直接撞出了轨道，这也说明了该行星不会自转的原因。
  • Moik：距离Kryok星第四近的行星，绿色，表面覆盖着许多巨大的棕色脉络。
  • Crypt：距离Kryok星第五近的行星。Crypt星以及其之后的行星都难以观测，不过依旧处于视野之内（除了POZA-808）。Crypt星的外表呈现红色，覆盖着大量黑色脉络，与Moik星相似。
  • EX-123：EX-123几乎无法用裸眼观测。其外表为闪耀的灰色，推测为金属形成。
  • POZA-808：距离Kryok星最远的行星。其外表未知。

实体

本层级内存在着两种一种实体，分别为宇航员与异星人。

宇航员的外观与那些巨大穹顶之下掩埋的宇航服大致相同。此实体并无太多行动，只会持续跟踪流浪者。所有企图与它发生物理交互的尝试最终都以失败告终。该实体是否有害、其身份来源等相关信息皆是一片空白。

在该层级内生活的另一批实体被称作“异星人”。关于异星人是否只是一种昏迷导致的幻觉，这一点在M.E.G.目前尚无定论。异星人的外貌恰似流行文化中对于“外星人”的刻板印象，它们有着巨大的头颅与眼睛、小巧的口器与骨瘦如柴的躯干。在与它们接触时，异星人总会缓缓淡出——通常是直接消失。如果在你接近一个异星人时，它没有表现出恐惧并逃走、或是直接消失，那么你会发现它正在注视着你。该类实体对于人类似乎并没有恶意，因此与它们接触并不致命。

基地、前哨和社区

由于该层级特殊的出入方法以及其内特殊的性质，在此建立社区或前哨似乎是不可能的。

入口与出口

只有在昏迷期间陷入一种“恍惚”状态才能进入该层级，而从昏迷中苏醒则会将你同步带出。
