从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]

--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

    孤立在永夜中的路灯

    描述

    Paradise 772表现为一片无尽的平坦场景，其中随机分布着几盏完全一样的路灯。

    一片压抑而漆黑的天空笼罩着目光所及之处，让整个场景陷入永夜。天空的黑暗，加上诡异的寂静，一次性影响着你五感中的两种，由此，不安、偏执的心绪萦绕着你。

    天空中可以看到一些星星。但我无法分辨它们究竟是真正的星星还是悬挂在天空中的白点，可见地，它们离地面很近。

    性质

    路灯同时作为此天堂的主要光源和唯一的人造物；这里完全没有结构和材料，有的仅仅是偶尔出现的高大漆黑墙壁。会挡住通路并形成迷宫。这些灯高约4米，只能照亮地面上的一小片圆形区域——光线到不了更远的地方。利用这些灯所处的位置是通过层级的唯一可靠方法。

    实体？

    偶尔，灯的下方会站着一个黑色人形。这个身影没有任何面部特征，至少我从远处所能观测到的便是如此。我无法得知此身影是否具有敌意，甚至无法确认它是否有生命体征。若是你决定继续前行并把目光移开，这个身影就会向你的方向倾斜，同时保持固定位置不动，仿佛在注视着你，等待着机会。然而，如果你决定靠近它，这个身影将会突然消失。

    入口

    唯一的入口是与彩虹宝珠互动，同时吟诵Paradise 771大图书馆中金色书籍中的诗篇77:2。

    出口

    连续行走数小时后，你最终会遇到一盏闪烁的灯。站在它的下方，它会使你到达下一Paradise 772

    孑然一身。
    迷失，于黑暗中。

    世上尚存者，皆为咎由自取之罹害者相息。

    汝岂不识这影翳，这残息？

    他们当因汝矗而守望，寄以余生；亦当于汝决计近前时无可捉摸。

    永恒的孑然，唯汝族类的空寂世界，可曾惧否？

    又当能受之乎？

    观察倒计时

    描述

    Paradise 772表现为一片无边无际的田野，让人联想到乡村环境。

    在此处，你将不可避免地发现两种设施的精确复制品，它们将在你的探索过程中反复出现。它们均是用砖块砌成的农场建筑；谷仓与温室。

    当你进入时将处于晴空下，令人惊讶的是，你不会看到太阳，而是一个带有四个巨大红色数字的倒计时。随后显示着分的倒计时将开始倒数。

    性质

    随着倒数，我注意到此处有三个阶段：

    阶段1（00:00）

    此处在你到达的前5分钟将处于白天。在这种状态下，层级可以概括为一个阈限空间；空旷而熟悉，异常安静又令人安心。不过，我建议你不要浪费太多时间，并尽快为下一阶段做好准备。

    阶段2（05:00）

    一旦倒计时到达05:00，天空就会开始变暗并呈现出灰色色调。你会听到背景出现群鸦的叫声，尽管此处看不到任何乌鸦。此阶段是进入下一阶段的警告。

    阶段3（06:00）

    仅1分钟后，天空就会变得漆黑一片，只剩下倒计时。虽然倒计时的数字是红色的，但地面会被一小束白光所照亮，足以让您感知到周围环境的基本情况。在此阶段，有意识的阴影将出现在室外的任何地方。它们的形状可以描述为扭曲的抽象图案，这使得它们在黑暗中难以被察觉。想要发现这些“实体”的唯一可靠方法是依靠它们所发出的风声，但在此阶段中，躲在基础设施中会更加安全，因为这些身影具有敌意，且会追逐它们发现的任何人。一旦被发现，你除了逃跑外将别无选择，因为接下来“实体”会一直知道您的位置。

    时间快到了

    循环完成（12:00）

    6分钟后，此处将恢复到白天状态，所有实体都将消失。然后，此循环将不断继续。然而，在每个循环后，基础设施都将变得比之前更加破旧，地面上会出现垃圾和废料等障碍物，如果你不够小心的话可能会被它们绊倒。随着循环重复，上述的环境影响将会不断加剧。所以你最好继续前进，远离你的起点远，再远，有多远逃多远。

    在某个时候，当你因为无处可藏而快速穿过荒废的田野时，你会看到一道光划破漆黑的天空，然后远处的一座灯塔便出现在你的视野里。
    进入灯塔后，你会慢慢失去意识，然后————

    入口

    站在Paradise 772闪烁的路灯下。

    出口

    在倒计时达到60:00之前进入灯塔2，它将。

    滴...答...
    时间到了。

    何事端将生？

    当时计倒数，始壹圆满时，有何事端将生？

    汝之周遭，是否将崩陨？

    旋即困陷于崩解位面中，偕余见证我们皆渴求的终末——

    复而囚困于时光永恒的渊狱中。

    此等情景，辄将降临。一切都将只是时间问题。

    描述

    Paradise 772是一片乌有之地———— Paradise 772的外表类似于一个”电子游戏沙盒“。

    未完成的材质纹理、概念阶段的实体和物品的原型在这个天堂中都十分常见。

    一个无比适合创造者的环境，毫无疑问。

    你可以天堂中发现一种模型：它主要（有时并非全部）由低分辨率的黑色多边形组成，在不同区域中拥有不同颜色的轮廓。多边形的材质类似于聚乙烯4，并具有大致相同的摩擦力和密度，但其强度要大得多，以至于无法被破坏。

    你会发现自己身处一个与许多其他平台相连的大型浮动平台上。下方可以看到的是不断移动的网格。网格的表面是几根上下浮动的线条。此网格的用途尚无法定论，且可能注定永远如此。

    主平台分为两个区域：住宅区和城镇区。

    住宅区


    此区域类似于开放式的顶层公寓，下层延伸至天堂的更深处。建筑奇异无比，大多数房间均是不对称的，完全没有家具，而且经常有通往相邻房间的开口；楼梯经常通向死路，奇怪的物体会出现在最意想不到的地方。

    住宅区最引人注目的建筑是位于其顶层的金字塔。

    • 神居
    • 未确认结构

    圣间

    当你进入住宅区的金字塔时，一条下行的楼梯会出现在你面前。

    走下楼梯后，你会发现自己身处Paradise 772的圣间。建筑轮廓的颜色多种多样，从白色到灰色各有不同，八根线条彼此平行。

    神典

    在你面前，你会发现一个奇怪的动态材质，看起来像是蓝色背景上移动着的代码行。它的材质本身是液体，因为当物体被扔进去后会产生像水一样的波浪。如果你试着与纹理产生互动，你的脑海中就会出现无法言说的景象。一连串场景迅速展开，以至于你几乎无法理解它们。最后，在效果消失后，一道闪光会将你致盲并短暂昏迷，然后，你会经历持续约5分钟的剧烈头痛。考虑到这种物质哪怕是最轻微的接触也会导致严重的危险，我无论如何都不建议你潜入水中。

    神言

    在房间的后方，你一定不会错过一个大屏幕，上面显示着两个白色球体，类似于眼睛，或者我猜测是上帝的象征。如果你靠近屏幕，就会出现一段文字并开始滚动。据我所知，这段文字由几个短句组成，构成了一首挽歌，献给我们最亲爱的造物主：神。

    城镇区

    边界

    这一地区有许多让人联想到古希腊风格的建筑元素，整个地区有着几座寺庙和遍布该地区的雕像。而在镇中心的后方，一座雄伟的桥将通向一座比其他寺庙大得多的寺庙。穿过500米长的桥便可以到达寺庙的入口，彼时映入眼帘的便是一座雄伟的大厅，在远处，你会看到一张桌子立在两扇大门前。桌子上缺少一些事物，因为上面有着四个镂空的形状，需要在里面放上相应的物品。

    概念岛屿

    主平台可以通往其他四个平台，其中分别包含了四件造物。它们的外形看起来几乎一模一样，表现为不同颜色轮廓的多面体。然而，这些平台的环境却各不相同。以下是四个可前往的平台：


    • 北侧平台
    • 南侧平台
    • 西侧平台
    • 东侧平台

    北侧平台：一座由浅蓝色轮廓的多边形组成的巨大山脉。环境可以称之为危险，由于其多边形的结构，很容易从斜坡上滑下来。第一件造物位于山峰内部的洞穴中，周围环绕着许多圣典，因此在尝试取回它时请务必小心。

    南侧平台：一片由浅绿色轮廓的多边形组成的平原，一条圣典河流经此地。第二件造物位于河周围的众多建筑之一中。

    西侧平台：一个黄色轮廓的多边形组成的迷宫，与Paradise 0类似但不完全相同。第三件造物位于场地内的某处你最终会找到它。


    东侧平台：一座由粉红色轮廓的多边形组成的城市，类似于Paradise 11，但除了第四件造物位于最顶层的摩天大楼外，其他建筑物均无法进入。这里没有电梯，所以你必须走楼梯。
