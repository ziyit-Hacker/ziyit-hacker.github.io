翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;

}
[[/module]]

描述

探险家约翰·卡西迪（John Kassidy）声称在层级{ʡ}中看到的3D渲染图。

Level {ʡ}，从这里开始被称为“域（domain）层级”，是一个包含 Raimar Wulkenhaar 猜想 Collatz 猜想 数学方程 x = x 的所有解的集，其中所有解都属于 所有实数的范围，包括 人 实体 现实 概念 范围 {ʡ}，其中“ʡ”表示属于至少一个精确概念的所有包含物以及属于域 {t} 的所有输入，其中“t”表示所有理论概念。“精确概念”被定义为在所有现实中表现一致的事物，并且在某个时间点至少在或曾经在一个事物的心理占有（mental possession）范围内。例如，数学在现实世界中永远是正确的。无论符号或数学本身在不同地区或现实中的含义不同，它都将永远是正确的。因此数学可以被定义为一个“精确概念”。所有属于“数学”这个概念的具体概念都在精确概念的范围之中。在所有现实中，现实本身都是真实的。因此，现实是一个精确概念。“现实的概念在所有现实中总是正确的”这一事实被理论化为这个层次的存在方式。在所有现实中，重力都是真实的，因此是一个精确概念，并存在于域层级中。 推论无效，两个现实被概念化，重力不存在于域层级之中。

这个层级的外形类似于

一个很长的弦，附带着域和范围内的所有内容

无限多的弦，每条弦代表一个精确的概念，这些精确概念下的每个精确概念都作为新的弦绑定到它们各自的父弦上

同性恋骄傲游行，每个人与事物都代表一个概念

一个无限的图书馆，图书馆中的每本书都包含与父主题相关的每个精切概念

什么都不是，因为人类的大脑无法理解无穷大

前厅的一家餐厅，被称为“哈德逊披萨屋”

一个大豆卷饼

探险家们自己的身体，仿佛他们已经死了

一个三维空间，仅由色彩柔和的蓝色规则多面体组成，呈网格状图案，在每个可能的方向上无限延伸。在某些顶点处，存在一个核绿色透明或半透明的蓝色球体，测量直径约 9 英尺 3 米 英尺 英寸。每个球体都包含一个概念，并且当触摸球体时，会将一个心理平面（mental plane）投射到代表球体概念的头脑中。这些头脑不一定是实在的物体，并且可能无法看见。但是，所有球体都是有形的，并且可以概念化。每个地区（area）或区域（zone）（每个区域大小约920万立方英里）被一个大球体包围，理论上是包含每个概念的球体的更大版本。这些较大的球体代表精确概念。

从理论上讲，可以精确地计算出这个层次中的概念分布于何处，从理论上讲，可以使用函数 v3 + w3 + x3 + y3 + z3 = k 并持有域层级的钥匙或钥匙残片，同时将上述方程的解想象为复杂概念的范围来进行运算，其中，“复杂概念”是任何存在中理论上可能拥有的任何概念，无论它是否存在。在步骤正确的情况下这样做能把你带到尽可能接近你想要去的地方。错误地使用这种方法或者将设定的目的地概念化到所有精确概念的概念范围之外，可能会产生可怕的后果，包括时间和空间异常，并将这些异常在你个人或我们的现实中表达出来。

探险家约翰·卡西迪记录到做出了不正确的计算，他不小心让方程的解表现为一个异常小的，纯白色的妖蛆（Wyrm），它试图咬掉他的手。妖蛆在接触他之前变成了甲烷气体，气体在几秒钟后消失了。他认为他非常幸运，因为如果他能够召唤出神话中的前厅野兽，他便可以召唤出完全不同的，更危险的，甚至可能是不会消失的其他东西。强烈建议将来任何人不要使用这种旅行方式，直到找到解决上述问题的方法，或者找到可以代替当前等式的新等式。如果必须使用此方法，不要尝试概念化不存在于当前现实的任何内容。

基地，前哨与社区

由于新现实持续不断地变化和创造以及旧现实不断地被破坏，这个层级的不稳定性使得在这个层级中几乎不可能建造一个可持续的基地或前哨。将人们运送到这个此处本身已经非常昂贵，更不用说只是简单地休息就有机会把在其中的人传送到其他的层级。然而，每个理论上可能和不可能的基地和前哨已经存在于域层级的某个地方。这些基地与前哨是否真实存在尚未确定。

实体

任何已知和未知的可想象或不可想象的实体在级别域中至少存在一次，它们是对于它们所属的每个处于确切概念之中有关它们的概念的重复。然而，这些实体只是在概念上是真实的，并没有表现出我们认为的“正常”行为。

入口与出口

入口

一个进入域层级的方式是在Level -2、蓝色通道，Level 18或者Level √2找到一把层级秘钥（目前，在Level √2中使用了一个超过20人的团队才找到唯一一把钥匙。这个方法不可靠。这把钥匙也是没有物理形态的），也可以在Level 9的钥匙链上面找到通往这个层级的钥匙。通过闭上眼睛，拿着钥匙或钥匙层级，并在脑海中概念化一个在所有现实中一致的模式或概念，你将被传送到域层级。

密钥在使用时消失的可能性约为45%。应该注意的是，只有大约27%的秘钥是进入所必需的，在使用时可能消失的只有那一部分密钥。一次只能有一个人使用密钥，也就是说，多个人拿着一个秘钥或秘钥碎片时传送如果成功，进入域层级的只会有一个人。最近，在尝试域层级是否可用作补给供应链的其中一站时，发现每次旅行的重量限制为250公斤。

进入域层级的唯一其他已知方法是在tgochi.exe上完成“高中辍学”成就。（在弗里曼先生的讲座里坐了累计三十个小时，然后翻倒一张书桌）并兑换奖励。这样做后将立即被传送到域层级。每个帐户只能触发一次。

出口

相比于极其有限的入口，离开域层级令人吃惊地非常容易。通常，在任何精确概念区域入睡或失去知觉都会被传送到到不同的层级。此过程不可靠的唯一原因是每个密钥会消耗大约6次使用所产生的耐久损失，区域变化的可能性以及前面提到的限制。

在“惩罚”的精确概念区域入睡通常会导致在Level 52醒来，坐在这一层级其中一间教室的书桌前。在这种情况下会有极小的机会让入睡者在Level 448覆盖草地的岛屿上醒来。

在“隐私”的精确概念区域入睡将导致在Level 12醒来。

在“空间”的精确概念区入睡通常会被带到Level 78。有一次，探险家被传送到Level 20。

在“和平”的精确概念区入睡会让你在Level 63醒来。

强烈建议不要在“享乐”的精确概念区域入睡，因为它的名字以及近来发现的相关性。

其他区域的入睡测试尚未展开。
