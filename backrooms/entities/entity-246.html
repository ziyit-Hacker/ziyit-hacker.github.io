Andrew 还与我们同在吗？

描述

“心”，于 Andrew 死前拍摄。

Entity 246，即 29 岁的 Andrew Donovan，是一具漂浮在一片封闭心形水池（因而被称为“心”）中的尸体，约四个月前出现在岩体泉中。我们不清楚他的尸体是如何到达那里的，但目前的主流论断认为他是在水中心脏骤停，随后溺毙而死。不幸的是，“心”那与普通温泉不同的高温（80-90 摄氏度）令我们难以回收他的尸体。尽管身处高温之中，他的尸体却没有表现出分解或受伤的迹象。

令人惊喜的是，Andrew 似乎还能表现出生命迹象。他偶尔会轻微抽动肢体，或发出呼救声，尝试引起他人的注意。然而这些迹象却无法被拍摄设备记录下来，仿佛只是人们心中的幻觉。无论如何，应当忽略尸体的求救。Andrew 已经死了1。

如果流浪者被尸体的求救声吸引，就会因过于靠近“心”的水域而受到三级以上的严重烧伤，需要立即就医。那些进入“心”的流浪者则会面临更严重的伤害——仅是与水接触几秒钟，就很可能导致肢体完全损坏。由此引发的大出血会在几分钟内夺走流浪者的性命。少数情况下，流浪者会选择潜入“心”中，但他们再也不会浮上来。请务必记住，Andrew 不需要救援。Andrew 已经死了2。

尸体似乎对“心”有着绝对的控制权，能够通过操纵水流在其上流畅地滑行。有时，尸体会故意将自己推到靠近岸边的位置，以引起周围流浪者的注意；随后再向湖心返回，诱使流浪者进入水中。碰触尸体的结果和碰触水面是一样的，因此强烈不建议这么做。许多尝试为尸体进行心肺复苏的受害者双手都被严重烧伤，危及生命的细菌趁机而入，导致他们最终不得不选择截肢。请注意，Andrew 是无法被复苏的。Andrew 已经死了3。

“心”渴求着血。在一系列悲剧事件发生后，它得到了第二个非官方的昵称——“血池”。不计一切代价远离“心”。

附录：发现日志

前言：一支由 Justin Zimals 与 Katherine Zimals 领队的 10 人小队遣往“心”尝试回收 Andrew Donovan 的尸体。

记录开始

[ 在离开 Level 11 的 13 分钟后，小队抵达了水池。这一不重要的片段已被剪去。]

Katherine：他就在那里，在岸边。你们上去抓住他的手脚，应该能把他拉回安全的位置。

[ 急促的脚步声。四个人接近 Andrew 的尸体，准备将他抬上一具担架。Justin 尝试抓住 Andrew 的手臂，但却立即尖叫一声，痛苦地收回了手。Katherine 跑到了他身边；她看了一眼 Justin 手上冒出的蒸汽，但没有理会这可怕的一幕。橡胶手套完全融化了，露出底下被烧焦的皮肤。]

Justin [沉重地喘息]：我操……这他妈？

[ 所有人都后退了几步，只有 Katherine 例外。她继续跑向 Justin，但 Justin 的右腿似乎无法动弹，很快就和他的手一样烧了起来。]

Katherine [气喘吁吁]：Justin……快回来！

Justin [仍在急促地呼吸]：我……我办不到！

[ Katherine 紧紧抓住了 Justin 的胳膊，用尽全力想把他拽走，却没有什么效果。]

Justin：把……你的手……拿开！

Katherine [略感震惊]：不！

[ Justin 努力抖动右腿，最终却跌倒了。他痛苦地嚎叫。]

[ Katherine 几乎也因此被连带着摔倒，但还是稳住了身形。她继续拉着 Justin，心想他的那句话不是在对自己说。然而，Justin 的衣服很快也被点燃了，难以忍受的高温让她不得不松开了手。她连忙退到 Justin 和尸体一旁。]

[ 几个人主动冲向 Katherine 想要帮忙，而她则飞快地从口袋中取出了摄影机，但 Justin 与尸体却突然被一股无形的力量拖入了湖底。他们溅起的灼热水花打在周围几人的身上，引发了一阵骚乱。所有人远离湖水的同时，水下传来 Jusitin 模糊的哀嚎声。湖面上开始冒泡，一阵嘶嘶声后终于平静下来。Justin 再也没浮上来，但 Andrew 的尸体重新出现在了湖中央。]

Katherine [惊恐]：不……不……该死！医生在哪儿？

[ Katherine 举重若轻的风度终于被打破了。她举着摄像机在湖边踌躇不定，双手止不住地颤抖；其他队员则在检查自己的灼伤情况。其中几人晕了过去，剩下的虽然还在强撑，却也都痛苦不已。镜头短暂地扫过湖面，随后又聚焦在队员们身上。Andrew 不见了。]

Justin……？：嘿……这儿呢。

[ 摄像头转向声音的来源。Justin 站在湖的边缘，全身三级烧伤。他的肌肉大面积熔化、一部分骨骼裸露出来。可以看见他的心脏在不断跳动。片刻之后，他软倒在了地上。几个人冲上前想要帮助，但 Katherine 立刻尖叫着制止他们。他们僵在原地。]

Justin……？：噢，拜托了，Kat，我要死了。救你的老哥一把，求你了。我看起来没那么吓人吧。我们的感情很深，是不是？

[ Katherine 因恐惧颤抖不已，但依旧强作镇定地开口。]

Katherine：你……不可能还活着。

Justin……？：但我还活着。看来在这里受伤很不一样。只要命运之轮还没决定你的死期，你就不会死……我的死期还没到呢。

[ 他沉默了一会儿，看向原本是自己左臂的地方。]

Justin……？：我觉得我能缓过来。只要……几个月就行。

[ Justin 虚弱地笑了起来，所有人向他投去不解的目光。Katherine 用手捂住了脸，而 Justin 则一把扯住自己的胸膛。]

Justin……？：哈啊？就打算站在那里，干流眼泪吗？我看起来可能已经死了，但我还是 Justin 啊。我们是兄妹。我们从小就一起生活……对吧？你爱我……对吧？

[ Katherine 开始流泪，但她尝试遮掩。她没有说话。]

[ Katherine 示意所有人离场。他们遵从指示退开，Justin 开始苦苦哀求。没有人听他的独角戏。最终，Justin 放弃了。他沉入湖中。湖面上冒出几个泡泡，接着 Andrew 的尸体又浮了上来，和之前一样死气沉沉。Andrew 已经死了。]

记录结束

他仍活在我们的心中。
Andrew Donovan（1995 - 2024）
