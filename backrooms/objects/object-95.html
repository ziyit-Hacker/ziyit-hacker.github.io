Object 95 - “时之神格”
2022 物品競賽 Object 95 - “时之神格”

时间是全能的神——它倒数着不可撼动且无法避免的湮灭计时，秒针的每次跃动都代表着某样事物终结的迫近，有些终结滋生了新的开始，而有的，则预兆了永久的凝固与停格。如此权能仍不可控，这让怠慢它成为了一种极不明智的行为。

描述

Object 95的正面照。

尽管从正面看，Object 95外表与十九世纪年代的欧洲怀表并无区别，但在它背部安置电池的舱格里却隐秘地藏匿着一个时间显示器——其被称作Object 95.1，它一开始被认为是用来检查时间的仪器，但这个说法最终被推翻了；研究人员发现该仪器的计时只会朝后倒扣，而非向前增加。这件谜团重重的物件身缠一种无法用语言描述的奇异光环，Object 95.1已知会让它的观测者产生包括强烈的恐惧、虚无主义，与末日将至的威压等一系列临时生效的感觉，这类情感的强度与持续时间会随着显示器的计时逼近00:00:00:00不断增加，但只要流浪者的视线从它身上移开，精神影响的效果便会很快消失。

怀表前侧的功能与正常钟表无异，每一秒的跳进都伴随一次微弱的滴答声，然而，Object 95已被观察到会在某些位置经历物理意义上的时间膨胀，当周围环境的重力或速度改变时，它指针的滴答会变得比其他钟表更快或更慢。该现象在Level 456最常发生，在该层级下怀表的滴答频率很少处于稳定的状态，从半秒一次到每两秒一次皆有发生；这或许是由于该层级永久持续性的重力变换造成的。研究者们试图利用Object 95这一被观察到的现象来帮助他们了解后室中不同层级的重力差异，但不幸的是；Object 95.1末日计时的逼近实在太过引人侧目，使得利用该物品这一性质的愿景都已变得不切实际。

Object 95.1那朝时之终焉逼近的倒计时。

Object 95.1的倒计时至今仍令人费解，有人猜测，在倒计时结束后，这枚怀表会遵循随机规律迸发出改变宇宙结构的力量？据称，与Object 95发生近距离接触的流浪者会在倒计时完成被植入虚假的记忆；这些假记忆瑕疵不一，从如M.E.G.Logo细节更改的微小区别，到如整个后室数据库全部被替换的荒谬差异皆有出现。Object 95周围的流浪者会受到效力更强的影响，但已有报告揭示许多分布在后室其他位置的流浪者似乎也被植入了同样的错误记忆，不过后者的记忆相较前者而言会显得更加模糊不清。因为这点，研究人员已将该怀表假设为后室多起异常事件的始作俑者，这一现象被称作曼德拉效应。

发现记录

由于Object 95将虚假记忆植入人脑的能力，有关M.E.G.最初如何持有它的记录也有多个版本，而且这些说法大多自相矛盾。一些编年史详尽描述了Object 95从齿轮缔造者2手里被偷走的场景，而其他人则声称这块怀表是在Level 512被发现的。有关Object 95发现渊源接受度最高、最常见的说法是：一个叫做Ella Parker的流浪者在Level 87与未来的自己相撞，产生了一个时间悖论，这让齿轮缔造者从中介入，给予了她这枚怀表，在怀表的倒计时结束后，Ella丧失了有关进入Level 87的记忆并被传送到了Level 906，在那里她遇到了Blanche，她的外貌似乎与Ella记忆中的有些许不同。Parker记忆残缺的情况与文件记录的匮乏意味着该场景没有切实的证据能够证明其确有发生，这让人们认为，这个所谓“官方”的说法也不过只是Object 95所植入的又一个虚假记忆。

很抱歉发邮件叨扰你，但这件事实在让我有些忧心忡忡：Object 89的纰漏或许是Object 95错误记忆植入的另一个形式。我已经做过一系列研究，并且询问过若干同事有没有关于这个页面的印象，但他们无一人知道这个页面是如何发布在我们的数据库的，甚至在我告诉他们之前都没有人知道它的存在。

然而，这一灾难性事件似乎只是一场更大阴谋的冰山一角——我们数据库的很多页面都有自相矛盾之处，我们真的能确定Object 95只是在植入错误的记忆，而非是在缝补它篡改抹消的现实吗？

举例：

  • Level 9的页面上写着可以从餐厅的卫生间进入Level 103，而Level 103的层级档案却没有这样的入口存在。
  • Level 0的档案在某天莫名被篡改了，而且它以前的样貌甚至还陈列在当前的数据库里面，这里面记录说Alpha基地在那里建立，但我却不记得我们有在Level 0设立过任何基地。
  • Object 97的档案记载着：我们把突袭后室机器人科技的理由归咎于一个叫做分裂者的团体但我的记忆中却并没有这样一个团体存在。
  • 流浪者坊间一直流传我们在后室并不会衰老的传言，但我不明白这其中的缘由，我们有关Dr. Shields的资料似乎暗示了这一现象的可能，这里面显示他在逃亡的二十年来都没有任何衰老，他的页面详尽记录了一场被称作“松荫大屠杀”的事件，里面涉及到了名为“半影”的实体，我对这个所谓的半影没有一丁点儿印象——他们甚至没有自己的页面。但你上传了这篇档案，Stretch。
  • 我发誓Object 95原来不是这个样子；它明明只是一块普通的表，Ella把它当做礼物赠与我后我就将这块表带回了Beta基地，它当时明明还没有什么重要的意义——它是这么普通，我在当时甚至觉得没有必要为这么一件平平无奇的物品设置页面。而现在，却有报告声称它会用末日预言劫持你的大脑，Ella和我明明都没有经历过这样的情况啊。该死，这块表甚至不会滴答作响，它也不是靠电池运行的。到底发生了什么，我的记忆力真的有这么差劲么？

全都乱了，Stretch，所有事都乱套了，我甚至不知道我现在还能相信谁。

Kat
