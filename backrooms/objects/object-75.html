Object 75 - “契诃夫之枪”

Object 75，也被称作契诃夫之枪，这把神奇的武器会在人们最有需要时出现。

描述

标准莫辛-纳甘步枪的示例。这不是真正的契诃夫之枪。

契诃夫之枪的外观与一把标准的莫辛-纳甘步枪相同1。这把武器非常新，在它身上找不到任何磨损、划痕或是生锈。 该武器最显著的特征是位于枪托上的一块金属板，上面刻着奇怪的字样，“安东的礼物，1904 年7月15日”2。

性质

契诃夫之枪似乎只有在满足某些条件时才会出现，但当它现身时，它就是无价之宝。契诃夫之枪似乎只有当流浪者受到会给他们带来伤害的侵略者威胁时才会出现，例如实体或敌对流浪者。通常情况下，受威胁的流浪者会在最后关头看到它，他们只有极短的时间去拿起它并用它保护自己。在极少数情况下，暂时逃离威胁的流浪者也能发现它并以此伏击，直到侵略者进入他们的视线。无论如何，契诃夫之枪都是一个罕见的物品，见过它的流浪者性命都因它得以保全。

那些见过契诃夫之枪的流浪者的报告中都表现出奇怪的相似之处。每份报告都显示发现这把枪的人要么觉得这把枪很熟悉，要么就是在前厅见过这把枪。这点引出了许多关于它与前厅、后室以及看见它的流浪者之间联系的问题。根据推测，这把枪在前厅只是一个幻影，因为目击者表明没有其他人能察觉到这把枪。看到这把枪很可能意味着一个人将进入后室并在后室使用它。然而，这把枪如何出现以及它向谁出现似乎都是随机的。

契诃夫之枪并非传统枪支。据报告，它无需弹药或进一步操作即可开枪。此外，值得注意的是发射时似乎感受不到后坐力，并且不会产生任何声音或火光。但最为奇怪的是，当用枪向一个目标开火时，目标将会凭空消失。除了目标之外，契诃夫之枪也将从使用者手中消失。目标和枪的去向目前未知。

由于流浪者能拥有契诃夫之枪的时间往往很短，因此枪的内部构造和工作原理尚且未知。但是，它似乎可以补偿使用者的瞄准，因为据没有枪械使用经验的流浪者表示，尽管他们瞄的不准，但还是锁定了目标。这一切都使得契诃夫之枪成为一种恩赐，一旦有使用机会就应当使用；它很有可能救人性命。

发现地点

契诃夫之枪理论上可以在任何层级中找到，但它往往出现于较危险的层级，因为它的获取条件与使用者的安危息息相关。

第一次发现

第一次已知的契诃夫之枪的发现是一位十六岁的男孩阿德里安·哈迪斯蒂，当他切入Level 2时，他用契诃夫之枪来保护自己免受一只窃皮者的袭击。事后对此人进行的采访如下：

记录开始

时间：3:46 PM
日期：2022年12月10日。
地点：Level 1，阿尔法基地。
采访者：格雷格·斯通
被采访者：阿德里安·哈迪斯蒂
[阿德里安坐在格雷格对面，看上去对采访感到不适。格雷格似乎无视了这些。]
格雷格：你好，呃，你是……阿德里安·哈迪斯蒂，对吧？
阿德里安：是的。
格雷格：那就对了，我只是想问一些关于你在Level 2发现的那把怪枪的问题。
阿德里安：好吧，快点，我可不喜欢回答一堆问题。
格雷格：当然，首先，当你发现那把枪时发生了什么？
阿德里安：当我在那个满是管道的地方看到一个……我不清楚……一个怪物还是什么别的东西？那玩意一眼看上去很像人，但我最终发现他不是。我奋力跑开，但它还是离我越来越近。当它逼近之时，我发现一把枪躺在地板上。我明白，我只能那么做，哪怕我过去从未使用过枪。我的手在恐惧中剧烈颤抖，当那玩意进入我视线时，我朝它扣动扳机，随后……怪物和枪一起消失了。我甚至不确定我到底有没有打中它。然后……枪不是一般都有很大声音吗？但我在扣动扳机时什么也没听见。
格雷格：真有趣。实际上你应该庆幸自己没有发出什么声音，在Level 2这种密闭空间中，枪声往往意味着更多实体，还有可能损坏你的听力。
阿德里安：呵呵，那我可真是幸运。
[当格雷格在笔记本中写下这些时，阿德里安看上去在思考什么]
格雷格：好吧，你能告诉我那把枪的外形吗，还是说你知道它的型号？
阿德里安：关于枪械我可是一无所知，你问我这个问题干嘛？
格雷格：我明白，但哪怕一点点信息都是有用的。
阿德里安：我想它是木头的，看上去是把老枪却异常的新。我可没什么好说的了，很抱歉我的话可能没什么用。但是……呃……我可能见过它……等等！我记得，当时我和我爸爸在一家当铺，爸爸在办事。当我环视整个店铺时，我发现了它。我想向爸爸指出我看见了把枪，但当时他正在和柜台后面的人交流，他忽视了我的话。我想……那把枪和我在Level 2中看到一模一样。
格雷格：这下可真的有趣了，你是说你在前厅看到过它？这可真是不小的发现。我会确保这些信息被正确的传达给我的上级的，这可真是一个突破性的发现啊。
阿德里安：前厅？你是指地球？好啦，问那么多够了吗？
格雷格：我想这么多就够了，谢谢你的配合。
[格雷格替阿德里安打开了门，二人离开采访室。]

记录结束
