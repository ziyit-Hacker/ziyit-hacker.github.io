简单地讲，福友玉（Object 101）是能够侦测实体、遏制危险事态的天然用具，它们出现在后室的洞穴地貌中，在里面勘探的时候会非常有用。

描述：

福友玉戒指变体；混合金元素合金，永恒资料库制造。

福友玉戒指变体；混合钢合金，永恒资料库制造。

从永恒资料库矿场获得的一块福友玉，重 4.5kg（9.9 磅）。

从永恒资料库矿场获得的一块福友玉，重 4.2kg（9.2 磅）。

Object 101 在 2016 年 6 月刚刚被发现的时候似乎和普通的软玉相同。某次永恒资料库在秘密矿场执行开采任务，结果观察到该物品发出了朦胧的光，这就激起了成员们对 Object 101 的兴趣。初级研究员易卜拉欣·福友（Ibrahim Frvyo）主导该物品的初步研究，物品以此人为名。

福友玉的主要用途是在限定区域1 内侦测实体（人类除外），同时判断实体的危险等级。这个特质表明福友玉能够适应各种自发情形，但是如何适应会因为所处的具体情况而有所变化，比如身处小队，又或者安全的环境当中。福友玉在基准状态呈现出苔藓色，该物品常常出现在洞穴系统中，平均温度是 8°C–14°C（46.4°F–57.2°F）。Object 101 通常拥有很高的密度，它的质地也非常坚硬，莫氏硬度处于 6.1–6.6 的范围，使用坚硬金属制成的犒具、锤具、凿具、铲具等采矿用具便可轻松地开采该物品。

Object 101 含有某种经确认导致该物品产生异常效应（即“福友映射”）的物质。这种名为“福友质”的物质尚未接受全面分析，因为组织需要合适的设备才能进行这种检测。此外，尚不清楚该物质属于元素还是化合物2

福友质很难从软玉中提取出来，同时会和除本身所在的玉石以外的几乎所有物品产生剧烈的反应。该物质一旦接触到软玉以外的任何物质，就会立刻和这个物质反应生成一种化合物。这种化合物名为“福友气体”，即使是小剂量也能产生剧毒。3

所以总而言之，我们认为福友质是一种异常的化合物，只能以软玉作为基础复合物，在其中充当组成元素。

福友玉还被用作民俗饰品和珠宝4。使用 Object 101 材料制成的饰品通常被称作福友戒指、福友项链、福友胸针、福友耳环、福友吊坠、福友手链等。

属性：

该物品可通过名为“福友映射”的现象来侦测某个实体的存在以及危险等级，此时玉石中的福友化合物会散发出充当声纳的不可见物质，然后它会在侦测到范围内的实体时产生反应，并发出对应强度的光照。很奇怪的是人类并不会引起物品的反应；人形实体，或者携带人体组织的实体却可以产生反应。（如：无面灵，窃皮者。）5

如果某个实体处于福友质的映射范围内，那么福友玉就会展现自身的效应。当有实体在附近的时候，玉石就会以福友质作为能量源发出光芒。物品照明时会发出不同色度的绿光，具体的色相取决于实体的危险等级和威胁等级。下面将已知的照明强度依降序列出：

  • 白绿 - 高度危险/极端敌对
    • 无法用眼睛直视该等级的照明。不计一切代价地远离该威胁。
  • 浅绿 - 非常危险/敌对
    • 眼睛可以处理该等级的照明，但是长期暴露会导致眼睛受伤。必须远离该威胁。
  • 绿色 - 相对危险/略敌对
    • 眼睛可以处理该等级的照明，长期暴露也不会致伤。建议远离该威胁。
  • 深绿 - 危险较小/不安全
    • 眼睛可以安全地观察该等级的照明。该威胁不安全，但是可以接触。
  • 暗绿 - 危险很小/安全
    • 该等级的照明几乎不可见。该威胁很安全，可以接触。

理论：

据信福友质只能侦测后室原生的实体或力量，也只能和它们产生反应，因为这是一种目前只存在于后室的化合物；可能这就是福友玉无法侦测人类或其他前厅生物的原因。虽然有些实体伪装得像人类一样，但是它们并非来自地球，或者直截了当地说，不是来自前厅。

虽然这个问题可能会涉及到出生在后室的人类，但是研究人员已测试并确认6了这些人群没有展现出上表所示的任何危险等级，从前厅切入的生物也表现出同样的性质。很明显不可侦测性可以通过基因被子代遗传下来。尽管这个发现表明了人形实体或携带人体组织的实体可能无法被福友质的效应检测出来，但是所有后室原生实体都推翻了这个猜想。

实体通过获取人体组织确实能使自己的危险等级发生改变，但是福友质总是会识别并确认该实体的内在原生性，结果就是，这类实体能够依靠福友映射被侦测出来。

结论：

这项理论引发了关于拥有人类身份、行为和性格的实体的大规模争论。受福友玉的影响，人们开始怀疑到底是否存在人类实体，但是多数研究者持接受福友玉的立场，他们表示该物品只是用于区分外来物和原生物的工具，并不能用来区分人类和实体。

虽然目前尚不能解释为什么福友映射效应唯独无法侦测人类或来自前厅的生物，但是人们普遍认为最好还是向前看，与其紧盯着福友玉的暗示不放，还是利用好这种物品的益处比较合适。

有关福友玉材料的饰品和设备的生产和分发环节，后室机器人科技和B.N.T.G.等组织与永恒资料库建立了长期合作关系。正是因为这些组织带头实现通力合作，普通人佩戴 Object 101 才成为了再正常不过的事情，已经有多次探索任务采用了该物品，进一步深化了后室内部的扩建工作。

可靠性：

在森林或洞穴等实体数量处于较低水平的孤立环境中，福友玉石可以挽救人的性命。但是对于城市和未收容层级等实体泛滥的环境，这种物品便无法应付，它们还会在多个实体的情况下频繁切换照明。因此建议探索者不要过度依赖该物品，因为该物品可能会随着具体环境的不同而变得很不稳定且变化多端。
