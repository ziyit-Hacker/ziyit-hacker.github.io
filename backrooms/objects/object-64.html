描述

Object 64，通常被称为“临终低语”，是一种单向无线音响系统。与在前厅徒步旅行时经常使用的语音导览类似，它们可以在大多数室内层级和环境中找到。

在Level 5中发现的一个Object 64实例。

Object 64最广为人知的是其发出的音频样本。这些音频通常以英语1描绘流浪者探索后室中未记录的区域。这些信息是真实的抑或是阈界反响捏造的仍有待商榷，因为报告中提到的所有名字都与通用公共数据库（G.P.D.）的记录不符，也从未找到过受害者的遗体。Object 64缺乏交流能力，这导致收集相关事件的信息非常困难。

起初，Object 64发出的音频内容平平无奇，录音主体往往会向听众们描述周遭环境，分享过往经历等。然而，尽管这些独白在开头都显得平静祥和，事态却会在短时间内迅速升级。尖叫，求救，与各类逼真的音效将紧随着之前平静的独白爆发开来，它们通常传达了主体的死亡。2由于这种突然的转变，流浪者在收听Object 64所发出的音频信息时往往会产生强烈的迷失感，故不建议未经标准训练者接触。收听Object 64音频产生的常见影响包括但不限于：

  • 恶心
  • 强烈的愧疚与后悔
  • 恐慌与/或严重的妄想症
  • 呼吸困难
  • 引发创伤后应激障碍或类似病症3
  • 产生寻找并援助录音主体的强烈冲动4

外观

Object 64实例的特征通常为鲜红色挂绳与附接的单边耳机。多数Object 64实例显示出明显的老化痕迹，在物品表面甚至可能存在刮痕或凹痕。尽管如此，还从未有过Object 64实例功能失效的报告，虽然过量静电噪音与语言难以辨识的情况并不少见。

用途

不幸的是，目前已回收的Object 64实例均为音频接收器，完全不具备将其用于通讯或娱乐的可能性。然而，它们曾作为关键组件短暂服务于卡拉格灵协会的人类死亡档案编录。M.E.G.与该协会达成了交易，通过交换报告——某些情况下也包括音频接收器本身——来获取该协会私有档案库与其他宝贵数据的的查阅权限。

尽管我们能够追踪到相当多的死者，但仍有一定数量的死亡事件从我们的调查中遗漏。不论是后室异象还是实体抢在我们之前找到他们，我们的调查都还不够完美。而Object 64为我们记录那些在此消逝的生命提供了巨大帮助。
-Isagani Mercado,卡拉格灵协会后室分部高级档案员

然而，这种共生关系并没有持续多久，随着围绕Object 64所提供信息的可信度的争论，双方之间的交易迅速中止了。

行为准则

M.E.G.已针对Object 64的报告与安全处置制定了专项协议，被称作R.E.L.I.C.

通 告

鉴于近期由Object 64引发的失踪事件显著增加，我们正实行一种新的安全收容其样本的流程。如果你发现了Object 64的样本，请遵循以下步骤：

R - Recognize 辨认

使用上述描述来确认物件确是Object 64的实例 。

E - Examine 审查

观察周围环境以便你准确描述物品的位置。你最好将这些观察结果记录下来以确保观测数据的完整。这些记录将有助于M.E.G.识别该物品出现的潜在模式。

L - Leave Behind 留置

请克制与该物品产生交互的冲动，并将其留置在离你最近的M.E.G.前哨站。

I - Inform 报告

向M.E.G.特工报告你的发现，并描述发现该物品的位置。

C - Carry On 继续

继续你之前在做的事情，后续工作将由M.E.G.负责。我们会妥善处理好。


我们感谢你的配合，也祝愿你在这段困难时期一切顺利。记住，英雄主义只是一种徒劳的努力。这些物品试图欺骗你并利用你的同情心。让那些失踪者的命运作为警告：无为即太平。


M.E.G. - 为了人类的明天





他们错了。他们错的彻头彻尾。

那些人，那些音频中的人，他们是人类。他们是真真切切的人。我们找到了其中一位名叫Stephen Campbell的人。Juanita 在一次调查期间于 Level 800 的隐蔽角落发现了他的尸体，以及一个损坏的录音机。我认为这会给你一个足够好的理论来理解这个物品的工作原理。

我知道我本不是会插手这种事的人，而这一切也终将被尘封掩盖，可我实在不想看着这些人就这样被白白抛弃。M.E.G.叫人们上报这些物品，并说他们会处理这些，但其实他们根本就是一群什么都不敢做的没种懦夫。那些失踪的人们，他们也有家人，朋友，以及牵挂着他们的人。如果M.E.G.打算背弃他们保护后室中所有流浪者的诺言，至少他们可以给失踪者的亲友们一个交代。
