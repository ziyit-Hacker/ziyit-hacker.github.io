Object 11: 幽鬼灯光
Class: 未知 可在阴暗的角落或者含有剧院的层级中找到。 物品拥有致幻属性。
↓Object 10 ↑Object 12




那是我第一次看到这个物品，那是刺破了绕折走廊中黑暗角落的一点微明。那是装饰在高立在阴影中的华美手作铁架台之上的灯光，引诱着我沐浴在其光芒之下。我感觉很安全，也许有点太过安全了。我很快就睡着了，我的疼感与痛觉渐渐融化在了我所找到的那灯光城堡之内。我在一个巨大的礼堂中醒来，成千上万崇慕着我的粉丝正为我欢呼。一位穿着饰有倾泻至膝盖处的闪点亮光长裙的演员向我伸出了裹有柔软丝质手套的手。我轻轻地握住了这只手，随后我们开始舞动。我们在一起旋转着，小提琴的协奏曲弥漫在这舞蹈的礼堂之中，观众们也沉醉在这优美的音乐之中。我闭上眼睛，微笑着，因为我终于找到了这世界中属于我的一处地方。而我睁开眼时，我正面朝下趴在腐烂的地毯上，我又一次被困在了后室那被弃置的走廊中，这里只有我身后诡异闪动着的灯光。


由 M.E.G. 提供的幽鬼灯光照片。

Object 11 是一种被代称为「幽鬼灯光」的设备。幽鬼灯光类似发光装置，常见于前厅中的剧院内。在剧院中会将其点亮，以让晚上还留在剧院内的人不会在黑暗中被绊倒。然而，某些前厅居民亦声称，这些灯光还可以用于防止或引导鬼灵在剧院清空之后居住在其内。虽然幽鬼灯光的神秘元素只是前厅中的一个都市传说而已，但它在后室的对应物品则会对流浪者制造出生动的幻觉以及其它有害且距离相关的效应。

描述

幽鬼灯光通常会出现在层级的阴暗角落之中，不过报告中该物品所出现的地点大部分都在 Level 74。物品本身类似于一个挂在老化铁架台上的白炽灯泡。Object 11 高约 0.9 至 1.8 米，铁架台部分似乎是用黄铜或铁手工制作的。无论幽鬼灯光的大小如何，它的重量都特别的大，有时候其重量可达超过 45 千克，且难以移动。

布置在固定物顶部的灯泡会一直开启，但其会偶然忽明忽暗以及闪烁。Object 11 可以无需电源也能生成自己的光亮，且其灯泡部分摸起来一直是热的。试图通过使用武力破坏该物品的尝试都以失败告终，猜测是由于其玻璃与钢铁的部分强度较高。灯泡是经典的维多利亚式的形状1，且所产生的灯光似乎是由钠灯丝发出的，会用黄橙色的灯光照耀周围。大多数档案中记载 Object 11 的灯光照耀半径能达到 4.5 米，不过有些物品的灯泡亮度较低，也有报告发现某些灯泡只会闪动。

M.E.G. 研究员观察到幽鬼灯光的半径中有着异常幽灵飞入飞出。这些鬼魂会在离 Object 11 过远时立即消失，且暴露于物品下的暂时性思维改变效应也会同样消失。灯光半径之外的观察者可能会看到灯光内有人形鬼魂，有数名特工亦描述称，幽鬼灯光发出的声音类似从其中传出的管弦乐队练习时的声音。

幽鬼灯光的主要异常

安全区域

人形实体，比如钝人和猎犬等都不会进入幽鬼灯光的范围之内。M.E.G. 猜测这些人形实体同样也会经历梦境状态，不过这一猜想仍在调查之中。也有报告称出现实体停止追捕逃离的流浪者，并在黑暗中静观其离开的例子。目前已对多种实体，特别是猎犬与幽鬼灯光之间的交互做出观察。这些实体通常会在暴露于幽鬼灯光下时挣扎并奋力逃跑，有只猎犬甚至在逃跑的时候摔断了腿骨。捕获后对其进行的进一步检查证实灯光本身并不会对生物造成任何明显可见的伤害。而测试结果则与上述结论不一致，某些对象似乎完全免疫影响，而某些则似乎会进入梦境状态。

当物品周围聚集了三个实体（包括人类）的情况下，灯泡会完全碎裂，为倒霉的探险者留下一根无用的金属杆。此外在灯泡碎裂时，任何在光照半径内被照射到的事物都会被击晕，使其感到晕眩与趔趄。某些曾暴露在碎裂灯泡中的流浪者报告称会在事后出现一段时间偏头痛的副作用，这段时间长度与其被光照射到的时间长度有关。虽然安全区域并非绝对可靠，但也可以临时性地帮助流浪者抵御猎杀他们的实体。

梦境状态

进入灯光半径内的流浪者会逐渐屈从于该物品的梦境状态。这些效应强度是与距离有关的，所以建议在效应减退之前远离幽鬼灯光。梦境状态的沉浸度对于各个体来说都有所不同，但可以通过更加靠近幽鬼灯光、事先处于疲惫状态或有其它实体出现来加速沉浸。此外，距离也会显著影响流浪者所经历的梦境内容。在外围的流浪者可能只会看见闪烁的鬼灵在其周围舞动，而更加靠近灯光的流浪者可能会完全看到鬼魂，或是听见奇怪的背景音乐。若要完全进入梦境状态，流浪者必须长时间地相对靠近该物品。

一旦进入梦境状态，流浪者就会忽然发现自己身处一个巨大的舞台上，正表演着某种戏剧。流浪者可能会体验表演与前厅中类似的著名音乐剧，或是以奇怪语言讲述的戏剧。据报告舞台类似于大型欧式剧院，其装修与建筑风格都类似十九世纪早期的风格。散乱布置的露台有着复杂的装修、镀金的花饰以及铺有红色天鹅绒毯垫的座椅。流浪者曾报告剧院里满是欢呼着的观众，这些观众穿着华丽的服饰，脸上戴着有微笑脸的白面具，模糊了他们的面孔。

那些完全沉浸入梦境状态会实际参与表演的过程，演出戏剧或音乐剧中的台词与剧本，甚至会说出他们所不了解的语言或来自他们未曾见过的戏剧中的台词与剧本。对于观察者来说，受折磨的人会开始大声表演，无论其周围可能潜伏着什么。梦境状态效应所持续的时间量不定，然而，如果此人被从幽鬼灯光的光照中拉出，那么该效应就可以被逆转。此外，在进入梦境状态时破坏灯光将立即停止所有受到物品影响的生物的梦境状态。演技会因人与人之间不同而有着显著差异，某些流浪者会完全破坏掉他们对自己所设想的戏剧为何的解释。如果表演被幻境中的观众认为低于平均水平的话，那么根据报告他们将会排队离开剧院，而流浪者将退出梦境状态。M.E.G. 研究证明流浪者参与进剧院的次数越多，那么梦境状态效应就会更加强大，他们也会演出更加复杂的表演。

多个流浪者被梦境状态影响的实例所导致的结果可能不同。某些流浪者报告称他们在幻境中协作演出，而有些则在梦境状态中关系破裂，为被抢风头而发怒。深入梦境状态的流浪者仍可以区分出其他流浪者以及幻境中的人，因为流浪者并没有适合用于表演的服装。

以下为描述 M.E.G. 所批准的使用 Object 11 的实验与交互记录。

M.E.G. 数据条目——实验音频记录 11：幽鬼灯光

转录：
你们好，我是 Everett Kyne 博士，我现在非常激动能够来到 Level 74，能够终于对幽鬼灯光做点实验了。我曾经见过一次幽鬼灯光，就是在 Level 74 停留太久之后友善地看了一眼而已，然后我就一直都很渴望想看看它各方各面的功能都是什么。我等了好久时间才能拿这么一个灯来做实验，那时候其我就自行部分地体验了一番梦境状态。不太幸运的是，我是个挺差劲的表演者，我的观众也……很不喜欢我的表演。我被委托收集数据并辨识出这个物品的准确本质，我也很兴奋能够为我的发现做一个报告。

特别感谢我们意愿暴露在幽鬼灯光之下的参与者协助测试它那迷人的属性。由于不确定暴露之后效应所维持的程度如何，所以我们有采取预防措施，比如准备好将参与者拉出灯光之外。在他首次暴露时，参与者花了大约一个小时的时间才开始进入梦境状态。他报告称见到了带着某种假面的演员围绕在自己周围，所有的这些演员都穿着复古的服装。而在休息之后，我们又继续增加了三十分钟与四十五分钟的照射时间，不过参与者的状态并没有太多改变。不过在过去一小时后则有了巨大的不同。他冷不丁吓了我一跳，喊了一声「宙斯！」。参与者是站着的状态，他的姿势非常夸张，手部明显指着幽鬼灯光。「热烈欢迎宙斯之声，您带来了何物？您从德尔斐的金库中为辉煌的底比斯带来了什么谕言呢？」参与者开始昂首阔步，围绕着幽鬼灯光舞蹈着，用一种优美的姿势挥舞着手臂。「受恐惧的煎熬——恐惧动摇着我的心脏，而我为您放荡的哭泣而悲嚎，阿波罗，提洛岛的医者，我在恐惧之中敬奉着您……现又如何，您的价码为何？」2

我鸡皮疙瘩都起来了。不仅仅是说参与者已经完全被幽鬼灯光所迷住了，而且他还能声情并茂地引述着俄狄浦斯王。我一边对他对索福克勒斯的艺术处理感到满意，一边迅速地将他拉出了实验外。参与者花了四十分钟左右才恢复正常状态，不过他跟我所讲的经历非常美妙。参与者被送到了一个了不起的地方，还有数百人在为他欢呼着。他不知怎么地就完美背下了自己的台词，而他所做出的所有动作都感觉像纯粹就是本能一般。

在回到安全的地方之后，我还想录下我的更多的一些想法。实体会回避它，人类则会为它着魔。但它的原理是什么？这又是另一件后室怪谈了，是一种我们永远都不可能真正揭秘的东西，因为这里的大多数东西都已经违背了我们对已知世界既有的实用性知识。我很期待能够对幽鬼灯光做更多实验。我也很好奇这个物品里藏有什么秘密。我认为只有时间才会揭开一切了。

结束转录。
