Object 41 - “电源插座”
2025经典速写 Object 41 - “电源插座”
评分:+8+x

描述

后室内的一个电源插座。

Object 41，通常称之为电源插座（outlets或sockets），是后室内最常见的单一电力来源。与现实基准中的对应物一样，电源插座是固定在墙上的接口，可为任何插入其中的电子设备供电。该物品的实例在后室中出现时，其种类与地球上可见的相同，分布大致均等。Object 41偶尔还会以设计怪异且陌生的插座形式显现，与任何已知插头均不兼容。最好不要擅自摆弄此类插座。

电源插座几乎可见于后室的每一个层级，即便是那些最令人意想不到的层级。不出所料，该物品在封闭空间中更为常见，或单独出现，或多个成组出现。这些集群通常由两个（偶尔为三个）插座依次排列组成，不过也观察到它们以更多数量杂乱无章地分布，或形成令人联想到螺旋与星辰的奇特图案。然而，Object 41的显现形式并不局限于室内层级。在极少数情况下，它们会出现在户外环境中，常藏于石块之下、埋于草丛之中，或隐匿于人造树的活板门后。

特性

Object 41最主要且最明显的特征是其为电子设备供电的能力，但这并非其唯一功能。当连接到某个Object 41实例时，手机、电脑以及办公终端可能会开始接收外来数据，形式包括BACKDOOR1消息、文件或来源不明的电子邮件。这些传输内容包罗万象，从身份不明实体的对话片段，到生存技巧，或是关于该插座所在层级的历史记录，不一而足。然而，这些信息并非总是有用——甚至并非总能被理解。以下是此类额外传输内容的一个示例：

……它在燃烧，一直在燃烧，永远不会停止燃烧。你让我去相信，我照做了。我信任了，相信了，爱过了，可这就是我得到的回报。但你会回来的，最终你也会被燃烧。哦，我们都会燃烧，在火焰中起舞。它在燃烧，它在燃烧，它在……

发现于Level 46中的一个插座中

尽管这些信息对有些人来说可能显得令人不安，但人们发现它们并无特殊意义。不应再对其予以关注。

研究

后室内存在诸如WiFi、自来水和电力等设施，长久以来一直让流浪者和研究人员十分着迷。多年来，许多人试图弄清这些系统的内部运作机制，而对于那些试图揭示后室潜在电网的人来说，电源插座是主要的研究对象。发现这一隐藏电网的初步尝试始于对多个邻近插座背后线路的检查，而这立刻表明上述电网很可能并不存在。人们不仅发现这些插座彼此独立，还发现每个插座的电力来源都大相径庭，且均属异常。

插座的电力来源可能有无数种；下面列出的是一些曾多次遭遇的例子：

  • Level 1、Level 4和Level 9中的一些插座由只能被称为“蒸汽朋克”的机械提供动力，这类机械主要由齿轮、金属管道、阀门和连杆构成。所有试图阐明这些机械运作原理的尝试都被证明是徒劳的，因为它们背后似乎不存在任何科学或逻辑。
  • 一群探险家调查了在Level 75一个未探索的洞穴区域发现的插座后，突然的坍塌揭示了该物体所嵌入的墙后面的东西：这个插座通过柔软的、类似血管的管子连接到一堆人体器官。在这些器官中，探险队识别出了多个肺、一颗巨大的跳动心脏，以及其他一些有机结构——其描述与任何已知的人类或动物器官都不相符。
  • 试图探查Object 41实例的后方，通常会发现根本没有任何东西为其供电。有的是回到该物品本身的电缆闭合回路，有的是被发现已断裂的电线，更令人困惑的是，有些插座似乎固定在墙上却没有实际的布线——可以干净地取下，仿佛是粘在上面的。尽管这些异常现象被揭示后，插座通常会停止供电，但在个别情况下，该物品仍会继续供电，使其成为一种便携式且看似无穷无尽的能源。这些样本极为罕见且备受珍视，因此经常在诸如Level 9.2之类的黑市上以极高的价格出售。
