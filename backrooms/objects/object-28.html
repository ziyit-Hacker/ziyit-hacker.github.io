Object 28 - “幸运豆奶”

幸运豆奶是一种由大豆制成的饮料，在后室颇受欢迎，可以与杏仁水媲美。幸运豆奶受欢迎度上升一定程度上得益于坚果过敏的人无法饮用杏仁水。

描述

幸运豆奶是一种大豆饮料，是杏仁水的绝佳替代品，适合对坚果过敏的人。 豆奶瓶通常由玻璃制成，类似于牛奶瓶，瓶身上有标签。标签似乎是与玻璃一体的，更像是有色玻璃。6种口味分别对应6个不同的标签，每种口味都有不同的效果。标签背面有成分表，成分如下：

大豆：100%
糖：0%
天然防腐剂：300%
人造调味剂/色素: 0%

标签还提到其中含大量钙，使得该物品成为后室中最健康的饮品之一。

幸运豆奶的效果与口味：

如上文所述，每种颜色有对应的标签和口味，可以通过查看瓶盖的边缘来识别，瓶盖边缘有一条与之匹配的色带。标签上也有标注口味，很容易辨别幸运豆奶的口味。唯一的例外是运气款和香蕉味，两者都没有在标签上标注口味。运气款幸运豆奶的效果由实际情况决定，如果没有正确识别和处理，可能会造成危险。

由于香蕉味与运气款过于相似，强烈建议在饮用前把任何/所有黄色豆奶加热到至少71摄氏度。如上文所述，二者标签上均未标注口味。

幸运豆奶的用途：

饮用幸运豆奶可以带来多种有用的效果。为了最大程度发挥该物品的作用，请按照以下说明进行操作（注：你也可以仅用它来补充水分。）

提高睡眠质量：
将抹茶口味幸运豆奶倒在纸巾上，然后慢慢地用它轻拍眼睛、鼻梁和眼睛下方。这有助于减轻眼睛、耳膜的压力，并疏通鼻子，从而提高睡眠质量。

饮用：
如果你想找一种获得效果的简单办法，直接饮用幸运豆奶。该物品富含营养，除了“幸运Nicky”事件外，没有记录到其它任何幸运豆奶引起的不幸事件。但大豆过敏者不能饮用该物品，因为其完全由大豆制成。
