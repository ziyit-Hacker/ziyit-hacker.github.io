Object 666 - “命运之骰”
2022 物品競賽 Object 666 - “命运之骰”

欢迎来到恐怖旅馆赌场的纪念品商店！

我们在这里向您介绍赌场的新纪念品 - 命运之骰！

赌场不对因使用此纪念品而造成的伤亡负责。

命运之骰由绅士本人推荐，可满足你的所有幻想！

使用步骤和物品性质说明：

  1. 捡起骰子。
  2. 投掷它！
  3. 等它停下，然后奇迹就会发生！

这个骰子与普通骰子不同——它虽然看起来是一个普通的立方体，但它却拥有无限种点数！而这意味着它可以抛出无限可能！

值得让我一提的是：在这个骰子抛出的无限可能中产生的奇迹只会向好的方面而行，这也就意味着你无论抛出什么样的结果，这些结果产生的事件对你而言都不是什么坏事！

照前面所说，它有着“无限种”的点数，但是为什么外观上来看它只是一个小小的、没有任何特征的立方体？我没记错的话，有一句俗语说得非常好：“无限来源于虚无。”这个骰子的点数是代表着无限结果的点数，但在我们的概念中，无限似乎并不是一个可以被很好囊括的定义，那么为了使我们的产品更加通俗易懂，我们只留下了完成一次抛出后对应结果的点数。于是在平时看来，它都只会是一个小小的没有点数的小立方体。

当你使用它时，只需将它抛出，然后心中默念你所想要做的事或者是你想要求得的物品，接着就是愿望满足之时！

最终的结果是…

不过遗憾的是，一次投掷投出的结果可能与你心中的想法不同，但是别忘了我在先前提到过这个骰子抛出的结果都不是坏事，这就说明你可能会获得一些意外之喜！

如果你投掷出来的结果满足了你心中的预期的话，就不妨来我们的赌场的售后部门来留下建议吧。当然，如果骰子出现意外的损坏的话，你可以携带购买时附赠的凭证来这里更换骰子，这是完全免费的。

获取方式：

如果你在赌场里一掷千金的话，这个骰子将会作为一个纪念品送出！同时你也可以在一些地方通过不同的筹码来兑换。

注意事项：

  1. 如果您的骰子开始自行滚动，请勿干涉。
  2. 如果您在一封闭空间内投掷骰子后其在5分钟后依旧未停止，您将获得一高动能武器。
  3. 如果您的骰子停止后朝上一面的点数是“乌贼”，“旅馆”或“赌徒”等，请待在原地不动。
  4. 如果您的骰子停止后朝上一面为空白，请触摸它。
  5. 如果您的骰子停止后立在（指用其一角或一边支撑）平面上，请靠近骰子，它可能会发生一些意想不到的反应。
