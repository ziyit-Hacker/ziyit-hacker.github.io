评分:+72+x

第一章：自我

M.E.G. 采访记录节选，Entity 440

历史学家

Entity 440，又被称作“历史学家”，是一个栖息于 Level 718 的神秘实体，似乎掌握着我们宇宙中的一切知识。不幸的是，如果你对它提出了分量太重的问题，那么唯有永远留在该层级中，成为“沉默僧侣”的一员，才能听到答案。


采访者：尼克·科沃基安
受访者：历史学家
前言：为了继续对杏仁水的研究，尼克·科沃基安需要采访历史学家。

由于 Level 718 内无法拍照，加比·巴维茨绘制了采访时的场景。

摘录开始

尼克·科沃基安：杏仁水是什么？

历史学家：你们称之为“杏仁水”的物质，是一种在后室中普遍存在的流体。其化学成分中 H₂O 的体积占比高达 94.3%，其余 5.4% 则包括葡萄糖、二氧化碳、氧气、以及氯化物、氰化物等多种电解质。此外，溶液约 0.3% 的部分由血清白蛋白、球蛋白、纤维蛋白原等脊椎生物血液内常见的蛋白质组成。然而，我相信你们已清楚这一点。你们将杏仁水置于显微镜下观察，而你对它的成分了然于心。这并非你真正想问的问题。你想问的是：杏仁水在后室广泛存在的原因。你想询问为何杏仁水化学成分普通，却有着特殊的效果。我能理解你的沉醉，我能看到你对知识的饥渴。但若要知道答案，你需先答应一件事：永远留在这个层级。

尼克·科沃基安：这样子吗？那能不能告诉我，这个问题为什么这么重要，非得我加入“沉默僧侣”不可？

历史学家：同样不可言，除非你答应永不离开。

尼克·科沃基安：嗯……遗憾。叨饶了。

摘录结束

十一鹰报

Alpha 基地备受喜爱的宠物大猩猩，墨墨，突发逝世

愿你安息

我们怀着沉痛的心情宣布，Alpha 基地人见人爱的吉祥物，墨墨，已经离开了我们。最初，是 M.E.G. 的爱丽丝探险团在 Level 18 发现了墨墨。M.E.G. 的队员们很难遇到一只总是泡在机油里的幼年大猩猩，更难遇到一只友善到能带回 Alpha 基地的大猩猩。墨墨是独一份的。虽然没人能弄懂他那湿漉漉、毛茸茸的脑袋里在想什么，但许多 Alpha 基地的队员还是认可了墨墨。他成为了我们的一员。

詹姆斯·卡福斯，一位 M.E.G. 成员，亲切地缅怀了墨墨。“我还记得第一次见到墨墨的时候。他站起身，走到我面前，给了我一个大大的拥抱，把我的衣服都弄得沾满了机油。他毁掉了我最喜欢的一条裤子。我把那条牛仔裤在洗衣机里洗了十几次，然后还是放弃了它，我承认那些油渍永远都洗不掉了。墨墨绝对是一只有趣的小猴。”

另一位 Alpha 基地的居民，加比·巴维茨说道，“就像所有人一样，墨墨也有自己的起起落落，但我相信‘起’肯定更多。我有时候会想，作为一只猩猩，没有见过大自然，却被困在了一个混凝土的世界，会是什么感受？但我猜墨墨从不在意这些。他的离开让我们一时缓不过来。”

上周二，墨墨死在了他在 Alpha 基地最爱的房间里。他的血液被抽干了，头部、胸部也有大面积缺损。他的死因被判定为自然死亡。墨墨将在 Level 18 得到火化，就在我们最初找到他的地方附近。许多 M.E.G. 成员都将出席他的葬礼。我们真切缅怀墨墨。

杏仁水历史记录的不一致性

尼克·科沃基安 / 著

这段时间，我一直在仔细研究杏仁水。不幸的是，我越是想要了解它，就越发现，自己正在一个又一个死胡同里打转。我不知道为什么它在后室经久不衰，也不知道它的效用来自哪里——我知道它的化学成分，但这只能带来更多问题。在检索信息时，我发现历史资料中对杏仁水的呈现存在一些有趣之处。

以下是我能找到对最早的对杏仁水的描述。这是一条在 Level 4 的办公终端中发现的聊天日志。

[JackalOfSpades]：神马鬼，冰箱里的水居然是热的。不过还好，至少它能喝。如果你闻到杏仁味，千万别喝。

[Bart0nius]：我靠。

[ClassicHopper]：Bart0nius？你还好吧？

[Bart0nius]：现在还好，刚刚晕过去了。所以听话，别喝那破水了。

[ClassicHopper]：好主意，我赞成

[ClassicHopper]：祝你好运

很有趣，这段对话似乎暗示了杏仁水是有害的。根据我找到的记录，在很长一段时间里，杏仁水都被认作是一种有害的饮品，只有将它涂抹在伤口上时，才能起到一些治愈的疗效。然而，在某个时间点，一切都变了：所有当前的文档都将杏仁水列作一种安全饮品。

我目前的猜想如下：我相信杏仁水的化学成分变了。跟据我所收集到的信息，杏仁水的效果发生转变的同时，人们对它口味的描述也从“苦杏仁味”逐步变成了“香草味”。我相信最初得名杏仁水的那种液体，其中一定包含了大量的氰化物；这样就能解释喝下它后出现的不良反应。不过，随着时间的推移，杏仁水中的氰化物含量大幅下降，逐渐变成了我们如今熟识的样子，最初的有害效果也完全消失。当然，没有任何科学的理论能够解释，为何后室中所有的杏仁水样本中的氰化物含量都不约而同地下降了。

我猜，只能说“杏仁水之谜”又多了一个吧。

M.E.G. 内部报告：域层级最新探索

域层级

域层级是一个我们所知甚少的层级。理论上，域层级中包含了所有宇宙中所有可能存在的概念。这些概念表现为一颗颗小球，被称为“复杂概念交集”，当流浪者触碰这些小球时，对应的概念将被投影至其思维。许多“复杂概念交集”聚集在一起，对应了一个层次更高的概念，即“实概念域”。通过域层级的密钥，可以轻松进入域层级。然而，使用这些密钥时，可能会导致其部分结构消失。

尼克·科沃基安意外进入域层级后拍摄的照片。

近日，M.E.G. 成员尼克·科沃基安无意间激发了一把的域层级密钥——当时我们并未发现，Alpha 基地内一只浸泡在机油中的大猩猩其实是密钥——随后发现了一片新的实概念域。据信，当科沃基安无意间接触钥匙时，他脑中思考的实概念为“信息”，这使他进入了一片崭新的实概念域。在域层级内滞留数小时后，科沃基安在“信息”实概念域内入睡，被传送入 Level 906。不幸的是，在这一过程中，密钥的部分被损毁了。科沃基安申请对公众隐瞒大猩猩死亡的原因，以免引发 Alpha 基地内工作人员的群情激愤。

在科沃基安进入域层级之前，此层级一度被认为没有科学价值。域层级不可预知、难以理解，不值得冒着风险去探索，因而我们对其缺少认知。尽管约翰·卡西迪在该层级的实验证明该层级的确具备将概念带入现实的能力，但实在过于危险且不可靠；况且，通过在层级内接触复杂概念交集所创造的投影似乎没有实体，仅能被观测。然而，“信息”是一个无需实体即可传递的概念，因此 M.E.G. 决定再次组织一次对域层级的考察，探索更多的信息。这次考察将验证我们的猜想，同时，尼克·科沃基安自愿带队这次考察。考察队将在引导下进入域层级，收集需要的信息，随后迅速撤离，以免遇到不可预见的情况。

考察计划如下：

  1. 由于域层级的密钥一次只能送入一人，我们此时也仅有一把残缺的钥匙（剩余的大猩猩尸体），本次考察团仅包含尼克·科沃基安一名 M.E.G. 成员。
  2. 科沃基安携带一个 M.E.G. 标准生存包与一袋安眠药进入 Beta 基地。
  3. 科沃基安与残缺密钥接触，同时专注于实概念“信息”，进入域层级。
  4. 科沃基安构思写有总部问题的纸片概念，通过截面方程前往对应的答案复杂概念交集。科沃基安在此时可自行探索收集信息的方式，以找到最高效的方法。
  5. 总部问题测试完毕后，科沃基安将尝试得到“何为后室”的答案。
  6. 得到答案后，科沃基安服下一枚安眠药，在实概念域中入睡。理论上，他将进入 Level 906，并通过 Blanche 女士回到 Beta 基地。

如本次考察顺利完成，我们未来可将域层级视为信息来源之一。

M.E.G. 采访日志节选，监督者 Kat

监督者 Kat

作为目前 M.E.G. 三位创始人中最神秘的一位，Kat 选择在 Level 135 里一片偏僻的森林中度过一生。监督者 Kat 对 M.E.G. 的事务极少过问，因此也有人质疑她的头衔，但她学识渊博、经验丰富，另外两位监督者总会在遇到重大事件时询问她的建议。Kat 的过去笼罩在迷雾之中。有传言说她是失落一族的一员，已在后室中生活了千载岁月。


采访者：尼克·科沃基安
受访者：监督者 Kat
前言：尼克科沃基安申请采访监督者 Kat，通过她历史的视角丰富自己对杏仁水的研究。监督者 Kat 通常不见访客，但科沃基安成功从监督者 Andrew 那里得到了特殊许可。

监督者 Kat

记录开始

Kat：我听说，你想知道水的历史？

尼克·科沃基安：杏仁水……我是说，没错，水的历史。

Kat：要把亘古的记忆编织成一张毛毯可不简单，但我会试试。

尼克·科沃基安：请继续。

[Kat 指了指左边一棵高大的白桦树。]

Kat：看到这棵树了吗？

[科沃基安点头。]

Kat：它看起来是静止的。你可以每天来看这棵树，一连看几年。它看起来纹丝不动。但我在这里住了很久很久，久到我还记得它最初被栽下的时候；我还记得它最初有多小，记得它是怎么一点点变大的。所以，虽然它现在看起来是静止的，但我知道它其实在动；等我一个世纪后再来看它，它会变得面目全非，可又状似静止不变，就像现在一样。我们的世界就像这棵树：它改变得如此缓慢，我们都不能用肉眼看到，但它永远都在改变。

Kat：我出生时，世上并没有混凝土与钢筋构造的迷宫，也没有无穷无尽的黄色墙纸回廊。我们的世界看起来更像一个森林。这是因为，在表层的一切与现在大有不同。当表层变化，我们身处的镜子也会变化。

Kat：但镜子反射的，不只是照来的光。它所看到的，远比我们肉眼能理解的更多。它用镜面扭曲了那些我们看不到的东西，直到这些扭曲形成了新的反射，就像那些混凝土，就像一切在此之前的事物。它们静止着，变化着，与自身映照的世界再无瓜葛。

一次有瑕疵的反射。

尼克·科沃基安：所以，你到底想说什么？

Kat：容我道歉。当我回忆得太多，思绪就不禁开始漫游。我说了这么多，其实就是说，“水”并不一直是水。在我的人生中，它经历过许多形态。我曾经看它是地底迸发出的烈烈熔岩，看它是岩石与木头上呼吸的苔藓，更多看它是我们所喝的，“水”。

[Kat 停顿了一下，倾听风声。]

Kat：有什么不属于这里的东西在偷听我们。

[她拔出一柄华丽的匕首，向着左边的白桦树扔去。]

[匕首在空中翻转，最终插在了树干上。一只原先通过伪装色隐藏的低矮人形生物显现出来，它的脖子被匕首钉在了树皮上。]

[随着那生物死亡，它的皮肤迅速变得焦黑，绿色的血液滴落在树叶上。]

尼克·科沃基安：这他妈什么！？

Kat：无需在意。看来是一些旧日的鬼魂正在回归，但它之于我们现在的故事无关紧要。不过它的出现，确实表明，我们应该长话短说。所以我直接告诉你结论吧。

[Kat 从树皮上拔出匕首，那生物滑落在地。]

白桦树上的刀痕。

Kat：当我下次来看这棵树，它将长得更高大，但我留下的这道伤疤不会消失。树皮上的裂口改写了它生长的轨迹，但不会完全偏离原本的路线。可如果我砍下整棵树呢？这就相当于，用不可预测的方式彻底改变了它。这棵树的树根早已生长到了我们所知的世界之外，我们无法承担那种行动的后果。

尼克·科沃基安：所以，你到底想说什么？

[Kat 将匕首插回腰间的刀鞘。]

Kat：我是说，纵使你有改变自然的能力，但若自然做出回应，也别感到惊奇。相信我，如果说我在漫长的人生中学到了什么，那就是这句话了。

记录结束

狄俄多斯，早期在部分科学文献中被称为“后室”——这一名称由其壳体上居住的少量半智能寄生生物给出——是目前已知高阶多元宇宙中最大的活体有机体，仅次于其他几个已死亡的巨型有机体，例如伟大之环、反虚空、P 和上帝。模因信标的探测表明该有机体为一个巨大的元克隆集群，占据了无法测量的无限三维空间、约 123024 奥祖拉克的五维空间，有可能还延伸到了不可观测的更高维度。它自我复制的机制扩张着自身的规模。在这一机制中，它吸收被带入体内的模因学信息，将模因学信息并入自身模因集的复制体中，以被吸收的概念为蓝本，创造包含无限物理空间的节点，从而完成扩张。

狄俄多斯的外层壳体，即三维的“壳”，被名为“栈”的空间井完全包含。栈内的异常空间性质允许无限个包含类似结构复制的节点同时存在于同一片维度且不被四维空间切割。这些节点之外则是大片的虚空，为节点提供了无限三维延伸而不进入其他节点领域的条件，仅有少数例外。据信，这一异常空间性质正是狄俄多斯能反常地以庞大身躯长时间存活的原因。

狄俄多斯的主体从四维、五维空间延伸到栈之外，难以研究，这一部分被称为“胶体”。胶体是一个 103024 奥祖拉克的五维结构体，完全由抽象的模因材料与散落其间的具象空间构成，大部分质量聚焦于中央内核。
