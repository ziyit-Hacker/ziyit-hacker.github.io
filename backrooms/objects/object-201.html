那生物奋力奔逃。

我们埋伏在33号层级，用一窝新生环颈蝰蛇散发出的微光引诱那动物现身。我们注视着它轻快地步步接近，鼻头耸动小心嗅探着空气中弥漫的危机，可惜这点警觉并不足以令其脱离险境。詹姆斯是第一个开火的，他的子弹从那幼鹿的脑袋旁擦过。

它转过身来，乳白色的瞳孔骤然放大——

（我眼前浮现出三段粗糙的木柱，如同疼痛的拇指扭曲着伸出黄色的墙体。沿着长廊向深处探寻，镜头中呈现出一些架设在高度非同寻常的天花板上的北欧酒店同款粗大木梁。我继续向前，天花板缓缓压低，周遭灯光忽明忽暗。在下个拐角处，入口处的墙体残缺斑驳，正是在此处，虚幻的边缘消逝无踪，现实的本体再度回归。）

——狩猎开始了。

詹姆斯和本尼冲在前头，而我紧随其后，霰弹枪紧贴着我的胸脯。这家伙敏捷的令人恼火：它在货架、收银台间急刹、攀爬，沿着墙面飞窜，以快得模糊的速度在一个个拐角间绕圈。我们看着它在狭窄的小路间飞驰，如履平地。复合地板的碎片飞溅，在我们沉重的靴底下滑出刺耳的声响；它径直撞破施工防水布，而我们紧随其后。我们向这鬼地方的深处进发，向我们的猎物步步紧逼。

（洞穴中的空气凝滞沉重。它就像是童年时躲在毛毯下用手电驱散黑暗的幻想。短暂的一瞬，这片空间令人觉得封闭安稳，就像是被子中产生的一团空气泡泡，在我一声声的喘息中被逐渐消耗）

几乎……几乎触手可及。我把我的手指放在扳机上，准备好纵身一跃——

（周遭喧闹的无法忍受。我知道我完全没有饮酒的欲望——无论如何我对那东西都生不出一丝好感——但周身的人们对此毫无顾忌。我看着他们挥舞着镶边的马克杯，里边冒着泡沫。他们丑陋的脸上挂着狂笑，为当下狂欢。反观我呢，却是每分每秒都坐立不安。）

一声枪响响彻整间百货商店，玻璃应声碎裂。橱窗玻璃四处飞溅，詹姆斯捂住脸低声咒骂。我继续向前——手中的玻璃瓶子蓄势待发。我的靴尖停在遍地狼藉之外，而苍白，沾满血迹的幼鹿尸体正躺在展示灯光下。我示意本尼戴上手套——即使已经死亡，那幼鹿的毛皮底下依然藏着剧毒——而我们三人迅速将值钱的部位装进我们的手提箱。

（我跪在一间低矮的房间内，四台电脑一字排开，底座垫着塑料仿原木墩。周遭光线昏暗，显示器散发的微弱光芒仅能照亮三分之一的空间，勉强可见墙面的托儿所风格立绘和门旁仅有的一个配电箱。门洞深处只剩一片漆黑，我清楚那黑暗下掩映着的唯一事物是商场的自动扶梯。）

幻觉带来的残影褪去，如同风中撕裂的蛛网

我们拖着猎物的尸体返程，三人怀抱着试剂瓶，脑中翻涌着本不属于我们的记忆。

BNTG 手记，黑市中最为昂贵的战利品


Object 201 - “光晕抗病毒血清”

[图1：原型抗病毒血清，以海绵作为参照物。]

物品编号： 201 ｜ 分类：消耗品

来源：人工合成

黑市上流通着众多价格不菲的货物，但光晕抗病毒血清是其中的硬通货。初见此物，似乎并没有什么特别之处：小拇指长的小玻璃瓶上没有任何标签。可正是在这里，装着人类所知的最为珍贵的奇珍异宝。

描述

光晕抗毒血清是一种不透明的虹彩液体，光照下如同碎钻般闪烁。低温冷冻后，液体会呈现出澄澈的淡蓝色。常温下，药液会像水银一样互相聚拢、粘连。而在空气中短短数分钟的暴露，便会使其凝固结块。

通常而言，它会被装在没有标记的小玻璃瓶中售卖。原因有二：第一，这是出于保护药液的虹彩光泽，因为长时间的强光照射会使其标志性的珠光色泽消退，这会招致买家对货品质量的怀疑；1第二，明目张胆地携带一瓶Object 201，往往吸引的不是普通买家，而是不法之徒。

图2 展示的是一整批六支成功产出的血清成品中的一支2

特性

对于Object 201是如何起效的，我们仍然知之甚少。唯一可以确定的是，这份药品解毒效率极高，效果稳定可靠。

! 使用说明 !

将整瓶药剂以注射方式送入体内。

如果没有注射器，亦可直接涂抹创口或任何可接触静脉的创口；在使用前请冷冻一小时以规避强烈幻觉，视网膜干涩等副作用。

简而言之，对于后室中任意一种毒素，光晕抗病毒血清都算是万能解药。目前为止，还没有哪一种毒素是光晕抗病毒血清不能治愈的。即使是垂死之人，只要有这支小小的白色试剂瓶在手，令他恢复健康也并非难事——如果不考虑它那高昂的价格的话。

分布地点

[Fig.2：一瓶光晕抗病毒血清被分装在七个试剂瓶中]

不幸的是，黑市的高价并非无缘无故的。光晕抗病毒血清并非后室的自然产物。在这份奇迹药材的各类提取、合成原料里，生物躯体组织是当之无愧的核心成分。

更确切地说，是Entity 201的血液，一种仅存于数个孤立层级中的濒危物种。

21世纪10年代早期，隶属于MEG的各大定居点大肆捕猎蓝颈幼鹿。这一方面是因为其皮毛可作刺绣奢侈品的上好原料，另一方面则是由于定居点居民出于迷信思想而视其为不祥之兆。经年累月的猎杀使幼鹿的数量断崖式下降。等到光晕抗病毒血清的价值被发掘出来时，一切都已经太迟了。每个幼鹿族群的数量都已经低至数千只。

但在资源枯竭的绝境前尚存一丝转机：内陆层级是环颈幼鹿最后的庇护所。现存约四分之三的Entity 201都栖息于此，幼鹿的活动踪迹在此地随处可见。但在周边其他层级，这类实体已经近乎绝迹。BNTG发布招募公告，许诺高额酬劳与丰厚利润，招募本地人员参与狩猎。首席贸易官本尼迪克特·泰勒对重启光晕抗毒血清产业链表现出极大的兴致，他认为这将继续为深陷绝望深渊的流浪者带去一线生机。
