Object 60 - “王座”
2023 经典竞赛 Object 60 - “王座”

描述

王座。

Object 60 是一张设计简单的铁椅，表面光泽，漆色深绿。就像其他正常的椅子那样，Object 60 有四条腿、一个座位、一张椅背，但没有扶手。这张椅子显然得到了妥善保存，表面没有明显的划痕与缺口。进一步的研究表明，该物品能抵抗所有形式的伤害，且绝对无法将其从原位挪移半分。

发现

最初发现 Object 60 并非寻常椅子的人是高级档案员劳尔·马库斯，他在此前已经研究了该物品数年。在他喋喋不休地宣扬了几个月后，其他档案员终于同意检查一下马库斯的发现，而结果则令人惊奇——他没有说谎。马库斯在档案中寻找到了数十个“发现一把普通的绿色椅子”的记录，每一次都在不同的位置，归档时间从几个月前到几十年前不等，甚至还包括了数个世纪前的资料。

特性

正如上文所述，该物品的主要性质为：抵抗一切形式的伤害、不可移动。但它还具备一些更模糊、无法被理解的特质。例如，接近该物品可能潜移默化地影响人的心理。精神承受度较低的目标会发现自己的记忆出现分支，逐渐认为 Object 60 对于他们弥足珍贵，曾在自己的人生中不可或缺，因而开始照料它，乃至在需要时保护它。

除了以上的特性外，Object 60 偶尔还会给坐在其上的人一个祝福。这种祝福的给出规律尚不明晰，因为这些受赐者似乎没有任何共同点可言。

马库斯声称自从第一次坐在该物品上后，他就得到了这些禁忌的知识：他认为 Object 60 一共可能给出五种“祝福”：

  • 头脑清醒。
  • 获得“隐秘”的知识。
  • 勇气与激情激增。
  • 更强大的心智能力。
  • 灵魂得到延展。

这些祝福的具体含义仍无法辨识。

位置

本质上，该物品可以出现在后室的任意层级。发现该物品的报告中，包括出现在 Level 39 的树林之中、半埋在 Level 46 的沙堆里，甚至是藏在 Level 4 的一个橱柜里。综合所有报告来看，该物品似乎只会随机出现在任意地点，其位置并无意义。然而，唯有一例报告与众不同，即高级档案员马库斯提交的档案。他在一个有位特殊的地方发现了 Object 60。

马库斯报告道，他曾经在研究期间进入了椅子间，在那里他遇到了一系列不同寻常的状况。档案员刚一进入房间，就听到了“为椅狂热”团体成员共同的吟唱、低语与祈祷。尽管这些声音低到难以听清，马库斯还是成功分辨出了一些音节：“……我们的主……回来”以及“众神之王……终归圣座”。另一个怪象为，整个房间里挤满了所有可能出现的椅子，这一反椅子间内椅子均匀排布的常态。此外，这些椅子并非是整齐摆放的。它们全都“虔诚”地、众星拱月地围在 Object 60 周围。

根据马库斯的说法，这是所有椅子都来此朝拜 Object 60。因而，他称之为“王座”。
