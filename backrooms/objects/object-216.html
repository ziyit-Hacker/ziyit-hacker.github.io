Object 216 - “海鲁姆神灯”
2022 物品競賽 Object 216 - “海鲁姆神灯”

“……他最初的破碎，起始的激燃，元始的造物都是如此灿烂夺目……他透亮清晰的神谕贯透每个位面，每个世界，每个灵魂：‘此地应有我威光。我应聚合这些光，去弥合那些暗！我要将每个灵魂中的蚀人之暗驱散！因此所有生灵皆得我引导，不再成迷途羔羊！我应在我爱之繁生之躯与魂内；在万物之中筑起抗衡黑暗的厚障壁……’”

- 《万古雷瑟书》抄本
源始之光，万物之光的创生。

前言：

为了进一步了解海鲁姆神光，我们首先得知道海鲁姆神光的实质是什么：海鲁姆神光是源始之光破碎后掉落的碎片；是包容所有产生灯火的物质的起源，海鲁姆神光亦为灯具的源头。海鲁姆神光可以以任一自然发光体的形式呈现，如星体、烛焰，广而言之即非人造的或已存在于此宇宙的自然法则者，乃至超越常规空间者，比如在后室内发现的发光物体等皆可为其载体。海鲁姆神光在此条件下仅仅会在后室中以油灯的外观呈现。如果一个人试图通过人工制造一个油灯以获取海鲁姆神光并产生其光焰的话，其与原始形式的海鲁姆神光的效能将有天壤之别1。这一现象证明了海鲁姆神光总是能在不同特定物体中存在，并诞生于多元宇宙中。

描述：

一盏从Level 9内取来的海鲁姆神灯的照片。

左图个例是一个具有酷似70年代油灯外观的海鲁姆神光：油灯的基座及提把由锈蚀的金属制成，灯罩是包围着灯焰的薄层玻璃片。该灯具被M.E.G.人员Penelope Harveston在对Level 9的一次勘探中于一个起居室内被发现。海鲁姆神光通常能在昏暗的层级中能被发现，它们所具有的反赴火效应特性对于在后室内的生存至关重要，我们之后将会具体探讨此效应。海鲁姆神光油灯2抗粉碎，轻质，而且耐用，能够承受至少2t重的压力3。此外，这些神灯似乎能发出通感效应的灯光，这类灯光温暖，让人冷静，同时带有香气，包括但不限于：薰衣草，香草和甘菊；据估测应仅为点亮海鲁姆神灯后所产生的效应，在熄灭神灯后其不会再散发香气。而在点亮神灯时，其会发出一种类似于白噪音的较为安静的嗡鸣声。这些特性保证了面对压迫感时流浪者能保持精神清醒可控。

尽管海鲁姆神灯常常发出的是一种480-515流明的白黄色的光4，目前仍存在有亮度能达到1000流明的神灯，这些神灯与其他神灯相比拥有更强烈的直接反赴火效应。但是这并不完全意味着在价值上有着极大差别，它们仍然拥有相同的IME5最大值与最小值。目前我们尚未测得海鲁姆神灯在激活状态下能维持多久，似乎只要使用者能对其发起请求其即可一直亮起。在某些情况下在被进一步注视时，此物品也会随机被激活。观察发现海鲁姆神灯在被激活时不存在任何能量增加或损失。

反赴火效应：

反赴火效应(I.M.E. )是海鲁姆神灯用来抵抗实体的效应6。影响半径为15英尺(圆周长为94.25英尺)，而这些实体最远会与神灯持有者保持30英尺的距离，如果持有者靠近实体它们会退避三舍后撤得更远。 尽管海鲁姆神灯的温度远没有达到能伤害具有攻击性和天生危险的实体，但只要它们停留在海鲁姆神灯的影响范围内便会受到神光的严重伤害，有时则会产生致命烧伤；免疫烧伤的实体并不能抵抗其伤害。

如今我们发现唯一对海鲁姆神灯免疫的有机生命体是人类及永驻一族——后者不仅对一个仅已知其名的神性形象即源始神子极度崇拜，还是源始之光的亲手造物，这与我们已知的一个“碎片”不能混为一谈。无害/被动性实体在神灯影响下一般总是安全的，但也有相反的案例存在。变异为实体的人类和拥有人类智能的实体对反赴火效应无法免疫。由此信息我们假定海鲁姆神灯遵循着一套由于其模糊特性无法精确指出的严格先天法则。

基于前置观察，神灯的激活周期(认定为不会闪动且保持常明)只要在持有者对其保持信仰的情况下就都是连续不断的。进一步研究表明相信源始之光存在的信众能将他们的神灯激活周期一直延长；在某些情况下，神灯会在危险出现时自动激活。从一盏海鲁姆神灯被停止激活算起，此区域被灯光驱赶的实体仍会对光源感到恐惧，并自主远离光源，这一情况保持约2至4分钟，之后才能恢复其基本认知能力。拥有再生能力的实体的自愈过程会更慢，但最终可以恢复活动能力。

人工反赴火效应：

由于海鲁姆神光会在全后室的油灯里存在和产生，非层级产生/非层级已有的油灯也不是此规律的例外。人工反赴火效应(A-I.M.E.)会在制造一个新油灯时发生；海鲁姆神光的确会在新油灯中生成，但这不能完全激发神灯的能力。事实上99.8%人造海鲁姆神光的能力都因人造的缘故被完全限制了。目前尚不清楚为何在此情况下几乎不可能产生有效能的人工反赴火效应7 ，尽管可能性的存在毋庸置疑；然而许多在神秘学研究方面的研究人员和学者的主流假说强烈支持了神灯与神类存在的联系，即所谓的源始神子和海鲁姆神光本身存有的明显神识。

海鲁姆神光之诫：

尽管大部分规则即使在第一代永驻一族的长老帮助下仍未被解释(其余部分则已阐明)，海鲁姆神光被推测是非自然地具有半自主神识，它遵循着由源始神子（唯一能通过源始之光制造海鲁姆神光者）制定的无法干涉，不可替代的运行规则。海鲁姆神光并非基于多元宇宙，特别是后室内亦存在的定律而产生，它几乎是凭自己意愿凭空出现的。它能发生进化并演变为各式各样的光，海鲁姆神光可能是依源始之光的在各个已知及未知方面需求而发生演化的。 排除其他的可能性，海鲁姆神光会选择油灯为其在后室内的化身，并以此形态仍在传播其影响力(即便是低效的形式) 给后室内存在的所有的油灯。尚不明确其为何会将油灯作为外体的原因，但这则证明了海鲁姆神光自身认知的模棱两可之态。

研究日志：

Object 216 - 海鲁姆神灯

实验日志 #1
日期：06/24/2021
实验领衔：Catelyn Rodriguez

摘要

现如今， 我们认为Object 216“海鲁姆神灯”的激活周期(及I.M.E.效能)的设定是完全随机的。本测试意在找到真正在影响激活周期长短的因素及影响原理，并尝试将激活周期的长度设定在一个更加稳定，可靠的时间框架内以确保流浪者能通过如信仰，祈求等特定的方式来保护自身安全。

为了协助接下来进行的实验，历史学家们已先行破译了来自失落时代8的经文，这些经文以直接引申形式包含了最初的有关海鲁姆神灯与神光的传说——这些传说提及了与海鲁姆神灯有关的强烈信仰现象。通过这些手稿记录，实验中我们随机选取了几名受试者，分为两组在不同情况下暴露于海鲁姆神灯光照下进行实验。

实例研究#1-神灯交互
关闭研究档案

4位受试者分开坐在4个相当昏暗的小房间内，有两名手持海鲁姆神灯的研究人员。第五个房间内没有受试者，作为空白对照。每位受试者都被要求与海鲁姆神灯进行交互祈求活动。

第一个实验对象是Natalee Thompson， 女性，31岁，经常主动在M.E.G.参与志愿活动，她也是首个报名参加海鲁姆神灯实验的人。她首先进入房间内，短暂的兴奋过后，她被要求坐下。当海鲁姆神灯被放置于她9跟前时，对象对其表现得缺乏兴趣，尽管我们已预计好对象并未提前见到过海鲁姆神灯。在经过2分钟对其的检查后，对象成功激活了神灯，神灯发出了相当昏暗苍白的灯光。对象试图将其调整得更亮，于是多次对旋钮进行了多次调节。我们发现神灯得光彩在Thompson表现出沮丧之情时渐渐暗淡下去。最终，对象对其完全失去了兴趣，神灯最后完全失活。几分钟后对象试图再次激活神灯，但努力无效，观察人员对Thompson 进行了评估后请其离开了实验场地。
第二与第三个实验对象是双胞胎Michael和George Ramsay，二人被其母亲Minerva Ramsay带至实验场地时皆时年5岁。二人被分在不同房间，与Thompson一样被分发到了神灯。

双胞胎中得第一个，Michael Ramsay对昏暗的房间表现出了一定的恐惧感。当将神灯提供给他时，对象拒绝了，并将其推开，开始轻声啜泣。几分钟后神灯自动激活了，发出耀眼的光芒。对象冷静了下来并迅速感到温暖感，因此将神灯抓在手里。神灯的光亮又一次增强了，而观察人员则记得能闻到强烈的薰衣草香气充满了整个房间。5分钟内，对象将头靠在桌子上安然入睡了。Michael在此之后被研究人员将其抱离实验房间，送还其母亲所在处，同时也是George做同样实验的地方。在睡醒后，研究人员评估了Michael的状态，请其离开了实验场地。

与Michael不同，George被观察人员认为是恬静安分的，他表现出了更良好的性格。对象与研究人员积极互动，询问了许多与研究目的有关的问题。当给予对象神灯后，对象开心地拿起并把玩起了神灯。之后对象尝试转动旋钮来激活神灯，但仅仅让其冒出了些许光芒。为了让神灯变得更亮，对象开始摇晃神灯，但没有收效。神灯地的灯光甚至大大减弱了，George气愤地将神灯扔在墙上，无能狂怒地离开了房间。在彻底检查后，神灯并未受伤分毫，但是不再能通过旋钮激活。几小时后，经评估对象被移出了实验。

最后一个受试者，由一个Entity 19810个体陪同，是一个在实验前两周切入后室的名叫Theo Bryant的流浪者，他居住在level-18Level 18已满一个月。研究人员给了Bryant同样的引导和一个Object 216。在看到神灯的第一眼，他们对神灯表现得不想信任它，仅仅是戳了它一下。在几分钟内，对象小心翼翼地拿起了神灯并成功激活了神灯。观察人员则记得看见了神灯内升起了一丝苍白地灯光，与对象二类似，Bryant开始对神灯表现出了浓厚的兴趣。在与神灯交互3分钟后，对象想要将它展示给身后的同伴实体看——直到之后Bryant发现它正在烧伤毛绒恐龙，它正在海鲁姆神灯照耀下燃烧。Bryant在惊慌之下马上丢掉了神灯，瘫坐下来。在此事件之后，研究人员将对象们移出实验，并对对象之一的毛绒恐龙进行了时长2周的治疗。至于这个神灯，尽管它很快因对象将其掷于地面而失活了，但它仍能在良好条件下继续运作。


实例研究#2-Level9
关闭研究档案

在进行实验之前，两组随机各16人被均分的试验群体加入了测试：一组暴露在与海鲁姆神灯有关的各种因素下，包括来自于永驻一族自身所有的知识(称为实验组1)，另一组则仅仅接受了与此物品相关的必要先导知识(称为实验组2)。在每个实验方案中，各个实验组都会被投放至相同层级，同时保持着相同条件不变。

对实验组2进行测试，他们被要求携带已激活的神灯在Level 9指定区域内行进50米。该实验组由观察人员进行激励并告知他们海鲁姆神灯本身及其具有的异常性质。在超过一分钟的时间的集体商议后，所有人都认为灯里的光最有可能是神灯具有异常性质的原因。据此确信，他们手中的神灯变得更亮了；观察人员对此进行了记录

在面对威胁时，实验组2的初始反应是立刻逃跑。远处观察人员坚持让他们待在原地，并尝试使用神灯来对抗逼近的实体，即一个笑魇。在神灯之一在实体面前被迟缓地抬起时，尽管光亮不足，但实体在接触金光的一瞬便被灼伤，并且在实体自愈前揭开了实体的表皮，而这个笑魇则在痛苦地尖叫。看来在遭遇实体时神灯会比之前更亮，此实验组对神灯的信赖使I神灯变得更为强力。

一天之后，同一时间实验组1被发放了同样的神灯。在短暂的5分钟等待期内，对象们被鼓励进行亲切交谈，我们观察到他们交流后分为了三个小组，分别对神灯有着不同的信赖度：8个人完全相信神灯是由一个上古生灵创造的，并相信神灯能庇佑他们；4个人则保持中立，并选择在实验中顺其自然，，但仍相信神灯可以保护他们；2人完全不相信这个说法；剩下2人则持漠不关心的态度。在等待期过后，实验组1被送至Level 9内进行穿行。

在穿行期间，观察人员一直在关注每个小组神灯亮度的差别，他们对此物品的信任程度影响了神灯的性质，但这并不影响I.M.E.的比率。从这之后看这是毋庸置疑的，随着游荡时间的增长，信任程度会影响海鲁姆神灯的照明时长。在观察人员发现这一事实后受试者被依照等待期分组相互分离观察。第一个小组的神灯保持激活状态最久，5小时后才失活；第二小组的神灯保持点亮1小时；而第二小组保持点亮50分钟；第三小组的神灯被激活30秒后便熄灭了。

从上述实验及由各种渠道自永驻一族收集的信息发现海鲁姆神灯的效力取决于使用者对于其激活的坚信，祈求，信仰和使其被激活的思维。在这两个实验之后我们进行了更多的实验，它们都与此实验有着相同的结果。

Object 216 - 海鲁姆神灯

实验日志 #2
日期： 6/30/2021
实验领衔： Tristan Petrovic

摘要

在2021年6月21日晚8：03，我们首次于求真者研究小组成员Penelope Harveston在一个门厅内发现首个Object 216后在Level 9内记录到I.M.E.事件，Penelope Harveston在那里成功在一个笑魇的威胁逼近下激活了神灯。因其由衷单纯的求生欲望，神灯开始剧烈地发出金黄色爆燃灯光，烧焦了这个笑魇个体。这标志着接下来一系列测试此物品性质试验的起始，这些试验得到了监督者议会的鼎力相助。

实例研究

实例研究#1-测试对象：笑魇
记录于07/12/2015

实验素材：

  • 笑魇横行区域 (Level 9)
  • 1个笑魇个体
  • 1名神灯持有者
  • 1个测试间
    • 配备有恰当防护，装配了三层玻璃和面向笑魇个体出现方位的铁栅栏的特制实验室。

Procedures:

  • 研究人员会全程观察测试。
  • 此区域的所有未授权人员都被护送离开了此研究站。
    • 如果未授权人员坚持滞留，应对其声明M.E.G.正在进行实验；必要时可以武力驱离。
  • 神灯持有者在实验室内进行测试时全程装备重型护甲。
  • 在实体失能后彻底击杀笑魇——此举在神灯能完全消灭笑魇时不列为必要项。

测试：

测试 1：笑魇个体
日期：6/30/2015
测试者： Elizabeth Ely Loomis——流浪者

[记录开始]

[00:03]Elizabeth Loomis——此后称为Ely——进入了实验房间，被要求在他面前的桌子上放置的神灯。

[00:10]对象拿起了神灯，并用其将耀眼的金光洒满了整个实验室。观察人员继续要求Ely手持神灯走至窗前。他按此行动了。
