Object 16 - “皇家口粮”

描述：

皇家口粮是一种不会变质的食物，在整个后室中颇为罕见。除了它作为首选营养来源与极具分量的交易筹码的声名之外，皇家口粮这一概念在流浪者中已被近乎神化——哪怕仅仅获得一份，都会成为一件轰动之事，而这也成了许多人争夺其所有权的根源。

一块皇家口粮的照片，取自一位匿名捐赠者的藏品。

皇家口粮的外观近似一小块石蜡，但其质地明显更为柔软、更加接近胶状物。所有皇家口粮的尺寸恰好为长 9cm、宽 6cm、厚 3cm，而此大小刚好可握于手心。皇家口粮的表面光滑、棱角分明、毫无气味，且即便处于室温1下，摸上去也微微发凉。尽管无人确切知晓是谁第一次尝试食用卖相不佳的皇家口粮，但发现其营养价值的这件事，已然给后室的日常生活与文化，带来了深远且影响甚广的连锁反应。

皇家口粮的稀有性，在很大程度上为其增添了神秘色彩。虽然据推测它们可能存在于后室的任何地方，但能够偶遇皇家口粮，实属千载难逢。该物品已确认的出现地点分布毫无规律可言，范围可从流浪者聚居的层级至一些罕见人迹的凶险之地。即便如此，它们也常常被放置在极不显眼的地方（甚至有人猜测其是被人有意放在那里的），以至于必须时刻留神，才能发现那珍珠般的珍品。无数流浪者为寻得皇家口粮，无所不用其极，许多人耗费数日之久，只为求得这美味佳肴。

食用者对皇家口粮味道的描述因人而异，不过貌似所有人都认同一点：哪怕舌尖仅仅是轻轻碰到一丁点这黏软的美味，一股欣快感也会紧随而来。无论食用多少，也无论饥饿与否，摄入任意分量的皇家口粮都完全能满足流浪者的营养需求，并且倘若一整份皇家口粮省着吃，单单一块就能维持数月之久，而后才被完全消耗殆尽，理论上这使其成为长期探索中最具效率的食物来源2。按理来说，这会使得该物品成为在此类情况3下配发的标准口粮，可每当皇家口粮被纳入伙食计划时，历来都会出现种种问题。

将皇家口粮用于任何实际用途时，最大的障碍归根结底都在于：该物品的味道似乎会对品尝者产生强烈的心理影响。皇家口粮的味道极其诱人，以至于流浪者只要身边还有另一份皇家口粮，便无法克制再吃一口的冲动，而这种冲动在刚吃完时最为强烈，但哪怕只吃过一次，其影响也可能持续数年之久。在首次品尝此物品后的数周内，流浪者往往会表达对其他原本还算可口的食物的不满——哪怕再吃到它的可能性微乎其微，他们也会全然执迷于那再尝一口的机会。因此，将皇家口粮纳入任何长期营养计划，都极有可能导致资源配给失控，而若长时间将其作为主要食物来源，反而会事与愿违地降低效能。

皇家口粮备受追捧，并非因其在生存场景中的用途；恰恰相反，它勉强算得上一种娱乐性药物。挚友、宿敌乃至反目成仇的旧友之间，无数争执都因一份皇家口粮悄然介入双方而起。后室地下圈层中，仅为获得品尝皇家口粮的机会便已达成种种非法交易与协议，乃至一旦被人知晓持有皇家口粮，就形同被悬赏人头。惯例认为，倘若持有一份皇家口粮，最好拿去和出价优厚的受惠者交易，切莫为满足好奇心而冒着上瘾的风险。

在后室的平民群体中，人们普遍对皇家口粮心怀敬畏，它不止是一件珍贵的发现物，更是厄运的预兆。一部分人选择冒险，哪怕只是为了体验品尝这所谓后室美食瑰宝的极乐；另一部分人则因惧怕随之而来的后果，放弃了机会。少数流浪者甚至认为，持有皇家口粮这件事本身就会招致灾祸，就如同人们认定从梯子下走过、在室内撑开雨伞都是不祥之兆一般。围绕皇家口粮的文化传说早已不止承载着人们对它的强烈渴求，更凝聚了一系列普遍且深入人心的观点：这份超乎寻常的食物本身究竟是否值得追求。古谚有云，禁果最是甘甜——可持有它的风险与依赖的赌局，真的值得换取那份难以想象的狂喜吗？

文件 016-003：露西尔·德容证词
采访人：卡茂·万布古

为留给后世参考，本次对已退休的 M.E.G. 高级档案管理员露西尔・德容开展了访谈。德容在担任 M.E.G. 远航部主管的漫长任职期间，曾时常沉溺于皇家口粮，本次访谈征集她的相关经历，旨在为后世档案管理员提供相关个人轶事的参考依据。

[采访开始]

万布古：德容小姐，感谢你接到临时通知便赶来。很抱歉又一次请你退休后抽身前来。

露西尔：害，别放在心上，这种事又不是头一回，以后也少不了。你清楚的，只要能帮到你们这帮人，我不介意跑这一趟，更何况是帮朋友。还有拜托——

万布古：实在抱歉！是露西尔，不是德容小姐。我还没习惯不再那样称呼你。

德容：卡茂，你的举止还是一如既往得体！那我们这就开始吧？

万布古：没错没错。想必你已经听说了，我们此次前来是要谈谈皇家口粮一事。

德容：当然可以。你想让我从哪里开始说？

万布古：我觉得咱们得从头说起……嗯，从最开始讲。你第一次是什么样的？

德容：几年前……说真的，其实是很久以前了，算下来确实过去许久，毕竟已故的贝塞拉先生当时也牵涉其中，他是我的一位老友。补充说明一下，这事发生在 M.E.G. 成立之前，那会儿这里只有一众零散的团体，都在试着搞清楚这片区域的情况。当时大家自然已经发现了一些信息，我们了解一些重要的事物，也开始互相分享这些信息。但仅仅几起因腰果水意外致死的事件，就让我们意识到必须想出规避它的办法。那时候这里的人口还没有暴涨，各个派系之间也尚未结下嫌隙。我说这么多，只是想说明，当时已经有少数人知晓皇家口粮的存在，我们当中一部分人更是把尽可能多地搜寻当成了自己的目标。

[德容咳嗽]

德容：贝塞拉先生——那怪人从没真正告诉过我们他的名——是一心要尽可能多吃后室里能找到的皇家口粮的人之一，至少他年轻时是这样……不对，是三十多岁的时候，算不上年少。我认识他那会儿，他脸上已经长出几道皱纹了。当初我不住在城市、研究工作还没成为优先事项，我们所有人都靠搜寻物资维生时，我便受他关照。每次外出搜集食物和饮用水，他总会特意强调，路上但凡找到石蜡，都必须交给他。当然，当时我们并不清楚他要这个做什么，但他态度十分坚决，我们心想行吧，给他也无妨。他名义上是个商人，我们便猜测这对他或许有用，况且我们又不是隔三差五就能找到这个。我在那片区域生活了大概一年，估摸着自己总共也就只找到一两块石蜡。

万布古：所以他没告诉你皇家口粮是什么吗？

德容：嗯，他瞒着我们其他人，独自占有了这条消息。他人其实挺好，但确实有点贪心，而且运气远胜过我和其他人——不知道他用什么法子，居然把这个骗局瞒了许久。那天我们之中另一个人找到了那块“石蜡”，我亲眼看见他咬了一口，吃下那一小块的时候，他整个人差点发抖。我当时自然一头雾水，可心里却想着：“既然贝塞拉先生都这么做，下次我要是找到一块，说不定也该尝尝！”过了好久我才……

万布古：抱歉打断一下——我不得不问一句，你们怎么会频繁找到皇家口粮？大多数人在这里待上好多年，野外都碰不到一份，可你们小队似乎总能频频发现，我没说错吧？

德容：你得明白，要是你成天在外头翻找各类零碎物资，早晚肯定能碰到一份皇家口粮。如今城市物资大多供应充足，人们不像过去那样频繁外出搜寻物资了，所以现在大家能找到这东西的概率很低，只是因为他们不像我们当年那样经常出入所谓的荒野。就像我刚才说的，就算是当年，我也花了好一阵子才找到第二份，那时候我索性硬着头皮，亲自试着尝了尝它。

万布古：那你感受如何？

德容：说实话，用美味可口都不足以形容它。那一刻我体会到一种前所未有的感受，那是一个全新层次、难以言喻的滋味。等我把一整份全部吃完时——这东西一旦开吃就根本停不下来——贝塞拉先生过来查看我的情况。当他看清我做了什么，整张脸瞬间惨白。他清楚我一定会向他追问，而他也必须为我们所有人给出一番解释。他身上缺点不少，胆子又小，所以也没打算再继续维持这个骗局。

万布古：那第一次尝试过后，你的这个习惯就是从那会儿真正养成的吗？

德容：可以这么说，没错。没过多久，我们这一小群人就因为谁该留存找到的皇家口粮爆发了争执。前五次还能遵循谁捡到归谁的规矩，可后来就有人开始小偷小摸。只要一扯上皇家口粮，理智就退居其次。没过多久，因为食物爆发了诸多争执，我们这群人根本算不上一个集体。最后大家分道扬镳——其他人后来怎么样了我不太清楚，只希望他们一切安好。自打那件事后，我一直盼着能再有机会弄到皇家口粮。可我在十一安定下来后，就很难再弄到它过足瘾了。偶尔会有人带一块到镇上，我们所有人都会想方设法把它弄到手，时不时会下些有风险的赌注，有赢有输。后来身上的担子越来越重，我再也没法亲自去找它们了。我明白自己终究得逐步戒掉它，消耗现有积蓄、透支还未赚得的钱财，根本无法长久。更何况，为了一份皇家口粮能换来的收益，有些人不惜痛下杀手。

万布古：我想这肯定不是件易事。话说你到底是怎么脱身的？

德容：办法很简单。我让人把我关在房间里，把我控制住，直到那种冲动消退为止。

[万布古立刻停下记录]

万布古：你在开玩笑……是吧？

德容：跟你开玩笑呢。看得出来，你还是和以前一样容易上当！

[万布古大笑]

万布古：我到现在真该学会，对你的话不能全信。

德容：该怎么说呢，我向来喜欢有意思的玩笑。不过回到你的问题，说到底就是学会克制自己罢了。我手头事务渐渐多了起来，身上的责任也要求我合理把控自身拥有的各类资源。你肯定想不到，在这里找到正经事做，远比漫无目的地游荡混日子要好得多。别误会，我偶尔还是忍不住掺和一下，但我认为只要稳住本心，人总能做到某种程度的节制。我花了好几年才练就这份自控力，可这远不像有些人想的那样难以做到。尝试皇家口粮并非要一辈子受束缚，只是不必将全部身心都投入其中而已。

万布古：说得有道理，不过我自己从没试过。所以你的意思是，克制住自身的欲望应该没那么难，是吧？

德容：倒也不完全是。说起皇家口粮——显然这不只是我个人的看法——它确实名副其实、盛名不虚。在你尝过之前，肯定早就听过各种传闻，说人们会为它痴迷癫狂，称其为诸神之食之类的。绝大多数人都会有这般感受，因为它本身就会带给人这样极致的体验。这也是很多人难以割舍的原因：吃一次还好，两次也无妨，可吃得越多，你就越能明白，为什么有人会说，我们人类的味觉本就不该被提升到这般境地。

万布古：诸神之食——我曾听人把它称作仙馔。要我说，这说法多少有点拼凑感。

德容：没错，虽说换作从前，我本心会认同你的看法，但实在找不到更贴切的形容了。这滋味完全不像是人类本该品尝到的，仿佛只是一瞥，窥见了远超凡人想象的美食。神话里的仙馔本是专供神明享用的食物，世间凡人能想到的任何厨艺都无法企及。只要舌尖轻触分毫——哪怕只尝针头大小一点，只需要这么一点就够，你就能彻底明白其中深意，也会懂为何绝大多数人都没法像我一样做到节制。

[万布古停下片刻记录笔记，随后将笔搁在记事板上]

万布古：话说了这么多，我还有个后续问题……想必你也听说过，我们所处的这片天地并非无神之地。这里确实存在诸多生灵，它们在很多方面都远胜于我们。

[德容轻笑一声]

德容：噢，多的是，我清楚得很！

万布古：那么，结合你亲身经历来看，你是否认为皇家口粮实际上只是某个比我们更宏大的事物的一小部分？

德容：不，不是的，那只是拿来作对比而已，希望你别觉得我是字面意思——我的意思是，确实有些人是这么认为的。呃，至少是我们这儿口中所谓的神明，他们信奉这套说法。不过先说清楚，我本身压根就不认同这个叫法。

万布古：我同意，我也不喜欢这个。

德容：是啊，说实话，我觉得这些事物能伴我们左右，纯粹是我们运气好。非要追问是谁、是什么造就了它们，其实根本没有任何意义，至少不会得出什么有价值的结论。毕竟我们现在根本无从知晓，不是吗？那一味猜测又有什么用呢？

万布古：我看这不过是一场脑力消遣罢了。这么多人出面作证，还试图弄明白这一切，我们也不是头一回听闻这类事了——

[德容嗤之以鼻]

德容：所有人都对此各有说辞，各持己见，诸如此类。要我说，这就跟口语里常说的杏仁水一样，它刚好就是被做成这样的。这已经是能给出最合理的解释了，除非那些所谓的神明亲自现身，告诉我们这份皇家口粮是他们亲手打造的。在那之前，纠结这些毫无意义。即便从人类学角度来看，这般揣测也毫无价值。这里还有远比这重要得多的种种事物，值得我们细细琢磨、深究其意义。一块味道绝佳的果冻，显然不在此列。我承认，虽说它给人的感觉像是专供高阶生灵享用的吃食，但事实并非如此，这也无妨。这里的万事万物，本就不必事事都合乎逻辑。

万布古：说得真好，露西尔，真希望我能像你一样把想法表达清楚。

德容：哈哈，你过奖了，卡茂。

万布古：好吧，我想为了做出通俗易懂的文档，我能合理分配的时间也就这么多了。露西尔，感谢你抽出时间。许久没有你的消息，这次能再次和你交谈十分愉快。

德容：实在是我荣幸之至。既然大家这么想我，我一定会多抽空过来看看各位！

[采访结束]
