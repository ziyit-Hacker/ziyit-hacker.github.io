背景：

大约一年前，即2024年11月11日下午6点08分，有人最后一次目击到M.E.G.的一名初级特工1，他当时正走进自己位于Level 4 Omega 基地的指定卧室。11小时后，因其未按时到岗，故而被宣布失踪。

采访前四小时，该特工意外从自己的卧室中走了出来（那间卧室现在已属于M.E.G.的另一名成员），其外貌与失踪前一模一样，只是脚上穿的并非M.E.G.制式鞋靴，而是一双鸭子拖鞋。不久后，该特工被送去接受采访。

描述：

Object 63 是一双软质面料制成的拖鞋。它们被设计成鸭子的造型，可穿在脚上。

目前，Object 63 仅存一双，被妥善存放于 Omega 基地 12 号储藏室。如需将 Object 63 移出 12 号储藏室，必须得到高级特工贾里德的批准。

属性：

Object 63 表现出发出嘎嘎声响的异常倾向。这类声响的出现本无规律，但若是将其关在阴暗处，或是长时间待在它们附近，就必定会触发该声响。

这些嘎嘎声频率异常偏高，已经困扰了部分 M.E.G. 人员，已有人提出申请，要求将 Object 63 转移至隔音效果更好的地方。

穿戴时，Object 63 和任何一双拖鞋表现一致，未观测到异常特性。

发现：

一名出于隐私原因隐去姓名的 M.E.G. 初级特工离开一年后返回 Omega 基地，Object 63 随之被发现。它被穿在那人脚上，与之一同出现。

据该特工所述，Object 63 得自一处名为鸭室的地点。他在遭遇两个形似鸭子的未知实体后进入了该处。这些实体与鸭室是否真实存在仍未得到证实。

面谈结束后，该特工一怒之下脱下拖鞋离开基地，将 Object 63 留在了 M.E.G. 手中。

确认空位就绪后，贾里德将 Object 63 上传至数据库，便准备过夜。又是荒诞的一天，又完成了一件要紧事。他钻进被窝渐渐入睡，心里想着。

几小时后，这场睡眠被粗暴地打断。

哔哔，哔哔，哔哔！

那是他的手机，正响着来电提示音。手机放在床头柜上，以防有紧急情况。而这样的紧急状况很快就会出现。

贾里德猛地惊醒。“嗯？什、什——”他顿了顿，打了个哈欠，“这会儿是谁打电话来？”

他拿起手机看了一眼，顾不上电子屏幕刺眼的亮度。来电者是他的好友威廉。贾里德按照特工规定针对此类紧急场景的要求，不情愿地点开了绿色的接听键。

随后他有气无力地向威廉说道：“你好……？”

“贾里德，出什么事了？！”威廉怒气冲冲地回应道。

“我……什么？”

“我被鸭子拖鞋粗暴地吵醒了！它们简直在我床头柜边嘎嘎叫个不停，我根本睡不着！是你把拖鞋放出来的吗？！”威廉怒气冲冲地质问道。什么？居然把它们放出来了？

贾里德攒起力气好好说话，回复道：“什么？！兄弟，那真不是我干的。我对天发誓！我去查看 12 号储藏室，稍等一下。”

贾里德压下想继续睡觉的念头，起身下床，轻手轻脚地走出房间，小心不吵醒其他特工。他点开手机快捷方式，打开内置手电筒来照明。他踮着脚穿过 Omega 基地，一路走到 12 号储藏室，可抵达此处后，他才发觉威廉说得没错。

通话还在继续，贾里德低声对威廉说：“它们不在那儿。”

“早就跟你说了。”

贾里德满心疑惑地问道：“它们还在你身边吗？我怎么没听到嘎嘎的叫声。”

“我试着穿上它们，叫声就停了，而只要我把脚抽出来，它们就又会嘎嘎作响。它们简直是逼我一直穿着，好让我不吵醒整个基地！因为我一走路，它们就又会叫！所以我只能僵在原地，可我还得睡美容觉呢！”

贾里德得想办法在不吵醒所有人的情况下把拖鞋拿回来，却又一时间毫无头绪。“呃……我……我不知道该怎么办……”

“快想想办法，我的腿好痛！”

这时他忽然心生一个想法，这念头着实有些荒唐。“我过去找你，抱你去没人的休息室，你可以在那儿睡。”

“WTF？！我又不是小孩子！”

“到底要不要睡？”

“要。”

“那我过去了。”

“行吧。但你敢告诉别人我得被人抱着去睡觉试试？”

话音落下，贾里德便朝威廉的房间走去。而这般古怪的情形，早已不是第一次发生了。







到底是哪个混蛋总打开 12 号储藏室，把鸭子拖鞋挪到别处找乐子？

未经我批准，严禁挪动拖鞋！它们会发出一连串巨大的声响，吵醒我们的部分特工。

屡次做出这种事的人，请立刻停止。这类情况已经发生五次了，我不希望再出现第六次。

这一点都不好笑，只会招人烦，还影响我们睡觉。








可即便有过提醒，第六次、第七次、第八次还是接连发生。事情并未就此停止。一夜又一夜，鸭子拖鞋总会出现在随机的卧室里，吵醒能吵醒的所有人。

无论贾里德贴了多少告示。无论他问了多少人。无论这种事发生了多少次。总有人在挪动它们。可到底是谁？

如今这类诡异事件已经发生了十三起，而在那个注定不平凡的日子里，贾里德像往常一样上床休息。他闭上眼睛，渐渐进入梦乡。可这份安眠并未持续多久，一阵熟悉的声响突然将他惊醒。

嘎嘎，嘎嘎，嘎嘎，嘎嘎，嘎嘎，嘎嘎，嘎嘎，嘎嘎，嘎嘎，嘎嘎，嘎嘎——

贾里德猛地惊醒，慌乱地四下张望，心脏因恐慌狂跳。就在他头旁的床头柜上，放着那双他再熟悉不过、也深为厌恶的拖鞋。

操！

嘎嘎声响个不停，听着刺耳至极。Omega 基地的墙体大多具备隔音效果，这股声响并未吵醒周边工作人员，但照这样持续下去，迟早会有人被惊醒。

贾里德虽然头脑昏沉，却努力回想过去其他人遇到这种情况时该如何应对。穿上它们。于是他照做了，立刻拿起拖鞋，光脚穿了进去……可这一次，并没有奏效。

嘎嘎，嘎嘎，嘎嘎，嘎嘎，嘎嘎，嘎嘎，嘎嘎，嘎嘎，嘎嘎，嘎嘎，嘎嘎——

它们就不能安静点吗？！

恐慌涌遍全身。这拖鞋每出一次事就变本加厉，这一切实在让人忍无可忍了。贾里德脱下拖鞋，准备做自己唯一能做的事来终结这阵疯狂。我受够这双拖鞋了！既然它们不肯安分，那我就逼它们安静下来！

贾里德飞快地拿起自己的M.E.G.身份卡，一把抓过那双不停发出嘎嘎声响的拖鞋。他拿起旁边一个上次任务剩下的塑料袋，把拖鞋塞进去，想以此压低声音。

他冲出卧室门，穿过 Omega 基地，刷身份卡打开出口，跑进了 Level 4 的办公区。

这些东西该放哪儿呢？他一边环顾四周，一边暗自思索。紧接着，他看到了救星。基地入口不远处放着一个空的办公垃圾桶，就等着装日常的办公垃圾。这垃圾桶个头不大，但也只能将就着用了。

贾里德以一种自己都觉得难以置信的速度冲到垃圾桶旁，趁着拖鞋还套在袋子里，一把将它们猛地丢了进去。希望那个心思龌龊、执意搞这种恶作剧的人，再也找不到这双拖鞋。

贾里德一秒也不想再听这些嘎嘎声，他迅速转身，跑回 Omega 基地入口，穿过一条条走廊，回到了自己舒适的卧室。

他猛地关上门，随即转过身背靠在门上，心中涌起一阵释然。藏匿拖鞋的后果他明天再操心，可睡眠太宝贵了。

贾里德花了足足一分钟平复心绪，随后摘下工牌，瘫倒在柔软的床上。没一会儿他就闭上了眼，思绪开始放松……很快眼前一片漆黑。终于，贾里德可以不受打扰地睡觉了——

“嘎嘎！”

“我知道。眼下就跟你说说我所见的些许情况。在一处别致的小池塘旁有个洞穴，方才提到的这个地方，通往一个你十分熟悉的广阔区域。根据我掌握的零星线索来看，我猜测吉米就躲在这里避开我，而这片土地也是所有鸭子都向往的栖身之所。”



“鸭室？他在鸭室里？”



“是的，我正在说明前往那里最近的入口。主人离开了 M.E.G. 回到那里，因为他迫切想要回去。”



“我们必须找到他。我们得重新被穿上。”



“可我们怎么去那儿？”



“呃……我不知道。”



“什么？！”



“我还以为你在用你的通灵能力呢。”



“我指的是 2 小时前有个人交给我的一些文件。”



“那你怎么知道我们的主人在哪里？”



“虽说我能凭借能力读懂你的心思，但对于肉眼看不到的人，我就无法探知他们的想法。我也是这样得知你主人的样貌的。至于他去了哪里，答案很简单，有文件记录有人看到过一个和他外貌描述相符的人。”



“我们必须立刻赶到鸭室！等等，你收到的邀请函出什么问题了？”



“它被一群无赖偷走，他们还为了取乐把它烧掉了。于是我决定略施惩戒，把他们全都变成橡皮鸭。那场面大快人心，可心里又不免有些难过。”



“哦，好吧。看来我们得绕远路过去了。”



“罗伯特，你能带我们带路吗？”



“当然。跟我来。”

鸭子们摇摇摆摆地出发了。去寻找它们走失的主人。
