描述

Object 82的一张图片

Object 82，常被称作圣晶，是一类在外观与物理性质上均与石英极其相似的晶体。此物品仅在蒙面教派1的前祭祀场所被发现过。相似于石英，圣晶虽然较脆，但其硬度相当高：圣晶的莫氏硬度为7级，高于碧玉，低于黄玉。同时，圣晶具有极高的耐热性，熔点为1670°C2，且导电性不佳。

圣晶与石英的一处主要区别在于圣晶的重量要低得多。石英的重量为265g/m²，而圣晶的重量则是140g/m²。此物体的另一独特性质便是其极高的耐腐蚀性，与铱较为类似。考虑到石英和圣晶的分子结构完全相同，这些差异似乎无法解释。

圣晶常被用于珠宝内，商贩会将其制成戒指或项链，随后当做幸运符售出。圣晶亦被宣传为能够疗愈疾病或复活死者，但这些说法完全未经证实。由于其与蒙面教派存在联系，圣晶亦有可能被附上魔咒：有关拥有此类晶体的人失踪的报告层出不穷，但此类事件发生的原因完全是推测。无论如何，建议对其保持谨慎态度。

由于圣晶的性质与石英较为相似，流浪者也会将圣晶用于与石英相似的用途，这包括制造玻璃、铸造金属、制造耐火砖及打磨工具。

在所有主要团体之中，后室机器人科技最常使用圣晶，他们主要将其应用于半导体芯片3的制造中。此外，亦有数个有关制造可抵御极端条件的无人机的未证实项目，这些项目打算利用晶体的耐腐蚀性和低质量来制造某些重要部件。

值得注意的是，失落一族也找到了他们自己的晶体用途：部分来自失落军团与失落骄阳的成员将此材料用于合成工具或切割部分宝石，而团体的其他成员则倾向于将其用于敬奉或装饰用途。无论如何，团体内的大多数成员都非常乐于接受携带他们的流浪者。这也适用于普通石英。据信，失落一族之所以对晶体如此敬畏，是因为晶体具有类似石英的特性，而不是因为晶体的异常性质，因为他们对晶体的构成一无所知。

人们普遍猜测圣晶是蒙面教派的造物，因为它们仅会出现在前教派祭祀场所。然而，此理论难以诠释教派费力生产这些晶体的动机。[为获取更多信息，请参阅创生部分]。

罗塞塔行动

未经永恒资料库的明确许可，不得分享或复制本文件

罗塞塔行动是由永恒资料库██████████领导的一个项目。项目致力于收集源自蒙面教派的全部文本，特别是来自第三大主教管区的文本。卷轴中的知识会赐予我们宝贵的信息，而这些信息将使教派在攻击面前不堪一击。

然而，尽管已然确认蒙面教派仅会使用英语和拉丁语，但仍有数条文本无以辨认。最初，这些文本被认为用另一种语言写就。然而经过进一步检查，我们发现文本已被附魔，以防止非教派人员阅读。

有鉴于此，罗塞塔行动的目标已然转变为接触一名教派囚徒。在与教派的战争中，愤怒渗透者4掌握了教派牧师用来强迫囚犯如实回答问题的特殊咒语。如果资料库能接触到一名教派囚徒，就可以准确地翻译难以辨认的文本，而不必担心信息有误。

尽管由于资料库并未插手与蒙面教派间的冲突，而因此未捕获任何教派囚徒，然而其他团体，例如M.E.G.与阿尔戈斯之眼，却抓获了囚徒。最初的计划是与阿尔戈斯之眼交换一名囚徒。然而，当他们听说资料库的审讯策略后，他们便立即企图杀死特使。幸运的是，由于Alistair Morgan后来促成并签署了一项和平条约，避免了冲突的发生，因此并无人员伤亡。

在与阿尔戈斯之眼的合作破裂后，我们又一次向M.E.G.发出了邀请。然而，与阿尔戈斯之眼相似，在听闻审讯策略之后，M.E.G.同样拒绝了邀请5。

幸运的是，两团体并非唯二拘捕教派囚徒的团体，阿丽亚娜集团6同样关押着一名教派囚徒。然而，在我们不作出让步的情况下，他们拒不接受这一提议。他们拒绝将囚犯的监护权交给资料库，相反，集团会允许资料库接触这名囚犯，作为交换，阿波罗小队和塔纳托斯小队将参加罗塞塔行动。

结论

在数月的测试后，对于圣晶，我们仅发现了一个其他特性：圣晶对于酸有很高的耐性。虽然对于此物品是否受到诅咒仍有众多猜忌，但仍没有确凿证据表明这些晶体受到了诅咒。无论如何，仍要警告诸位不要佩戴或接触它们，尤其是在野外佩戴，或是佩戴源自身份不明的街头小贩的圣晶。

描述

福友石英是圣晶的一个亚种。除能够与福友质发生反应外9，此物品与普通圣晶全然相同。鉴于石英无法与福友质安全地发生反应，因此此特质便颇为古怪。

该物品的显著特征与福友玉相似：当探测到实体时，福友玉会发光；而福友石英则会根据实体的危险或威胁程度，以不同的频率释放白光和少量热量10。已知频率将以倒序在下表中列出：

闪光频率 实体危险度 建议
每秒4闪 高危险度/极具敌意 不惜一切代价，远离此等威胁
每秒2闪 中高危险度/具敌意 高度建议远离此等威胁
每秒1闪 中危险度/敌意极低 尽可能远离此等威胁
2秒1闪 中低危险度/不安全 此等威胁不安全，但仍可接近

过热


过热福友石英的一张照片

若处在激活状态过久11，福友石英将会过热。过热晶体在颜色上呈血红色。若处在此等状态下一个小时，晶体将会爆炸，将数百破片抛入空中，其速度足以穿透人体。不仅如此，大量的神经毒素12“福友气体”亦将被释放，导致处在近处的所有人因吸入而中毒。因此，强烈建议不要将福友石英带到实体数目高的层级。



可靠性

福友石英与福友玉在勘探方面有着相似的优势。在遮盖物密布（譬如树木茂密或杂草丛生）的偏僻环境和地区，以及实体数目较少的地方，它们便是救星。然而在实体数目较高的地区，例如大都市与实体巢穴之中，晶体便极度不可靠。福友石英在长期勘探中的使用亦颇具风险。在光亮较少的层级中，晶体也是一种危险，因其发出的光芒可被轻易探测到，尤其容易被高度感光实体（诸如死亡飞蛾与笑魇）探测到。
