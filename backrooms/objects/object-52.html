Object 52；博物馆展品 Æ7

描述

Object 52 是一个由未知金属化合物构成的截角八面体1 。该遗物包含十四个面：六个面积为1平方米的正方形面和八个面积为 3√3/2 平方米的正六边形面。Object 52 的每个表面都蚀刻有分形图案2 ，排列方式让人联想到现代微芯片的蚀刻。尽管其表观密度很高，但 Object 52 似乎不受重力影响，因此没有记录到重量。除非受到外力作用，否则该遗物保持悬浮在距地面约三米的固定空间位置。在对 Object 52 的广泛研究中，未记录到任何声学、电磁、术法或热学偏差。

目前尚不清楚 Object 52 是否已停止运作3，或者需要某种未知的操作方式。尽管其目前处于惰性状态，但历史背景和考古发现已经描绘了该遗物的实际应用。


发现

发现 Object 52 的遗址；Level 46，Bāl 发掘现场。

Object 52 于 1974 年由 I.M.B.H. 考古队在发掘 Level 46 内的一处遗址时发现。我们的研究始于已知的失落一族原始派系与先前未知的 Bāl4 要塞之间约 3000 年前的一次通信。发掘过程中，发现了一个埋藏的房间，内藏 Object 52 和十块石板。由于侵蚀，其中两块石板已无法辨认。

实证研究

自发现以来的数年中，对 Object 52 的部分研究集中于确定其物理特性和可能的应用。为此，进行了几项实验，使用了各种方法，并咨询了多个基于其各自资质的团体。

顾问方 目标 结论
失落一族；领导者；探险者总署。9 检查物品作为武器的潜在用途。 物品过轻且不保持动量，这表明其可能存在技术/非物质性的用途。
后室机器人科技 检查物品的技术方面。 研究无定论。我们能够确定，在物品表面的蚀刻中使用了高度先进的极紫外光刻10技术。蚀刻内部可检测到小至 5 纳米及以下的结构，远超当前能力。
阿里亚娜集团11 使一个 Entity 6 样本暴露于物品，以确定它们之间可能的联系。 实体在暴露于物品时立即改变了行为。进入房间后，它锁定视线于物品，且不会移开。它直立待命，仿佛在等待物品的某种反应。当物品被移除后，实体恢复了先前的姿态和典型行为模式。

历史背景

由于在其有记载的历史中，许多文明将该层级称为家园，Level 46 已成为一座古老大知的宝库。这些文明中的大多数已随时间流逝而消失，或被影响该层级的第一次或第二次大灾变从历史中抹去。尽管关于这些早期社会的信息很少，但一些原始和二手资料确实证实了某些地点、民族和事件。

描绘 Y'an'Kụ 的雕塑；博物馆展品 Æ7.1

来自多个来源的记录证实了 Y'an'Kụ 的存在，这是一个规模难以估量的城市，通常被描绘为能够通过某种形式的悬浮移动。这是该层级许多居民恐惧的地方，因为它预示着入侵军队的到来。一些被发现的通信详细描述了由一群特征类似于钝人12的实体组成的军队即将入侵。据信，这支军队很可能就是 Sol'Ņok Akụn 石板中描绘的“无面大军”。据称，Y'an'Kụ 在巴勒被夷为平地后不久，即从 Level 46 切出，前往未知地点。

毁掉城邦 N'Lẹr 后，Sol'Ņok Akụn 的艺术描绘。

关于 Sol'Ņok Akụn 的早期生活知之甚少，要么是因为记录随时间流逝而丢失，要么是在此期间没有值得记载的事件发生。他的名字最早出现在新 Bāl 的历史记录中，涉及 Maloch 和 Tyr 部落13的消失。

() 一支巡逻队发现 Okkon14 的人民消失了；七名幸存者声称是一个男人所为。一位名叫 Sol'Ņok Akụn 的祭司使用了“亵渎神明的力量”来毁容和控制当地人口。() 他们的描述符合困扰附近定居点的恶魔生物的报告。()

Bāl 军队通信；公元前 1505 年

其中一名幸存者提供了关于 Sol'Ņok Akụn 在袭击 Okkon 时使用 Object 52 的唯一目击叙述。尽管转录件随时间严重受损，但他们故事的一些片段得以保留：

在他用外语吟唱时，那个球体有了反应。() 那光芒以一种我无法解释的方式显得不对劲。他们都变得如此之快：朋友，家人，所有我曾认识的人 () 他们不再是人类了；那光芒没有放过任何人。他们毫不犹豫地遵循他的命令。() 那些灰色生物撕碎了卫兵；无人能挡。你们不应该跟随他；我们应该逃往阈限，离开这个世界。无论他祈祷的是哪位神，显然都青睐他的征服。()

在已发现的关于这些历史事件的信息中，没有找到任何提及名为 Zọŉ 的神祇，或与该词相关的宗教实践。理论上，如果对以此名命名的神祇的信仰确实存在，它要么早于我们的记录，要么已被误译 ，要么仅由 Sol'Ņok Akụn 一人崇拜。

在失落军团文物中发现的描绘新 Bāl 的画作。

目前可获得的关于 Object 52 、Sol'Ņok Akụn 以及 Level 46 这段历史时期的信息，若非 I.M.B.H. 直接发掘，则几乎全部来自失落一族在与失落 Kengir15战争期间（公元前 976 年）缴获的记录残片。在新 Bāl16围城期间，他们的许多历史文献要么被毁，要么严重受损，要么被入侵军队遗弃。寻找新 Bāl 的努力，以及在 Level 46 本身寻找进一步证据的努力，已在我们组织中持续了数十年，并将继续成为关于 Object 52 及其起源的研究重点。
