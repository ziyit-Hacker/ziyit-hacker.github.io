翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;

}

描述

一台模拟设备的特写图像

Level 15.1，常被光顾的流浪者称为“枉然”，是Level 15中的一个拥有尖端科技的区域。该区域拥有超现实仿真室和头戴式仿真设备，能够呈现流浪者所渴望的任何环境或场景。这些仿真的复杂性和独特性似乎不受限制，许多人甚至声称它比现实更加“真实”。

该区域的科技水平极为先进，以至于无法通过逆向工程来再现产品的设计技术。包括后室机器人科技和B.N.T.G.在内的多个团体，都企图通过将该技术贩运出该子层级来将其商业化，但每当有闯入者尝试带着这些设备切出该层级时，设备便会爆炸，并夺去任何企图走私之人的生命。

控制室的右侧区域

一个房间位于该子层级的中央，据可靠信息，该房间是整个层级的电力供应中枢，被命名为“控制中心”。进入这个房间的唯一通道是一扇密封的门，门上仅设有一个小观察孔，透过它可以看到多个模糊的身影正站在一个被认为极其复杂且庞大的设备前，该设备连接着多个监视器。以手持仪器检验表明：正在使用这些设备的人，其大脑图谱和模拟信息均被传输到这个房间。目前尚不清楚这些信息被用于何种目的或由谁使用。测试显示，任何模拟设备都无法准确描绘控制中心内部的景象，反而会立即使所使用的设备永久性崩溃。

生理效应

黄线和绿线对应于进入Level 15.1的流浪者睾酮素分泌水平和杏仁核1活跃程度。

该子层级的环境已被证实存在多种精神危害。心理测试表明，每个进入层级的流浪者都有更高的攻击性和精神病倾向。由于模拟设备数量较少，因此一直存在争夺和暴力，甚至为争夺下一个模拟设备的使用权而致人死亡。据可靠消息，那些散落在Level 15的尸体是一个身份不明的团体对流浪者诉诸暴力的结果。该团体率先发现这一子层级，并以暴力手段保护该子层级及其内部设施的秘密。

最令人担忧的事情是，那些对等待失去耐心的人，强行将头戴式仿真设备从使用者的头上摘下。这一行为导致了使用者即时的脑死亡。而使用者能够安全离开模拟的唯一方式是出于自己的意愿摘下头戴式仿真设备。但由于模拟场景与使用者当前所处的现实相比极具优越性，使得它们沉溺其中，主动离开模拟的情况极其罕见。这种凄凉的现实就是该子层被冠以“枉然”之名的原因。使用这些设备的人无法面对他们所处的无意义的现实状况——他们永远被困在后室中，并诉诸于模拟设备那虚假的舒适和幸福中度过他们的余生。最终，将全部时间沉溺在这一子层级与模拟装置的人，其结局都会死于营养不良、脱水或器官衰竭。

发现记录

2023年12月18日，Level 15.1的存在首次引起了M.E.G.的注意，这一发现源于流浪者Enric的报告，他已经受困于Level 15多年。几乎在发现这一子层级的同时，立即出现了多个自Level 10通往Level 15的入口报告，这些报告足以促使多个流浪者团体进入这个先前无人居住的层级，以探索这个未知的子层级。直到年底，该子层级的重要区域已经被绘制出来。

起初，由于能无障碍的进入这一子层级，许多不同团体为了利益而试图控制整个子层级。但M.E.G.最终成功稳定局面，并派遣守卫保护入口。M.E.G.的守卫严格的执行周期为两个月的轮换制度，以对抗该子层级的各种生理效应。

“您的私人地狱”

4月1日，在“控制中心”的舷窗内。

2024年4月1日，整个层级发生了前所未有的功率激增事件，这对子层级的功能造成了严重影响。当时正在参与模拟的每个人都被猛烈地驱逐出模拟环境，并被关进一间模拟黑室。在那里，他们经历了长达40小时的令人毛骨悚然的噩梦和内心深处的恐惧。大约35%的使用者在此事件后立即死亡。这一事件发生的异常时间，导致一些人怀疑是那些存在于控制中心的人蓄意引发了该起事件，目的是发出警告或引发清洗事件，从而降低流浪者对其设施的需求和能源消耗。对层级中功率激增的测量和对设备压力的分析表明，在未来几个月内很可能发生类似的事件。M.E.G.目前已经采取了措施来预防此类灾难再次发生；然而，尽管用尽一切手段，模拟设备的受欢迎程度和流浪者的热情仍然保持在创纪录的高水平。

基地、前哨与社区

掠夺者

由于这一子层级的潜在伦理问题，多个与M.E.G.敌对的相关团体联合起来，形成了一个大约由17名成员组成的联盟，他们在子层级中四处游荡，极力制造混乱和破坏。他们以该子层级违反人理的运作模式作为其制造混乱的借口，而他们频繁的袭击已经严重阻碍了该子层级的正常功能和日常运作。
