翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

该组件支持简繁切换，如下方代码所示：

|lang=cn/tr
|class=等级
]]


在lang 处选择语言，cn 表示简体中文，tr 表示繁体中文，不填默认选择简体中文。

自定义等级

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

旧版颜色：

如果你不喜欢新版的样式，想要用回旧版的红色边框色，只需要在你的页面中与组件一同引入下方的代码：

[[modulecss]]
.sd-container {
--sd-border:90,29,27;
--sd-image:90,29,27;
--sd-symbol:90,29,27;
}
[[/module]]

描述

构造

此层级由一座高度和宽度无限，而厚度有限的大型建筑组成。这一建筑的构造分布在两侧，长长的彼此叠加成层的人行道覆盖于其上。不同高度的楼层之间偶尔会通过楼梯间，这一上下楼的最安全的方式互相连接着。结构内部有着无穷多的酒店套房，皆可以通过位于人行道上的门进入。

虽然此层级有一实心墙隔开了两侧构造，但两侧之间仍能互相看到。只需要向栏杆外眺望便能成功做到这一点；层级沿垂直于建筑构造的轴线不断循环。构造两侧之间的间隙大约有50米宽，使穿越其变得不可行。

此层级内部具备不同的区域。这些区域的主要差异为走道的外观互相之间有所不同，但也有可能表现为房间内部的差异。这些区域的大小有显著差异——最大的区域可以包含数百扇门，而最小的区域可能只有寥寥数扇。结构两侧的区域布局互相统一。这种区域的差别与明显分界使得各个团体能利用这一特征非常方便地标记其控制区的边界。

在墙附近偶尔能找到金属杆。这些金属杆总是无限向下延伸，但向上的方向则只是有一定可能无限延伸。尽管许多层级内原生群体使用此类金属杆快速下楼，但 M.E.G. 不鼓励其他人进行如此尝试；即使是一个小小的失误也可能致死。

客房

建筑构造内的酒店客房的形状和大小各不相同。其内部通常被一般意义上酒店客房会出现的家具，例如冰箱、床和桌子所充斥。冰箱被打开之前其中的食物不会变质。在极少数情况下，将空冰箱关上可能导致其中出现额外的食物。此为层级内居民的重要营养来源。

这些客房也额外提供庇护和住宿服务。该层级的定居点通常由一系列有人居住的房间组成，家具放置在房间门外的人行道上。有时，甚至层级环境本身也会通过诸如建造一条穿过墙壁的额外通道等方式被改变。旅行者在长途旅行中也经常使用客房作为休息场所。

客房的最后一种功能是用作通道。由于某些房间在建筑构造的两侧都有对应的门，因此可以简单地穿过它们以到达构造的另一侧。这样的房间通常是每小时有数十人经过的活动热点区域。该层级中的大多数团体都试图获得对此类房间的控制权，因为这通常让他们得以控制贸易路线的一部分。

实体

酒店套房偶尔会被死亡飞蛾，这种常见于Level 5中的实体所侵扰。在Level 5.2中发现的死亡飞蛾体型相对较小，但具备同等级的攻击性。许多以前被死亡飞蛾侵扰的房间内的死亡飞蛾已经被层级内原生群体所去除。然而死亡飞蛾偶尔也能够于新的房间中出现。目前还不确定该子层级中死亡飞蛾的未来会是如何。

无面灵于套房内外都是常见的。它们通常表现的很温顺，并且无视周围人类的存在。据观察这些无面灵会睡在床上，或是沿着人行道徘徊，乃至于爬上贴在外墙上的杆子。一部分人推测，攀登杆子的这一操作和技巧起源于这些无面灵，后来被人类采用。由于这些无面灵没有表现出敌意，他们与人类自由地共存着，甚至在极少数情况下与人类一起生活。

死亡飞蛾和无面灵是在该层级中发现的两种主要实体。其余的实体仅有从Level 5无意跌入此层级的实体。这些外来实体无法在此层级中长期生存，因为它们会被死亡飞蛾或人类居民杀害，抑或是因缺乏生存所需的资源而死。曾有多起被以都市传说和民间传说的形式记录的，细节往往被扭曲与夸大的与不寻常的实体相遇的案例。

虽然死亡飞蛾对人类和外来实体怀有敌意，但它们通常会将无面灵完全无视。其原因尚不清楚。一种热门的解释认为由于无面灵不会对死亡飞蛾的种群构成任何形式的威胁，这使得死亡飞蛾对无面灵的攻击成为了对其时间和资源的纯粹浪费。无面灵倘若刨去似乎处于本能地避开了死亡飞蛾出没的套房这一点以外，无面灵也是将死亡飞蛾完全无视的。

社区与定居点

Level 5.2是众多社区和定居点的所在地。然而，这些社区与定居点除了少数几个以外对其记录基本是一片空白。下文描述的两个社区是这些社区和定居点中最为人所知的。

阶梯镇

该社区位于一个长阶梯的周围，该阶梯是这一地区各个楼层之间唯一的通道。一个多世纪以来，此楼梯一直是一条受欢迎的贸易路线，但该定居点只有五十年的历史。其人口在150人左右波动，大多数居民住在靠近阶梯的酒店房间里。此外，此定居点的居民还包括三个无面灵。社区认为它们是承载着好运，并因其不死的而崇敬它们。

杆落团

杆落团为一约有20名定居者的较小的社区。该社区于一组用于楼层速降的杆子旁形成。长期以来，这些杆子一直是该地区旅行者广泛使用的捷径。杆落团曾多次与M.E.G.合作，并一直是该层级的重要信源。

入口与出口

入口

Level 5.2仅能从Level 5进入。标有包含“外部”或“胜景”等文字的标志被标注在通往此层级的走廊上。每条这样的走廊的尽头都是一扇作为Level 5.2的入口的门。

一旦某个体穿越门，它就会自动关闭并上锁。通过障碍物卡住门是不可行的；门会逐渐对物体施加愈来愈大的力，直到它得以破开物体，直接关上门。

出口

离开这一层级的唯一方法是从另一方向通过层级的入口。由于门会自动上锁，这起初被看作是不可能的。然而，每当有人从门内侧打开入口时，就可以短暂地通过此门进入Level 5。要使这种方法起作用，必须靠近门并足够快地注意到其被打开。有许多小型团体的成员在入口旁边扎营并轮岗进行观察。
