翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

--sd-border:var(--gray-monochrome);/*大多数等级*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

描述：

2020年8月25日 有关Level 410.1的第一张已知照片。拍摄者不明。

Level 410.1被认为是Level 410的公寓地下室，它以独特的现象与微妙的环境为人所知。走下被黑色墙面包围的木质楼梯，再穿过一条狭窄的走廊，流浪者便能来到该层级。这些楼梯可以看作Level 410.1最安全的部分，它们不会受到任何反常现象的影响。一旦流浪者走下楼梯，楼梯顶部的门便会关上锁死，无论是用钥匙还是其他办法都没法重新打开。

楼梯之外的层级由面积巨大的走廊迷宫构成，走廊铺着米黄色的墙壁与磨亮的混凝土地板。走廊上则有着模仿Level 410的电器与家具，它们看起来像是卡进了墙壁之中。触碰这些物品会使其移位到地板里剧烈抽搐。触碰它们也会导致流浪者变形，要等几秒才会回归原样。有趣的是，该过程会将所有由细菌引起的疾病驱除到流浪者体外，因而过去的人们也会用这种办法来消除Entity 19。不过并不推荐利用这种办法来治疗细菌感染，因为这有可能引起皮肤刺激或者造成肌肉损伤。

现象

虽然楼梯部分相对安全，但整个Level 410.1实则埋伏着许多隐患，这使其成了用来验证某些现象是否能在不同层级发生的主要案例之一。在层级中观测到的一些现象如下：

  • 随着身在子层级的时间越来越久，流浪者会逐渐听到类似黑胶唱片的噼啪声。噪音会随时间推移不断变响，引发流浪者的焦虑。除此之外，噼啪声中似乎还混有像是在弹奏钢琴的节拍，模拟着流浪者脑中记忆模糊的曲目。
  • 进一步深入Level 410.1，会开始发现一种装着蓝色物质1 的烧瓶，每个烧瓶都标着先前进入过该层级的流浪者其个人信息。一旦流浪者接触其中一个瓶子，上面的信息就会变得模糊，标着信息的那位流浪者也会丧失自己的身份，不论那名流浪者曾在什么时候当过哪个组织的一员，只要有人触碰过瓶子，其存在便会从数据库消失。这些烧瓶还具有一种精神危害，它们会引发流浪者危险的好奇心，促使他们下意识地想去喝下其中的物质。如果流浪者喝下了瓶内物质，他们本人的身份与信息便会替换成原来标注的那位流浪者，从而在事实上担起先前之人的角色，获得前人的身份。该现象被认为是Level 410.1最为危险的一面，应当不惜一切代价加以回避。
  • Level 410.1的大部分现象都可以看作是离开层级的潜在办法，除了沿着自己的路返回这一种办法外。当然其中有些办法仅仅还处在理论阶段。2

当地团体：

该层级不存在基地，前哨或社区等为人所知的团体。但在距离楼梯几公里外的地方，似乎有一座子虚乌有的哨站，其绰号为“敏感室”。乍一看人们会认为它是一个没点燃的壁炉，但在壁炉内实则藏着一顶帐篷，那顶帐篷通往一个与层级其他地方截然不同的区域。该区域的地板与墙和Level 410厨房中的类似，只是颜色更加黯沉。区域中存在许多人体模型，看起来就像是来自不同组织的成员在哨站里休息一样。由于该区域具有某种影响精神的效应，破坏这些人体模型会使人感到强烈的悲伤与罪恶感，就好像是真的杀了一个人。

在敏感室最深处的一面绿墙上，挂着一台尺寸巨大的平板电视。上面播着模仿葬礼的纪念幻灯片。它如其他纪念幻灯片一般放着令人动情的歌曲，但本应表现回忆录的图片却摆着后室各个组织的极密文件。幻灯片的结尾显示有一串二进制文本，翻译过来是“RIP 切勿外传，1017-2060。”信息的第一段可以解读成一则警告，提醒人们切勿泄露任何写在幻灯片上的信息，因为假如这些信息流到了某些黑恶势力手里，很有可能会有动荡产生。“1017-2060”的意思我们仍不得而知，与其有关的猜想各不相同，有人认为它代表后室的一个时间段，如全新纪之类，而有人则认为它表明后室将在2060迎来毁灭。

敏感室的这一区域在得到更进一步的通知前，将一直由M.E.G.提供的安保摄像头进行管控，将敏感信息泄露给他人的流浪者会受到相应处罚。

入口

Level 410

进入Level 410.1的一种办法是在Level 410的厨房储物区内走进一扇向下的废旧门。遗憾的是，进入Level 410的人本就稀少，通过这种办法进入该层级的人也毋庸置疑最为罕见。

http://backrooms-wiki-cn.wikidot.com/level-6-1

Level 6.1

另一种进入Level 410.1的方法也是最常见的，那就是走进Level 6.1的酒吧中一扇通往休息室的门。

http://backrooms-wiki-cn.wikidot.com/level-70

Level 70

甚至可以通过Level 70中一扇写着“员工专用”的门来到这一层级。

出口：

在离开Level 410.1的几种方式中，除了利用层级本身的现象外，还可以从来时的门回去。不过这种方法只有在流浪者尚未离开楼梯时才可能起效。利用现象离开该层级的办法包括：

http://backrooms-wiki-cn.wikidot.com/level-18

Level 18

在墙上写下自己的年龄会被传送到Level 18。

http://backrooms-wiki-cn.wikidot.com/level-408

Level 408

在墙上写下自己的名字会被传送到问讯间。

http://backrooms-wiki-cn.wikidot.com/level-448

Level 448

有猜测认为，如果破坏或者踢中信息瓶，便会自动切入Level 448并同时失去记忆。该猜测尚未得到确认，但无论如何都不应如此尝试。

http://backrooms-wiki-cn.wikidot.com/level-101

Level 101

有传言称，如果在敏感室的人体模型上写下老家的邮政编码，便会被传送到Level 101。不过这一条同样没有得到证实。
