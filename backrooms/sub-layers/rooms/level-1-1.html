使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

Level 1.1中区域1的一小段走廊的一张照片，镜头朝向入口。

Level 1.1是Level 1的一个子层级。它像一条长长的、笔直的走廊，它所延伸的长度尚未确定。

描述

Level 1.1是Level 1中的一条笔直而狭窄的走廊，它所延伸的长度尚未确定。它的墙壁由涂成白色的炉渣砖所构成，地面铺设着蓝色瓷砖。该层级的大部分地方都是这种蓝色和白色的配色。偶尔，在墙壁和天花板的裂缝与洞口之中，会探出一些裸露的管道和通风管。与Level 1相似，Level 1.1资源丰富，层级各处散落着许多装满物资的板条箱。然而，探险者越是深入该层级，这些箱子出现的频率就越低，这使得长距离探索变得十分困难。探险者们在一起进入Level 1.1时并不会被分开，这使得他们可以组队行动。这促使许多探险者在该层级内展开探险行动。曾有许多人试图到达Level 1.1的终点，但都以失败告终。其原因并不是道路受阻或是路途遥远，而是整体的安全度与实体的数量存在着极其危险的波动。

沿着走廊越往深处走，层级就会变得越不稳定。该走廊被分为四个不同的区域（以及一个未经证实的区域）。它们的状态会从非常稳定逐渐变成非常不稳定。靠后的部分极其危险，无论如何都应该避免去到那里。

区域2的一个平坦区域。照片在M.E.G.对该层级的探索行动期间拍摄。

区域2是Level 1.1的第二个区域。虽然它比区域1更危险且更不稳定，但经验丰富的探险者仍然能够在这里通行无阻。该区域的许多环境特征都出现了故障，在这一区域的某些地方可以通过墙壁切出至Level 1的随机区域。区域2的地面经常以奇怪的角度倾斜，形成陡峭的上坡和下坡。走廊的颜色可能会变成异常的色调，走廊的某些部分会不断地重复，管道和通风管也可能会堵住部分走廊。据估计，该区域的长度在5到50英里之间，但由于其环境令人迷惑的性质，很难对其进行精确测量。如果对该区域长度的估计可靠，那么它将会是Level 1.1中最长的区域。

这个区域里敌对的实体很少，但偶尔也会出现笑魇、猎犬和窃皮者。探险者可以很容易地在这个区域的一些前哨站中寻求庇护。建议探险者们从此处开始结伴而行。在靠后的区域里单打独斗很容易会被危险的实体攻击。

人们在区域2的一些墙壁、地板和天花板上发现了一些标记。这些标记似乎是用一种未知的语言写的，且至今仍未被翻译出来。

组织

两个组织正在为得到Level 1.1的控制权而进行着交战，它们分别为通道帮和M.E.G.的走廊小队。

M.E.G.走廊小队

走廊小队受探险者总署（M.E.G）委托，目的是探索和记录Level 1.1的相关信息。其中包括对未知区域进行有组织的探索，以及对层级中的实体进行分类记录等等。该小队由大约十几名常驻成员，以及一些在该层级进行探索的临时M.E.G.研究员和探险者组成。同时，走廊小队还运营着该层级中的许多前哨站，并为它们提供补给。

通道帮

通道帮是一个由自发武装的探险者组成的团体，他们宣称对Level 1.1拥有主权。他们由一个叫做“刀锋”的人领导，然而，在进一步的调查后，这个人被确定为名叫Miles Mason的前M.E.G Gamma基地成员。他们具有相当高的敌意，为了得到该层级的控制权与M.E.G一直处于交火状态。通道帮相信，那个构想中的区域5或许就是离开后室的出口，并已为此进行了多次尝试。他们在区域2的末端占据了一个非正式的前哨站（详见“Jakob的小屋”），现在将其作为他们的总部。尽管充满敌意，但他们很少构成真正的危险。他们的武器极其原始，是用Level 1到处散落的补给箱废料制成的。因此许多探险者可以击退他们，从而获得进入区域 3 的通道。

M.E.G决定不理会通道帮，甚至曾尝试与他们进行和平谈判，但全都遭到了拒绝。一位M.E.G代表认为，通道帮实质上为进一步探索走廊的探索者提供了材料，这样M.E.G.就不必消耗更多物资去重新补给了。

一名独行的探险者在Level 1找到了一本写有简短手写探险日志的笔记本，据推测，它由通道帮的一名成员所写。其内容已转录如下。

手写日志 - 通道帮

回收文档 - 未知作者

第四次探险，第一天 - 2021年2月7日

今天，我们要踏上前往区域5的第四次旅程。我们带了大量的食物和水，所以我们希望能走得比上次更远。刀锋说，我们这次做的准备比以往任何时候都要充分。我们交易来了一些背包以带上更多的东西。希望它们能派上用场。

刀锋在叫我了。我觉得是时候该出发了。但愿这是我最后一次看到这鸟地方了。

第四次探险，第二天 - 2021年2月8日

好吧，因为区域3实在是太黑了，我没有办法去更新日志，但我们最终到达了一个明亮的地方。昨晚我们睡在了走廊里，进展一切顺利。刀锋说我们应该会在几个小时内到达4号前哨站，我们到现在还没有遇到过任何实体，这代表着我们这次比上次要幸运得多。

更新：到达了前哨站4，在前进的时候，Cam撞到了一个箱子，伤到了膝盖。还不清楚他的伤势如何，但他说他还可以继续努力，而且除了有些一瘸一拐以外，他走路也没有什么大碍。今晚我们会睡在前哨站4的箱子旁边，明天争取多赶点路。

第四次探索的第三天 - 2021年2月9日

由于Emma平时起的都很早，她计划在今天一早就把我们叫醒，但一个笑魇决定代替她做这件事。它偷偷溜过来，趁我们睡觉时发动了攻击。刀锋设法击退了它，但Cam就没那么幸运了。他后退的时候没看路，直接切出了墙壁。刀锋说我们不回头了，等我们完事后再去和他会合。我们今天会尽量多赶点路，但刀锋说我们还要几天才能到达区域4。这片黑暗开始让人吃不消了，而那些随机出现的刺眼的光亮也无济于事。我都差点忘记我有多讨厌这个区域了。

第四次探险，第四天 - 2021年2月10日

刀锋说我们越来越接近区域4了。我们已经越过了第二次探险时折返的地方。不过Jake的尸体已经不在那里了。我们也不知道它去哪了。补给越来越少了，我希望能尽快走出去。

第四次探险，第五天 - 2021年2月11日

今天我们来到了区域4的入口。我从未想过我能到达这么远的地方，但我确实做到了。这里的走廊就像是奇怪的游乐园一样旋转和扭曲。刀锋说在开始行动之前，我们需要花几天的时间来进行侦查工作。我有些紧张，因为此时我们的补给已经开始见底了。希望区域4不会很长，因为我们需要尽快地离开这里。

第四次探险，第六天 - 2021年2月12日

我们开始意识到，我们严重低估了我们所需的食物数量。如果我们不立刻开始探索，就有可能不得不折返回去了。刀锋说我们要开始行动了。

我可以看到一些实体在入口不远的地方出现。它们是凭空出现的。其中一些实体的外形看起来十分奇怪。但不知为何，它们似乎没有靠近我们。

刀锋说机不可失，时不再来。我们正在整理装备准备进去。我真的很紧张。我们很有可能都会死在这里，但反正我在后室里迟早也得死。还不如碰碰运气。

记录结束。作者的命运目前未知，然而在最后一篇日志的两周后，有人在Jakob的小屋看到了刀锋和其他两名探险者。当问起这件事时，刀锋和通道帮的其他成员都拒绝讲述他们这次探险的遭遇。

基地、前哨站与社区

前哨站和其他安全地点的简要地图。

Level 1.1中存在有数个前哨站和安全地点。这些前哨站为探险者们储备了各种补给以及资源。层级中较为靠前的前哨站可能会有人员常驻，但靠后的前哨站通常无人居住，只有在每隔几周或几个月重新补充物资时才会有人造访。其中五个前哨站由M.E.G建立，但也有一些是独立的。前哨站通常位于隧道出现某种结构变异的区域。这包括墙体上的小型内凹处，此时走廊可能会拓宽至 20 英尺或更宽，或者是可以通过短侧廊进入的大房间。目前尚不清楚，为何这些异常结构出现在原本规格统一的走廊中。

-隐藏前哨站1

前哨站1

前哨站1，第一次发现时所摄。

前哨站1是位于区域1的一个常驻人员前哨站。在所有的前哨站中，它是最安全且最稳定的那个。里面有M.E.G成员常驻，并经常补充物资。在区域1的入口处，走廊会变成一个小房间。这个房间里有一个物资储存区、一组供旅行者使用的四张三层高的床、存放食物的冰箱，以及其他其他基本生活用品。这个前哨站像是一个未完工的地下室。与这个层级其他的地方一样，这个地方的墙面由炉渣砖构成，但没有被涂上颜色。墙上和天花板上会有着一些暴露的管道和通风管，还有荧光灯提供照明。地板一开始是由泥土做成的，后来换成了木地板。

前哨站2

前哨站2位于区域1和区域2的连接处，由M.E.G派人驻守。它是最大的一个前哨站，由数个房间组成的网络构成：

前哨站2结构的地图。

  • 有16个床位的宿舍
  • 厨房与用餐区
  • 储藏室
  • 交易大厅
  • 公共区域

探险者在这个前哨站度过的时间比在其他任何前哨站都要长，以此为前方的危险做准备。在这个前哨站的入口，走廊会拓宽至12英尺宽。在这个拓宽的区域里是交易大厅，可供探索者们展示物品并进行交易。交易大厅的两侧各有一扇门，每一扇门都通向一个由房间构成的网络。前哨站2是最后一个足够稳定的前哨站。这里的地板、墙壁以及天花板都被白色的瓷砖所覆盖。整个前哨站都被荧光灯所照亮，每天亮起16小时，在剩余的8小时内关闭。该前哨站主要由M.E.G.补充物资，但通常一些独立探险者也愿意在交易大厅内交换物资。

前哨站3

前哨站3只不过是位于区域2的走廊上的一些小型货架，货架上会摆放着各种补给。底层架子下方还有一张小折叠床，可以拉出来睡在走廊里。因为区域2故障频发的情况以及其不稳定的性质，因此众所周知，补给有时会从货架上消失。这导致一些任务被迫提前结束，因为想要在前哨站3补充物资的探索者会发现货架上空空如也，所以他们只好折返回前哨站2。由于没有其他的选择，探索者只能冒着会被敌对实体攻击的风险在走廊里睡觉。前哨站3由M.E.G每月补充一次物资。

+查看Jakob的小屋
-隐藏Jakob的小屋

Jakob的小屋

Jakob的小屋位于区域2的末端，它是一个非正式的前哨站。它是用多余的衣服和床上用品，挑在树枝上搭建而成的，它在墙壁的一个大凹陷处，构成了一个原始的小屋。它是在一次由Jakob Bokaj所领导的前往Level 1.1尽头的一次探险中建立的。该小队用它来储存多余的物资，以便他们能够重新补给，而无需跋涉返回前哨站2或3。在那次任务的灾难性失败之后，通道帮声称这个小屋为他们所有，并长期居住在这里。只要不表现出任何与M.E.G.有关的迹象，通道帮就会主动在小屋与探险者进行交易。

-隐藏前哨站4

前哨站4

前哨站4极度地不稳定，只适合短暂修整。它由一个长宽高都为4英尺的木制储物箱构成，推测是从Level 1的某个地方拿来的。里面有着各种食物、饮料、衣服以及其他的必需品。它位于走廊的中央，因此探索者可以很容易地在区域3的黑暗中找到它。鉴于前往区域3极其困难，此处很难得到物资补充。有些敌对的实体已经意识到探索者经常会来到这个箱子附近，因此它们会潜伏在箱子的周围，等待着放松警惕的探索者向它们走来。

前哨站5（已废弃）

人们曾经多次在区域3的末端尝试建立第五个前哨站，然而在遭遇数次来自实体的攻击之后，M.E.G认为第五个前哨站过于耗费资源且困难重重。

入口与出口

从Level 1的M.E.G. Alpha基地的正南方可以轻易地进入Level 1.1。在入口的外面贴有一个标志，标示着它所在的位置。除了Level 1之外，似乎没有其他的层级能够进入Level 1.1。

想要逃离Level 1.1，只需沿走廊原路返回，由入口处离开即可。切出也能够让探险者来到Level 1的一个随机地点，然而通过这种方法所到达的地点不可预测的，因此这种方法只能在紧急情况下作为逃生的方法使用。请注意，从区域4中切出不会使探险者来到Level 1。目前没有任何记录表明，通过切出能够到达除了Level 1以外的层级。
