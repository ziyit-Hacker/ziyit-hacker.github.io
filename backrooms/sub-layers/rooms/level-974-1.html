翻译者须知：

从 2026 年 5 月 20 日起，后室英文维基开始使用层级等级（后室英文维基），全面替代此组件。最终的结果是，此组件从 component:level-class 变成了 component:old-level-class；而 component:level-class 则被替换成了上述的新组件。

这导致后室英文维基所有使用了生存难度分级组件的页面，都自动更新成另一版本。中文维基不会跟进这一改动，亦不会重命名此组件。译者可以自由选择在翻译过程中应用新版组件，使之与原文相同；也可以继续使用此组件，即不改动 [[include]] 代码。

除了外形有所变化，新组件还新增了 1E-5E 的环境危害分级，并稍微扩展了自定义维度；因此部分页面可能有必要更换为新组件，才能正常显示。请译者自行甄别。

使用 CSS 进行自定义：

你可以使用 CSS 进行额外的自定义，将代码放入到 [[modulecss]] 中或者是放入到页面的版式内都可以。在这一组件中，不要把 [[modulecss]] 放在 [[include]] 里面，把它放在那个的下面或者是页面的顶部或底部。
将这些代码放入到你的页面/版式中以编辑所有的颜色，因为组件的|color= 部分仅能控制背景：

[[modulecss]]
.sd-container {
/*字体*/
--sd-font:Poppins,NotoSansSC,NotoSerifSC;

/*边框*/
--sd-border:var(--gray-monochrome);/*大多数等级*/
--sd-border-secondary:0,0,0;/*不适用*/
--sd-border-deadzone:20,0,0;/*死区*/

/*标志*/
--sd-symbol:var(--sd-border)!important;/*大多数标志*/
--sd-symbol-secondary:255,255,255;/*4级以上的是白色*/

/*文本*/
--sd-bullets:var(--sd-border)!important;/*点句符文本颜色*/
--sd-text:var(--swatch-text-secondary-color);/*顶部框文本颜色*/

/*等级颜色*/
--class-0:247,227,117;
--class-1:255,201,14;
--class-2:245,156,0;
--class-3:249,90,0;
--class-4:254,23,1;
--class-5:175,6,6;
--class-unknown:38,38,38;
--class-habitable:26,128,111;
--class-deadzone:44,13,12;
--class-pending:182,182,182;
--class-n-a:38,38,38;
--class-amended:185,135,212;
--class-omega:25,46,255;
}
[[/module]]

Level 974.1 是 Level 974 的子层级，可以通过卧室书桌上的电脑进入。

*注：若流浪者采取特定行动，例如找到一定数量的“线索”或进入被称为“居所”的区域，该层级的生存难度等级可能会提升至等级3，即使存在的实体数量很少。*

描述：

Level 974.1呈现为一个无尽的分隔房间空间，每个房间都源自当前流浪者的梦境。这些梦境无论是曾经经历过的还是尚未发生的，随机分布在形状和大小各异的多个房间中。每个房间都有多个出入口，其中一些比其他的更为显眼。在这些房间内，物理法则和时间的流逝表现出显著的变化。值得注意的是，这个子层级中没有噩梦存在；然而噩梦可能会随着流浪者的行为开始出现。

于该子层级中，流浪者可能会发现一些散发着独特重要性光环的物品，这些物品与周围环境形成鲜明的对比。这些物品被认为是关于Level 974计算机“持有者”身份的线索，同时也可能提供该账户密码的相关信息。这种对比或光环对于儿童流浪者而言似乎并不那么明显。虽然大多数线索因损坏而无法被记录，但仍有一些物品包括：一只毛绒猫玩具、一只空碗、一只空盘子、一张看似受损的森林地图、一支注射器、一朵深红色的花，以及一件已经褪色的小白裙。

寻找线索会对974的主层和子层产生影响。“持有者”将负责对这些层级进行修改。“持有者”可能会进行的修改包括在子层的房间中增加噩梦、视觉和听觉的幻觉，以及诱发失眠，这些效果会随着线索的发现而逐渐加剧。此外，“Kitty”在主层跟踪流浪者时也会保持更远的距离。

于该子层级中获得的任何物品，包括图片和录音，都无法带回主层级。此外，流浪者在梦境房间中经历的任何身体变化或影响都不会延续下去，除非是因积累了足够的线索而由持有者主动引发的。

居所

居所的3d复原

若流浪者冒险深入下层，他们可能会在无意中进入一个被称为“居所”的区域。这片区域的特点是漂浮和移动的房间框架，以及灰度色调的墙壁和门口，夹杂着类似薰衣草的色彩，这些元素在一个广阔、可能无限的空间中交错重叠。随着流浪者在居所中不断深入，环境伴随着一种压倒性的恐惧感变得愈加昏暗。此处全然寂静，与梦境区域形成鲜明的对比。尽管框架和墙壁相互穿插，但它们依然坚固，不会受到任何外部因素的影响。这种现象有时会导致意外的陷阱，入口可能会被墙壁或框架阻挡，直到它们飘散开去。

在深处的居所中理论上潜藏着某种尚未被证实的实体。当流浪者穿越这一区域时，会感受到一种类似低重力的状态，就像在卫星或宇宙飞船中漂浮。这个居所从梦境区域中可见，始终处于不断变化和漂浮的状态。随着流浪者逐渐接近居所，周围的声音会变得愈加微弱，重力也会开始减轻。

实体

该子层级中存在着一种孤例实体，其被称为“持有者”。目击“持有者”实体的实体形态极为罕见，只有少数流浪者曾与之相遇，但他们都不愿意详细记录自己的经历。尽管如此，相关的描述显示，该实体并未以其“真实形态”出现。唯一的描述是它的头部被星形覆盖物包裹着眼睛，但关于其“真实形态”的信息依然不明。

关于“持有者”的理论
凭证已接受

虽然我拒绝透露自己的身份，但我并没有拒绝尝试讨论我收集到的关于这个所谓的“持有者”的信息。我之所以说是“尝试”，是因为“持有者”不仅难以谈论，甚至难以记录。我在这里见过很多疯狂的sh##1，但这个实体真的与众不同。似乎有一种诅咒的存在使我不得不忽略一些关键细节。我唯一能够测试它而没有被它击中的原因，是因为它能看到我想要帮助它的愿望。我是真心想要帮助它，但它似乎不信任任何人。它甚至几乎不信任我，而我甚至都不知道为什么。我似乎是少数几个与它交流过的人之一。它并不想被拯救。通往安宁之路需要承受太多痛苦。我听到过它的痛苦。我身上还留着试图逼迫它太过的伤痕。那些尖叫声仍然在我脑海中回荡，而且是无端的。听起来几乎像是一个小女孩的尖叫声。它……就像我们一样。我甚至无法说出我们是什么，但它肯定曾经是其中之一。我能感觉到，除了还有一个可能的地点之外，它们从未在后室探索过其他任何地点。它似乎黏在了那个地点，藏在电脑里。尽管它去往的层级已经扩大了。曾经只是一个房间，现在变成了整整一座房子。它甚至给……嗯，我不知道它是个什么，但是个叫“Kitty”的东西做了一张床。我几乎能在Kitty身上看到它的一部分。我知道，“持有者”已经破碎了。它被撕裂成碎片，害怕将自己重新拼凑起来。我理解，捡起碎片的痛苦是难以承受的。我担心，如果我和它尝试去拼凑，我们会在自己的鲜血中溺亡。要是我能找到一副手套来保护它就好了。碎片已经摆在那里了，我可能不知道它们所有的位置，但在找到那些“手套”之前，任何努力都将是徒劳的。

此外，还有一个被称为“居住者”的理论实体群体。然而，居住者的存在通常被视为流浪者们的幻觉或偏执导致的。这些实体的性质和特征仍然主要处于推测阶段，缺乏确凿证据来证明它们在该子层中的存在。关于这些理论实体的外观，普遍看法是它们通常被描述为阴影，有时模糊地呈现出类人形态，但似乎没有任何明确的特征。
